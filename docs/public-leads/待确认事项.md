### 1.1 当前代码已提前采用的临时口径

以下仅是代码事实，不是项目需求决议，也不能用来关闭本文件中的问题：

- 页面已选择 `/sourcing` 承载当前原型。
- 行业和地区选项前后端均为硬编码；页面采用下拉单选并在表格行内显示标签，行业与地区叠加时为 AND，已显示“当前结果 N 条”总数，但不显示逐标签 facets 数量、不写入 URL、不记忆选择。
- Node 由现有行业、评分 registry 与 Radar profile 规则派生 `businessTags`，没有标签来源、置信度、更新时间、规则版本、人工锁或审计。
- 渠道列、渠道筛选和二级来源 UI 已删除，但 Store/API 参数及底层渠道/来源数据仍保留。
- 列表已选择六列：公司主体/项目、行业/地区、估值、AI 技术评分、更新时间、详情。
- 技术评分按评分维度的 key/name 关键词启发式匹配；该规则未形成批准的业务定义。
- `dataUpdatedAt` 是评分时间、Radar 发布时间、数据库入库时间的临时最大值，不是各来源最近成功或最近新增时间。
- 估值已临时显示“待核验/暂无公开估值”，并从评分研究、Radar 画像和历史融资中顺序选值；正式估值口径、来源证据和冲突规则仍待确认。
- 上述页面/API 改造当前没有对应功能开关。相关问题必须在正式验收/发布前关闭；未确认项不得因代码已存在而视为可以直接发布。
