## LEAD-TASK-004

- **接口改动**：候选响应增加 sourceKey、updatedAt、payloadHash 或版本字段。
- **数据库改动**：Radar 当前仍为文件存储；若迁移数据库需另立技术决策。
- **迁移**：历史 JSONL 离线规范化、备份、dry-run、校验行数和 hash 后替换。
- **依赖**：各来源能够提供或派生稳定 ID；无代码前置任务。
- **阻塞**：历史版本是否保留需 Q-POOL-008 确认；基础 Upsert 可先实现。

- **复杂度**：高。
- **工作量**：3～5 人日。
- **测试**：新增、无变化、字段更新、空字段保护、跨来源同标题、损坏行、并发写、进程中断。
- **验收**：同一来源记录更新后 API 返回新值；文件写入可恢复；统计区分新增/更新/无变化。
- **回滚**：保留版本化备份；切回 append-only；恢复原 JSONL。
- **状态**：未开始。
