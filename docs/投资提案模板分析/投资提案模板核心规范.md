# 投资提案模板核心规范

## 1. 规范目的

本规范基于 `docs/投资提案` 中 9 份投资提案模板提炼，用于统一人工写作与 AI 生成的文档格式、结构和章节内容。

模板只提供格式、结构、写作方式和专业术语，不提供当前项目事实。模板中的公司、人物、客户、金额、估值、预测、条款和结论不得复制或改名复用。

## 2. 输入与事实优先级

生成内容按以下顺序取值，低优先级不得覆盖高优先级：

1. 用户本次明确输入；
2. 当前项目结构化字段；
3. 截至资料截止日的已授权项目证据；
4. 截至资料截止日可追溯的联网公开信息；
5. 基于上述事实形成的审慎分析；
6. 模板仅用于控制格式、结构和文风。

发生数据冲突时，应同时披露不同口径、注明各自日期和来源，并标记为“待核验”，不得自行选择更有利的口径。

联网公开信息只作为补充线索，统一标记为“待核验”。工商、财务、合同、交易条款等关键事实仍须回到官方页面、原始文件或独立来源复核。若联网检索服务完全不可用，应停止生成并提示重试，不得继续输出一份充满资料缺口的文档。

## 3. 文档格式

### 3.1 页面

| 项目 | 统一规则 |
|---|---|
| 纸张 | A4，210mm × 297mm |
| 方向 | 竖向 |
| 分节 | 单节连续排版 |
| 左页边距 | 31.75mm |
| 右页边距 | 31.75mm |
| 上页边距 | 25.4mm |
| 下页边距 | 25.4mm |
| 分栏 | 单栏 |
| 页面背景 | 白色 |

### 3.2 字体与字号

| 文本角色 | 字体 | 字号 | 字形 | 对齐 |
|---|---|---:|---|---|
| 文档主标题 | 黑体 | 16pt | 加粗 | 居中 |
| 一级标题 | 黑体 | 14pt | 加粗 | 左对齐 |
| 二级标题 | 楷体 | 14pt | 常规 | 左对齐 |
| 三级标题/条款标题 | 仿宋 | 12pt | 加粗 | 左对齐 |
| 正文 | 仿宋 | 12pt | 常规 | 两端对齐 |
| 投委会称谓 | 仿宋 | 12pt | 加粗 | 左对齐 |
| 表格标题 | 仿宋 | 12pt | 加粗 | 居中 |
| 表格正文 | 仿宋 | 10.5pt | 常规 | 按列设置 |
| 单位、注释和来源 | 仿宋 | 10.5pt | 常规 | 左或右对齐 |
| 页眉 | 宋体 | 10.5pt | 常规 | 居中 |
| 页码及西文数字 | Times New Roman | 10.5pt | 常规 | 居中 |

同一文本角色全篇使用相同字体、字号和字形，不使用微软雅黑、彩色字体或临时直接格式覆盖统一样式。

### 3.3 段落

| 项目 | 统一规则 |
|---|---|
| 正文行距 | 固定值 24pt |
| 标题行距 | 固定值 24pt |
| 段前 | 0pt |
| 段后 | 0pt |
| 正文首行缩进 | 2 个汉字 |
| 称谓首行缩进 | 0 |
| 标题首行缩进 | 0 |
| 正文对齐 | 两端对齐 |

每段只表达一个中心意思，主要采用“判断—事实—限制或影响”的顺序。

### 3.4 标题编号

统一使用中文公文式编号：

```text
一、一级标题
（一）二级标题
1. 三级标题
（1）条款或分项
```

不得在中文一级、二级标题前再添加英文数字编号。

### 3.5 页眉与页脚

- 页眉写投资机构、基金或管理机构标准名称；
- 页眉文字居中，下方设置一条细黑色横线；
- 首页和后续页使用相同页眉；
- 页脚只设置居中的连续阿拉伯数字页码；
- 页眉页脚不放置项目结论、长段保密说明或技术信息。

### 3.6 表格

- 使用 Word 原生可编辑表格，不使用截图或空格拼接伪表格；
- 表格宽度不得超过正文版心，必须明确设置列宽；
- 使用黑色细实线边框；
- 表头加粗并统一使用 `D9D9D9` 浅灰底；
- 表格正文使用 10.5pt 仿宋；
- 文字列左对齐，序号、日期、比例和金额按列居中或右对齐；
- 行高自动增长，不使用可能截断内容的固定行高；
- 跨页表格重复显示表头；
- 单位、币种、期间、实际/预测属性和数据状态必须明确；
- 表后需要说明口径时，使用“注：”单独列示。

### 3.7 排版与分页

- 不设置独立封面，主标题后直接进入投委会称谓；
- 正文按章节自然流排，不按固定章节数量强制分页；
- 标题必须与后续至少一段正文或一行表格同页；
- 不在页底留下孤立标题；
- 长表格可跨页，但不得超出版心；
- 机构落款和日期保持在一起；
- 全文只使用黑、白、灰，不使用彩色卡片、渐变背景、彩色状态标签或营销式装饰。

## 4. 标准文档结构

统一采用以下完整结构：

```text
页眉：投资机构/基金/管理机构名称

主标题：关于[投资主体]对[目标公司]实施股权投资的提案

各位投资决策委员会成员：
提案说明
授权说明

一、基本情况简介
  （一）公司简介
  （二）核心团队
  （三）公司股权结构
  （四）产品及技术
  （五）运营摘要
  （六）财务摘要

二、交易条件
  （一）历史融资情况
  （二）本轮公司估值和投资方案
  （三）风险控制及保护性条款

三、公司业务计划
  （一）经营预测与回报测算
  （二）可比公司估值比较

四、项目亮点总结

五、风险提示与对策

六、结论

投资机构/管理机构落款
日期

页脚：页码
```

项目资料不足时必须先联网补充。公开检索已执行但未发现可直接引用结果的，保留对应标题并标注“待核验”，说明检索边界和需取得的原始资料，不得直接输出“资料缺口”，也不得使用模板项目内容补齐。

## 5. 各结构内容规则

### 5.1 主标题

标准格式：

```text
关于[投资主体]对[目标公司]实施股权投资的提案
```

投资主体尚未确定时：

```text
关于对[目标公司]实施股权投资的提案
```

标题必须包含投资主体、目标公司、投资动作和文种“提案”，不得加入日期、估值、轮次、版本号、Skill 名称或“AI 生成”等技术信息。

### 5.2 投委会称谓

统一使用：

```text
各位投资决策委员会成员：
```

### 5.3 提案说明

使用一个完整段落说明：

- 投资主体和目标公司；
- 增资、老股受让或组合交易形式；
- 本次提交审议的事项；
- 同时提交的投资建议书、尽调报告或其他材料。

交易形式尚未确定时写“拟议股权投资方案”，不得擅自确定交易方式。

### 5.4 授权说明

说明：

- 投委会审议通过后的执行主体；
- 执行范围；
- 仍须以后续尽调、内部审批和正式协议为准的事项。

不得把“提交审议”写成“已经批准”，也不得将授权表述为无限制授权。

### 5.5 一、基本情况简介

本章回答“目标公司是谁、做什么、由谁经营、经营和财务质量如何”。

#### （一）公司简介

写明：

- 公司全称、成立时间、注册地和主要经营地；
- 主体性质、发展阶段和控制关系；
- 行业定位、主营业务和商业模式；
- 当前发展状态及进入本次审议范围的原因。

优先使用工商信息、项目档案、公司 BP 和经核验的公司材料。

#### （二）核心团队

写明：

- 创始人、实际控制人和关键管理人员；
- 技术、销售、交付、生产和财务等关键岗位；
- 与当前业务匹配的教育、从业和创业经历；
- 团队稳定性、专职状态、关键人依赖和潜在冲突。

重点说明经历如何支持当前岗位，不堆砌头衔。未核验的履历、荣誉和行业资源必须注明资料属性。

#### （三）公司股权结构

写明：

- 实际控制人及控制路径；
- 主要股东、持股平台和员工持股安排；
- 最新股本口径和持股比例；
- 代持、质押、冻结、优先权、历史变更和潜在纠纷；
- 本轮交易前后的股权变化。

使用原生股权结构表，至少包含：

| 股东 | 出资额/股份数 | 持股比例 | 股东性质 | 备注 |
|---|---:|---:|---|---|

#### （四）产品及技术

写明：

- 产品或服务矩阵；
- 核心技术路线和关键模块；
- 技术成熟度、研发进度和产品化状态；
- 专利、软件著作权、许可和知识产权归属；
- 与替代方案或主要竞争者相比的差异；
- 尚未验证的性能、认证、临床或量产假设。

必须区分“已形成”“研发中”和“计划推出”。公司自述的性能指标不得直接写成独立验证结论。

#### （五）运营摘要

写明：

- 客户类型、代表性客户和集中度；
- 合同、订单、交付、验收、回款和复购；
- 获客方式、销售周期、定价和商业模式；
- 供应链、产能、生产、交付和售后能力；
- 当前经营里程碑及其核验情况。

必须区分已确认收入、已签合同、意向订单和潜在业务机会，不得把框架协议、试用或意向合作写成确定收入。

#### （六）财务摘要

写明：

- 历史收入、成本、毛利、净利润和现金流；
- 资产、负债、现金余额和主要异常科目；
- 收入增长、毛利变化、费用结构和亏损原因；
- 审计状态、会计期间、币种和数据口径；
- 财务数据与合同、交付、发票和流水的一致性。

使用原生财务摘要表，至少包含：

| 指标 | 较早年度 A | 最近年度 A | 最新一期 A | 备注 |
|---|---:|---:|---:|---|
| 营业收入 |  |  |  |  |
| 毛利/毛利率 |  |  |  |  |
| 净利润 |  |  |  |  |
| 经营活动现金流 |  |  |  |  |

`A` 表示实际数，`E` 表示预测数。未审计管理报表不得写成审计结果。

### 5.6 二、交易条件

本章回答“以什么价格、什么方式、什么权利和风控安排实施投资”。

#### （一）历史融资情况

写明：

- 各轮融资时间和轮次；
- 融资金额、投前或投后估值；
- 主要投资方；
- 增资或股权转让形式；
- 历史特殊权利的延续、终止或恢复安排。

使用原生历史融资表：

| 时间 | 轮次 | 融资金额 | 投后估值 | 主要投资方 | 备注 |
|---|---|---:|---:|---|---|

融资金额、估值、工商变更和付款凭证不能勾稽时，必须说明差异并标记“待核验”。

#### （二）本轮公司估值和投资方案

写明：

- 本轮投资主体；
- 增资、老股受让或组合交易形式；
- 投资金额；
- 投前和投后估值；
- 拟取得股比及计算口径；
- 交割步骤、付款安排和资金用途；
- 与基金期限、投资范围、地域或返投要求的适配关系。

使用原生交易方案表：

| 项目 | 方案 |
|---|---|
| 投资形式 |  |
| 投资金额 |  |
| 投前/投后估值 |  |
| 拟取得股比 |  |
| 资金用途 |  |
| 交割安排 |  |

估值、金额和股比必须互相勾稽。尚处谈判阶段的内容使用“拟”“暂定”“以正式协议为准”。

#### （三）风险控制及保护性条款

归纳说明：

- 交割前提；
- 董事席位、观察员权和重大事项同意权；
- 信息权和检查权；
- 优先认购、优先购买、共同出售、反稀释和领售安排；
- 回购触发条件、义务主体、期限、价格和责任上限；
- 优先清算和视同清算；
- 创始人服务期、竞业、知识产权和违约责任；
- 投资人解除或暂停交割条件。

先说明条款目的，再概括触发条件和投资人权利，不逐字复制整份协议。未形成正式条款时必须标记为“拟议条款”并提示法务复核。

### 5.7 三、公司业务计划

本章回答“未来业绩、估值和退出依靠哪些假设，这些假设是否可以验证”。

#### （一）经营预测与回报测算

写明：

- 预测期间；
- 销量、客户数、订单、单价、收入、毛利和净利润；
- 产能、人员、研发、销售和资金投入假设；
- 退出时间和退出方式；
- 退出估值口径；
- 投资回报倍数或内部收益率；
- 关键变量敏感性。

使用原生预测与回报表：

| 指标 | 历史年度 A | 预测年度 E | 预测年度 E | 关键假设 |
|---|---:|---:|---:|---|

管理层预测必须标为预测，不得写成承诺。回报测算必须说明稀释、税费、持有期和退出估值假设。

#### （二）可比公司估值比较

写明：

- 可比公司的选择理由；
- 业务、发展阶段和盈利模式差异；
- 数据时点和来源；
- 市值或交易估值；
- P/S、P/E、EV/EBITDA 等适用倍数；
- 对目标公司估值的支持和限制。

使用原生可比估值表：

| 可比公司 | 主营业务 | 数据时点 | 市值/估值 | 核心倍数 | 可比性说明 |
|---|---|---|---:|---:|---|

必须解释可比性，不得把上市公司市值与一级市场融资估值直接等同。

### 5.8 四、项目亮点总结

提炼 3–5 项已经获得证据支持的投资逻辑，包括：

- 行业或市场机会；
- 产品和技术差异化；
- 客户验证和商业化进展；
- 团队能力；
- 交易价格或退出路径；
- 与基金策略的适配。

每项采用“亮点判断—支持证据—对投资价值的影响”。不得使用“唯一”“绝对领先”“确定上市”“零风险”等无证据表述。

### 5.9 五、风险提示与对策

至少检查：

- 技术和产品风险；
- 客户、订单和商业化风险；
- 财务真实性、现金流和持续经营风险；
- 团队和关键人风险；
- 供应链、产能和交付风险；
- 知识产权、资质和合规风险；
- 估值、交易和退出风险；
- 基金适配和内部审批风险。

每项风险统一采用：

```text
风险事实或触发条件 → 潜在影响 → 核验或缓释动作 → 责任主体和完成时点
```

不得只列风险名称，不说明影响和应对动作。

### 5.10 六、结论

综合公司质量、交易价格、回报路径和重大风险，写明：

- 是否建议进入下一阶段；
- 主要支持理由；
- 必须完成的补充核验；
- 必须落实的交易或保护条件；
- 重大否决条件；
- 下一步动作和责任主体。

统一使用条件式建议：

```text
综合现有资料，建议在完成[关键核验事项]、落实[关键交易条件]并经[必要审批主体]确认后，
将本项目推进至[下一阶段]。如[重大否决条件]未能消除，则应重新评估或暂停本次投资。
```

结论不得表述为投委会已经批准，也不得替代正式投资决议。

### 5.11 落款与日期

- 写投资机构、基金或管理机构全称；
- 写提案形成日期或提交日期；
- 右对齐；
- 机构名称和日期保持在同一页；
- 日期不确定时使用资料截止日并注明口径，不得猜测。

### 5.12 联网补充与来源留痕

- 生成前围绕公司基本情况、团队、股权与融资、产品技术、客户运营、财务、本轮交易、预测退出、行业可比和风险合规执行联网检索；
- 优先使用官方网站、政府或监管信息、交易所公告、司法及知识产权公开系统、权威行业机构和可追溯媒体；
- 搜索结果摘要只能作为线索；公开网页支持的正文或表格统一标记为“待核验”；
- 已执行检索但未发现可直接引用结果时，正文说明“公开检索未发现可直接引用信息”，并列明应取得的原始文件；
- 联网服务全部失败时停止生成，不以资料缺口占位后继续交付；
- 来源名称、网页地址、检索日期、资料截止日、引用位置和核验状态写入任务来源表及产物审计元数据；
- 用户补充内容单独标注为“用户补充输入”，并保留在任务来源表；
- 正文末尾不增加“免责声明”或“引用资料”板块，机构落款和日期即为文档结尾；
- 模板样本不得作为当前项目事实来源。

## 6. 写作与证据规则

- 使用正式、克制、可审议的投委会书面语；
- 每段只承担一个中心任务；
- 先给判断，再给事实和限制条件；
- 每个金额写明币种，每个财务数字写明期间和单位；
- 区分实际数、预测数、意向数据和管理层口径；
- 区分“资料记载”“分析判断”“待核验”和“资料缺口”；
- 联网公开信息必须使用“待核验”，不得升级为“资料记载”；
- 公司自述、意向订单、框架协议、未审计数据和拟议条款必须降级表述；
- 同一事实、数字、风险或资料缺口只在最相关章节完整出现一次；
- 项目亮点只能总结前文已有证据；
- 风险章节不得被保护性条款替代；
- 结论必须能够回溯到前文事实、表格和风险；
- 不使用模板项目内容补齐当前项目资料缺口；
- 不输出提示词、模板分析过程、Skill 名称或内部技术信息。

## 7. 资料不足处理

| 状态 | 使用条件 | 写法 |
|---|---|---|
| 资料记载 | 有直接、可追溯来源 | 客观陈述并关联来源 |
| 分析判断 | 有事实支持但属于推论 | 使用“预计”“可能”“在……前提下”等条件式表述 |
| 待核验 | 联网公开信息、有部分资料、存在冲突或真实性未确认 | 披露检索结果或已知口径、判断边界及需取得的原始资料 |
| 资料缺口 | 联网检索已经执行，但项目证据和可引用公开结果仍不足 | 仅说明证据边界、所需原始资料和人工复核要求；生成物标记为受限初稿 |

### 8.1 格式

- [ ] A4 竖版，左右页边距 31.75mm，上下页边距 25.4mm；
- [ ] 主标题 16pt 黑体，一级标题 14pt 黑体，二级标题 14pt 楷体，正文 12pt 仿宋；

- [ ] 中文标题编号完整且没有额外英文编号；

- [ ] 标题、称谓、提案说明和授权说明齐全；
- [ ] 六个一级章节及规定的二级章节顺序完整；

- [ ] 落款、日期位于文末，正文不增加免责声明或引用资料板块；
- [ ] 资料不足的章节已先执行联网补充，并以待核验方式写明边界和后续动作。

- [ ] 结论为条件式建议，并写明下一步；
- [ ] 同一事实没有跨章节重复；
