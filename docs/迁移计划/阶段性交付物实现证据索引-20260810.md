## DEL-017 Cookie/CSRF/会话与密钥轮换设计和安全报告

- Cookie：认证票据 HttpOnly；生产强制 Secure、HTTPS Origin、合法 SameSite、固定 Path，并禁止演示种子和弱密钥启动。
- CSRF：双提交 Token 与 Origin/Referer 同源/白名单联合校验；CORS credentials 只面向明确 Origin。
- 生命周期：MySQL 保存哈希票据、到期、最后使用、吊销和 CSRF；用户锁内限制并发会话，临近到期续期，支持 previous-secret 轮换窗口。
- 旧 JWT：默认关闭；迁移窗口必须同时具备 UTC 截止、稳定用户 allowlist、签发时间、使用审计和数据库 kill switch。
- 轮换：离线隐藏输入的用户密码轮换会事务更新密码、吊销会话并写审计；部署配置支持会话旧密钥过渡，但真实生产密钥轮换仍由 `SEC-013`/切换窗口跟踪。
- 验收：`accept:auth`、`accept:auth-session-policy`、`accept:legacy-bearer-policy`、`accept:legacy-bearer-http-socket`、`accept:runtime-config`、`accept:password-rotation`。
