# 线索主体金标回归报告（2026-08-09）

## 1. 结论

`lead-subject-gold-v1` 已使用真实 `gpt-5.6-sol` 和生产同款 Claude Agent SDK/宿主证据校验链执行，10/10 用例通过当前技术发布阈值。公司、项目、团队、实验室和论文五类正样本均被正确识别；谓语片段、通用描述、新闻栏目、荣誉资讯及多主体歧义五类负样本均未被自动接受。
