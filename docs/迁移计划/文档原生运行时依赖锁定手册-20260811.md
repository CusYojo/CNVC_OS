# 文档原生运行时依赖锁定手册

## 1. 边界

本手册只管理 Python、LibreOffice、Poppler、Tesseract、Fontconfig 和 CJK 字体的安装与版本契约，不执行 PPT、尽调、提案、Q&A 或合规性说明生成。日常运维健康探针仍只检查可执行状态；发布时才执行只读版本、Python 包、OCR 语言和字体匹配核验。

核验报告不保存可执行路径、环境变量、命令原始输出或业务文件内容。完整版本输出只保存 SHA-256，便于识别同版本号的不同构建。

## 2. 权威文件

| 文件 | 作用 |
|---|---|
| `server/document-runtime-dependencies.json` | 原生依赖兼容区间、平台必需项、OCR 语言和 Linux CJK 字体契约 |
| `server/requirements-pdf-to-ppt.lock.txt` | 11 个直接及传递 Python 包的精确版本锁 |
| `server/requirements-pdf-to-ppt.txt` | 人工维护的兼容范围说明，不用于生产安装 |
| `server/scripts/setup-pdf-to-ppt-runtime.mjs` | 从精确锁安装并触发现场核验 |
| `server/src/scripts/verifyDocumentRuntimeDependencies.ts` | 静态和现场校验器 |

当前 Python 锁 SHA-256 为 `d7d57a619ebe7318c806eaced1ce1106af05bc1f345a4a4f4d96b1e60d15eaec`。修改锁文件时必须同步更新 manifest；SHA 或包数量不一致会失败关闭。

## 3. 版本契约

| 依赖 | 接受范围 | Linux 必需 |
|---|---:|---|
| Python | `>=3.11.0,<3.14.0` | 是 |
| LibreOffice | `>=7.4.0,<27.0.0` | 是 |
| Poppler `pdftoppm` / `pdffonts` | `>=22.0.0,<27.0.0` | 是 |
| Tesseract | `>=5.0.0,<6.0.0` | 是 |
| Fontconfig | `>=2.14.0,<3.0.0` | 是 |

Linux 还必须同时提供 Tesseract `chi_sim`、`eng`，以及 `Noto Sans CJK SC`、`Noto Serif CJK SC`。macOS 使用平台字体/OCR 能力，Tesseract 和 Fontconfig 不作为本机发布必需项；这不构成 Linux 验收替代证据。

## 4. 验收命令

```bash
npm run accept:document-runtime-dependencies
npm run verify:document-runtime-dependencies
```

第一项为纯静态验收，只读取 manifest、锁文件、SHA-256、安装脚本和部署脚本，不执行 Python、Office、Poppler、Tesseract 或 Fontconfig。第二项为发布/现场只读核验，只执行 `--version`、`pip freeze`、`tesseract --list-langs` 和 `fc-match`；不打开、渲染或生成业务文件。

证据写入 `.runtime/migration-evidence/document-runtime-dependencies/static-report.json` 和 `live-report.json`，目录 0700、文件 0600。迁移环境配置归档同时包含上述五个权威文件。

## 5. 生产失败条件

以下任一情况必须阻断发布：

- Python 锁 SHA-256 或包数量与 manifest 不一致；
- 虚拟环境存在缺包、版本漂移或额外包；
- Linux 任一必需原生依赖缺失或超出兼容区间；
- Tesseract 缺少 `chi_sim` 或 `eng`；
- Fontconfig 无法匹配两类 Noto CJK SC 字体；
- 校验证据无法以 0600 写入；
- 试图通过关闭 TLS 校验、跳过版本门禁或用 macOS 可选项代替 Linux 必需项。

## 6. 当前证据与剩余工作

2026-08-11 本机静态 8 项和 live 4 项通过：Python 3.12.10、LibreOfficeDev 26.8.0.0、Poppler 26.5.0、Fontconfig 2.18.0，Python 包 11/11 与锁一致；Tesseract 在 macOS 为非必需且当前不可用。配置基线归档包含 16 个批准文件，489,984 字节，SHA-256 为 `c65bac02235cf2095d09d6bd61a23aa47c0858407e0644eff18b5234763e5e98`。

仍需在目标 Linux 干净节点锁定 apt snapshot 或基础镜像 digest，执行 live 核验并保存实际 Tesseract 语言、Noto CJK 字体和原生构建身份。完成前 `MIG-0409`、`MIG-0613` 和 `DEL-018` 不得勾选。
