# 旧系统与迁移环境已知问题基线

日期：2026-08-10

本文件完成 `MIG-0026`：明确问题的已知来源，避免迁移后把既有数据缺口、环境约束或已批准延期误判为新系统回归。问题是否关闭仍以《迁移决策与问题台账》为准。

| 基线项 | 已知来源 | 当前事实 | 迁移验收判定 |
| --- | --- | --- | --- |
| `ISSUE-001` | 迁移环境 | 配置的生产 PostgreSQL 候选当前拒绝连接 | 不归因于 MySQL 应用；真实 CDC/切流保持未通过 |
| `ISSUE-002` | 生产资产治理 | 生产源资产盘点没有负责人签字 | 本地盘点不能外推为生产全量 |

| `ISSUE-004` | 旧文件资产 | 17 个项目原件缺少源字节 | 元数据不等于文件恢复 |
| `ISSUE-005` | 旧文件资产 | 7 个 AI 产物缺少源字节 | 在线隐藏不等于产物恢复 |

| `ISSUE-012` | 外部渠道联调 | IM 管理、加密绑定、Outbox 和授权线索推送基座已实现；钉钉/飞书/微信原生协议与真实租户凭据仍未验收 | 本地通用契约不能外推为真实渠道收发成功；未联调渠道保持关闭 |

另有两个非回归约束：迁移开始前工作区已包含大量用户改动，不能自动清理或归属；外部模型网关的输入 Token 当前可能返回 0，完整 Token 门禁不得据此宣称通过。
