# 浏览器权威源与退场页面验收（2026-08-09）

## 结论

本地生产构建由唯一 `cybernaut-app` 在 3100 提供。使用新的应用内浏览器会话首次访问，登录页账号和密码均为空；登录后首页、项目、OA、公共线索池和系统数据均从服务端恢复，刷新 OA、线索和系统页后数据仍在，浏览器控制台无 warning/error。

本次证明 `SMOKE-014` 的本地页面范围通过，但不能替代目标生产域名、TLS、真实 systemd/cgroup 和多角色人工验收。

## 验收中发现并修复

1. 首页“本周新增 2 个”“待生成材料 +2”“本周已生成 5 份”“今日到期 2 项”和顶部固定 2 项优先任务属于演示偏移。已改为按 MySQL 项目创建时间、真实待办截止日/优先级、风险和 OA 数量计算，并将材料入口改到统一 `/ai`。
2. 会议页曾在 AI 失败时制造占位摘要、结论和待办，且上传文件会写入“音频模拟转写”，详细纪要为固定文本。现已失败关闭：AI 失败不保存会议/待办；表单默认正文为空；录音转写和假导出入口退场；详情展示持久化会议原文。
3. 后续代码复核发现会议 API 的数据库字段与页面字段错配，且前端分步创建会议和待办会产生半成功。现已改为稳定页面契约，会议、待办、实际操作者审计同一 MySQL 事务提交，刷新按 `meeting_id` 恢复；`accept:meeting-persistence` 4 项通过。
4. 线索池“上传 BP”和“批量导入”尚无正式文件解析任务契约，原实现通过定时器制造进度并写固定分数、主体、团队、融资等内容；固定成功的 `/ai/bp-parse`、`/ai/jobs/:id` 也无权威状态。上述入口和 API 已退场。新建项目不再编造公司全称或占位业务摘要。
5. 模型健康检查现与实际 Runtime 共用 `LLM_*`/`OPENAI_*` 网关地址和鉴权配置，避免运行时可用但页面误报本机默认网关故障。
6. `accept:client-state-authority` 已扩展至 15 项，持续阻止首页固定演示指标、会议占位内容、模拟 BP 导入、项目虚构兜底字段和模型探针配置漂移回归。
