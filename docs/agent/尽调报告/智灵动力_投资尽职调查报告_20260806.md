## 一、执行摘要

### 1.1 核心结论

**现阶段建议：暂不进入投资决策，转入“补充资料后再评估/谨慎观察”。**

智灵动力被公开信息描述为一家以国产开源大模型为基础、面向医疗、服装、教育、工业、媒体内容等场景提供多模态AI解决方案的早期企业，公开信息显示其已有天使轮融资记录，并形成数字人、内容生产、视频创作、时尚设计等产品线。但当前证据链存在明显缺口与冲突：公司成立时间、注册资本、地址、经营历史与产品历史口径不一致；公司披露的客户规模、产品效果和商业化数据缺乏合同、验收、回款及第三方测评支撑；财务、股权、知识产权、医疗合规和数据合规材料均未取得。

### 1.2 初步亮点

1. **产品矩阵及垂直场景探索较丰富。** 公开报道提及“元娲”数字人、“元评”内容系统、“元镜”视频平台、“元裳”时尚设计平台，体现多模态、智能交互和垂直行业适配思路。
2. **时尚垂类存在较具体的方法论描述。** 联合创始人朱旭琪公开介绍了元裳大模型的数据标准、私有模型训练、多模态模型及从设计到试衣、3D秀场的链式服务框架。
3. **公开信息显示已完成天使轮融资。** 第三方创业数据库/企业信息页面称公司于2025年3月获飞图创投、盛景网联（盛景嘉成）投资，但金额、估值及交割文件尚未核验。
4. **行业方向具备需求基础。** 企业智能化、AIGC内容生产、AI医疗和服装设计数字化均存在效率提升需求，但不同赛道监管强度和商业化路径差异较大。

### 1.3 核心风险

1. **主体与历史沿革冲突（高风险）。** 工商页面显示主体成立于2024年11月11日；媒体采访称“智灵动力成立于2023年”，并称元裳于2023年实现PMF。需核实是否存在前身公司、业务承接、资产/IP转让及关联交易。
2. **工商信息冲突（高风险）。** 不同公开页面显示注册资本为100万元或2,000万元，注册地址亦存在差异。可能源于工商变更或第三方数据滞后，须以全套工商内档为准。
3. **商业化真实性未验证（高风险）。** “服务3万家企业”“省级党媒日产能从300篇增至5000篇”“72小时生成3000+设计稿”等信息主要来自自媒体/转载文章，缺少客户实名确认、合同、验收、发票与回款闭环。
4. **财务信息完全缺失（高风险）。** 无法判断收入质量、毛利率、研发投入、算力成本、现金消耗、应收账款及持续经营能力。
5. **核心技术与知识产权边界不清（高风险）。** 公司强调基于国产开源模型并升级DeepSeek基座，但自研层级、开源许可遵循、数据权属、模型权重、专利及软著尚未核验。
6. **多赛道战略分散（中高风险）。** 医疗、服装、教育、工业、媒体、咨询等场景跨度大，早期企业可能面临研发、销售和交付资源分散，难以形成单一可复制商业闭环。
7. **医疗业务监管风险（高风险，若实质开展）。** 若产品涉及诊断建议、临床决策或医疗器械预期用途，可能涉及医疗器械注册、临床评价、算法变更和质量体系；若处理健康医疗数据，还涉及个人信息、敏感个人信息和数据安全义务。当前未发现项目级资质证据。
8. **宣传合规与声誉风险（中高风险）。** 若公开效果指标未经严谨测试或客户授权，可能引发虚假/夸大宣传、客户保密、知识产权及声誉风险。

在以下事项完成前，不建议给出估值或投资条款：

## 八、行业与竞争分析

### 8.1 行业判断

公司跨越多个AIGC应用赛道，不宜用单一“AI医疗”市场规模为其整体估值背书。行业资料显示，AI医疗正由概念验证走向商业化，但医疗数据、临床验证、产品注册、收费路径和医生接受度仍构成核心门槛；服装AIGC则对数据标准、设计可控性、制版可靠性和行业接受度要求较高。

### 8.2 竞争结构

- **基础模型与云平台：** 大型模型厂商可向下提供通用多模态、Agent和行业工具，挤压应用层议价空间。
- **垂直AI企业：** 在医疗、时尚、内容、数字人等单一赛道深耕，拥有更强数据、客户和合规积累。
- **传统软件/设备厂商：** 掌握医院、媒体、服装企业的既有系统入口和客户关系，可通过集成AI功能形成替代。
- **客户自研：** 大型客户可能基于开源模型和内部数据搭建私有系统。

### 8.3 智灵动力可能的差异化

公开材料显示其试图以“人机共生引擎+多模态+垂直适配”覆盖多个场景。但该差异化目前更多属于产品叙事，尚未由独家数据、专利、头部客户、续费率、单位经济模型或权威评测证明。

### 8.4 战略建议

优先收敛1—2个已具备付费与复购证据的场景，以可量化ROI、标准化交付和数据闭环建立壁垒；医疗等高监管方向不宜仅凭通用产品能力横向扩张。

7. 关联方往来、资金拆借和异常大额交易；
8. 未来24个月预算、现金消耗及融资计划。

### 9.3 财务核验重点

- 收入确认是否与验收及履约义务匹配；
- 免费试用、渠道代销、关联交易是否被计入收入；
- 项目制交付的人力和算力成本是否完整归集；
- 应收账款是否存在长账期、回款依赖或坏账；
- 研发费用及无形资产是否存在不当资本化；
- 融资到账与估值是否与工商、银行流水一致；
- 现金可支撑月数及降本空间。

## 十、法律、合规与数据安全

### 10.1 公司与合同合规

需核验公司主体资质、重大合同、关联交易、借款担保、诉讼仲裁、行政处罚、知识产权争议及商业秘密保护。当前未取得项目级原始证据。

### 10.2 数据与个人信息保护

公司产品涉及文本、图像、语音、视频及可能的医疗健康数据，应重点检查：

- 数据来源和处理目的是否合法、正当、必要；
- 是否取得个人信息及敏感个人信息的有效授权；
- 客户数据、公开网络数据、训练数据的使用边界；
- 数据脱敏、最小权限、访问审计、加密、留存和删除机制；
- 向第三方模型/API传输数据的合同与风险控制；
- 跨境传输及海外业务的合规安排；
- 生成内容的版权、肖像、声音、商标和不良信息治理。

### 10.3 生成式AI与内容治理

若公司向境内公众提供生成式AI服务，应核验适用的备案/登记、安全评估、内容标识及投诉处置要求；企业私有化部署也需明确客户与公司的责任边界。当前未发现项目级备案证据。

### 10.4 医疗业务监管

若仅用于行政办公、患者服务或非诊断性内容生成，监管路径相对轻；若输出诊断、治疗建议或具有医疗器械预期用途，则应开展产品分类界定、注册检验、临床评价、质量管理体系和不良事件管理。必须以具体产品功能、宣传文案及实际使用方式判断，不能仅以“技术平台”规避监管。

### 10.5 知识产权与开源合规

需建立软件物料清单（SBOM）和模型/数据来源清单，核验DeepSeek及其他模型的许可证、商业使用条件、权重来源及二次分发义务；同时确认员工、顾问、外包和合作开发成果均已归属于公司。

## 十二、投资价值判断

### 12.1 正面逻辑

- AIGC向行业工作流渗透具有长期趋势；
- 公司公开展示了多模态与多个垂直场景的产品化尝试；
- 元裳方向具有相对具体的数据与工作流方法论；
- 若公开客户和效率指标经核验真实，可能已具备一定产品市场匹配基础。

### 12.2 反面逻辑

- 现有证据不足以确认真实收入、复购、毛利和现金流；
- 主体历史与工商口径冲突，资产完整性需优先查清；
- 产品线过宽，可能以项目制交付为主，标准化和可扩张性存疑；
- 基于开源基础模型的应用层容易同质化，技术指标尚未形成可信验证；
- 医疗方向的合规、临床证据和支付路径均未呈现；
- 宣传性指标较多，但缺少可复现测试和客户实名证据。

### 12.3 当前建议

**评级：谨慎观察 / 暂不推荐进入投决。**

建议先安排一次“资料核验型尽调”，用2—3周完成主体、股权、财务、客户、技术和合规六条主线的红旗排查。若公司能证明：

1. 主体及核心资产完整清晰；
2. 代表性客户真实付费并持续复购；
3. 核心产品具有正向毛利和可复制交付；
4. 自研技术、数据和IP权属清晰；
5. 医疗及数据合规路径可执行；
6. 现金续航与融资需求合理；

再进入估值、条款及投资回报分析。
