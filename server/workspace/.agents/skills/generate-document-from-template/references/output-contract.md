# 文档生成与质量规范

## 输入

- 当前用户、项目和会话。
- 原模板文件及其 SHA-256。
- 指定版本的 `template_analysis`。
- 资料截止日、用户参数、当前项目授权证据和联网公开资料。

## 内容生成

1. 保持分析数据中的内部结构槽顺序和层级，但重新拟定全部可见章节标题。
2. 对封面、目录、正文、附录和引用页使用与当前项目用途匹配的全新内容。
3. 正文事实只来自当前项目资料及联网公开信息；模板示例正文只能用于判断表达方式，不得进入输出。
4. 文档标题必须包含当前项目或公司主体并重新生成，不得使用上传文件名或原文档标题。
5. 数字注明期间、单位和口径；推断必须明确标识。
6. 不输出“资料缺口”状态、标题、清单或占位文案；未公开的非公开事项只形成简洁的待核验边界。
7. 同一事实只在一个主结构完整陈述，其他位置只允许简短交叉引用。
8. 文末或最后一页只列正文实际使用的来源，并包含责任声明。

## 格式生成

### DOCX

- 使用分析数据中的页面尺寸、方向、页边距、字体、字号、行距、段距和对齐方式。
- 正文、标题、表格、页眉页脚和页码保持可编辑。
- 保持结构层级，避免将整页内容栅格化。

### PPTX

- 使用分析数据中的画布比例、主题字体、字号、颜色和幻灯片顺序。
- 文字、表格、基础图表和形状保持可编辑。
- 背景、照片和复杂装饰可作为图片使用，但不得把核心业务内容整体图片化。

## 交付前检查

- 文件可由 Microsoft Office 和 WPS 打开，无修复提示。
- 中文无乱码，字体缺失时使用安全替代字体。
- 格式画像的关键令牌已应用。
- 结构完整且顺序一致。
- 无大段重复内容或连续重复句。
- 引用可定位到实际使用的项目资料。
- 交付物不含“资料缺口”标签或占位文案。
- 模板原文档标题、可见章节标题、页眉页脚、示例项目名称、人员、客户和数字没有泄漏到交付物。
