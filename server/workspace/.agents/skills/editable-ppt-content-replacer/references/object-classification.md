# 对象、槽位与实体分类

## 分类原则

所有对象默认 `KEEP`。只有确认对象承担目标内容且存在对应资料时，才能加入
替换白名单。不要把“可编辑”误解为“必须更换”。

| 分类 | 典型对象 | 默认处理 |
|---|---|---|
| 固定视觉 | 背景、卡片底板、边框、线条、箭头、页眉、页脚、页码、机构标识 | 登记为保护对象并 KEEP |
| 共享语义图标 | 使命、愿景、价值观、研发、市场、团队、风险等图标 | 登记为 `shared_semantic_icon` 并 KEEP |
| 内容槽 | 标题、正文、指标、注释、页内结论 | 按资料原位替换文字 |
| 可选槽位组 | 一项荣誉、一张团队卡、一项产品或案例及其配套装饰 | 有内容则填写；无内容则整组删除 |
| 公司专属素材 | 旧公司 Logo、人物、产品、客户、案例、官网截图 | 有对应素材且关系已确认时原位替换 |
| 数据槽 | 原生图表系列、表格单元格、指标数字 | 只替换明确数据 |

## 判断顺序

1. 对象是否属于母版、品牌框架、共享语义图标或页面固定装饰？是则加入
   `protectedObjects`。
2. 对象是否已经可编辑且语义仍适用于新内容？是则 `KEEP`。
3. 对象是否包含旧项目专属文字或数据？是则列为内容槽。
4. 图片是否可以识别为旧公司的 Logo、人物、产品或案例？是则列为公司
   专属素材。
5. 多个对象是否共同表达一项可选内容？是则建立 `slotGroups`，包含文字、
   图片及只属于该槽位的月桂、图标、边框和标签。
6. 人物或产品图片是否能够与姓名、职务、产品名或型号建立唯一关系？能则
   建立 `entityBindings`；不能则停止替换并报告冲突。
7. 是否有可信的目标内容与之对应？没有则标记待补充，或删除完整可选槽位，
   不得随机替换。
8. 被修改页面中的每个可见内容区域是否已进入 `slotAssignments`？未进入则
   不得开始替换。空白矩形、空标签栏和只有图标没有说明的卡片也必须盘点。

## 共享图标规则

- 使命、愿景、价值观等左侧图标属于共享语义，不随右侧文字变化。
- 共享图标必须进入 `protectedObjects`，不能出现在任何替换或删除操作中。
- 原生形状、独立 SVG 或独立图片图标，只要语义仍适用就保持原样。
- 图标语义冲突时，不得自动寻找近似图标；先报告并获得用户明确授权。
- 不得用循环、随机、页内顺序或图片尺寸规则分配新图标。

## 可选槽位组规则

- 一个槽位组必须包含内容对象和只服务于该内容的装饰对象。
- `contentShapeIds` 与 `decorationShapeIds` 必须互斥，二者并集必须等于
  `shapeIds`。
- 删除只允许作用于 `optional=true` 的完整组，使用
  `delete_slot_group` 和 `missingContent=true`。
- 删除后保持原网格：不移动、不拉伸、不居中剩余内容。
- 共享图标和模板固定对象不得加入可删除槽位组。
- 只清空文字、只删除月桂的一侧、只留下空卡片均视为失败。

## 人物和产品素材规则

允许替换：

- 旧公司人物照片；
- 旧公司产品、官网或界面截图；
- 旧公司客户与案例证据；
- 用户明确指定替换的其他公司专属图片。

替换前必须：

1. 为每个实体创建稳定 `entityId` 和 `bindingId`；
2. 将图片槽与姓名/产品名文字槽绑定；
3. 人物还应绑定职务，产品应尽量绑定型号或说明；
4. 核对图片文件、显示名称和标签文字来自同一来源；
5. 禁止同一素材绑定给两个不同实体。

默认保留：

- 通用装饰图片；
- 模板机构 Logo；
- 抽象背景；
- 共享语义图标；
- 不能确认语义归属或对应关系的图片。

## 排版锁定规则

- 1.1 版文字操作必须设置 `styleLock: "exact"`。
- 保留模板的字体、字号、字重、颜色、段落属性、文字框坐标、尺寸和层级。
- 新文字行数与原文字不同或长度显著增加时，校验器会给出警告。
- 先精简内容和调整人工换行；不得自动缩小字号、移动文本框或扩大卡片。
- 替换计划记录模板样式指纹，最终渲染时按指纹和视觉结果双重检查。

## 内容覆盖规则

- `required` 槽位必须 `replace`，且 `expectedContentShapeIds` 全部非空。
- `optional` 槽位只能选择 `replace` 或 `delete`。
- `shared` 和 `template` 槽位只能 `keep`。
- 操作的 `semanticKey` 必须与槽位分配一致，避免把市场数据填入能力图、
  把产品说明填入团队卡或把示例图表当作真实数据。
- 最终结果必须重新分析对象地图；必填文字为空、图表类型错误、图片槽没有
  媒体或应删除对象仍存在，均为硬错误。

## 数据规则

- 数据必须能追溯到用户资料、授权数据库或可靠公开来源。
- “线索”“意向”“在谈”不能写成“合同”“收入”或“回款”。
- 没有对应财务或估值数据时，写“待补充/未披露”，不得沿用模板数据。
- 原生图表仅修改系列、分类和标签，不更换图表类型或视觉样式。
