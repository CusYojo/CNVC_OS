# 投资建议书 PPT 输出契约

## 交付范围

只交付一份最终 PPTX。模板的页面尺寸、页面顺序、母版、版式、字体、字号、
行距、颜色、对象坐标和层级均以用户上传文件为准。PDF 模板先由转换服务生成
可编辑 PPTX 和交接证书；交接通过后，内容阶段严格由
`editable-ppt-content-replacer` 原位替换。完整顺序只能是
`pdf-to-editable-ppt` → `editable-ppt-content-replacer`，不得加载第三个
聚合型生成 Skill，也不得绕过交接后新建空白演示文稿。

核心文字、表格、图表和形状必须保持为原生可编辑对象。不得生成第二份纯图片
PPTX，不得在整页背景图上覆盖文字冒充内容替换，也不得为了容纳文字自动缩小
字号、移动文本框或新增未授权页面。

模板背景属于交付契约：母版、版式背景以及确认的幻灯片背景对象不得被旧项目
清理逻辑删除。公司 Logo 默认使用透明底素材；与 Logo 重叠的旧公司底板必须
单独识别和处理，不能遗留矩形色块，也不能误删模板品牌底板。

## 当前项目内容

模板只提供结构槽和视觉规范。封面、全部业务页、结论页及引用页必须重建为
当前项目内容；不得保留模板项目名称、人物、客户、产品、竞品、行业结论、
财务数字、融资信息、图片或投资判断。

编辑前必须锁定项目身份、逐页建立旧项目污染指纹，并将全部可写内容汇总到
唯一事实库。页面只能引用事实库中的最终值；数值必须携带单位、期间和口径，
不得在不同页面独立生成同一指标。

先使用当前项目资料，再识别内容缺口并定向联网核验。行业、政策和竞品页面只
能作为上下文，不得反推为当前公司事实。客户、合同、财务、融资、估值、专利、
市场份额等重大事实必须由用户原始材料、官方一手来源或两个独立可信来源支持。
无法证实的可选槽位删除完整槽位组；重大必填缺口只在一页专用“待核实事项”
中集中披露。官网、地址等非必要字段缺失时直接省略，不显示
“未提供公司官网”“缺少原始文件”等制作过程提示。

同一事实、数字、风险或投资判断只能在最相关页面完整出现一次；摘要只保留不
重复的结论，不得逐页复述。证据分片和来源必须去重，同一文件的多个片段合并为
一个来源条目。

## 来源与审计

每项替换操作使用 `semanticKey` 和 `evidenceIds` 绑定实际支持该内容的证据。
对应页面的演讲者备注写入 `[Sources]`，记录标题、发布方、直接 URL 或用户
文件定位、发布日期和访问日期。搜索结果页、百科聚合页、视频搜索页、AI 摘要
和无法定位原文的转述不得作为证据。

最后一页为“引用资料与责任声明”，只列正文实际使用且已经去重的来源，并写明
资料截止日和内部使用责任边界。未被正文引用的来源不得出现在最后一页。
如果最后一页只有标题槽位且没有可编辑正文槽位，允许新增且仅新增一个受控
可编辑责任声明文本框；对象名固定为 `references.disclaimer.generated`，
必须位于最后一页画布内，并纳入白名单、保真校验和最终内容覆盖校验。该例外
不得用于正文扩写、增页或改变其他模板对象。

## 交付门禁

交付前必须验证：

- PPTX OpenXML 完整，可在 PowerPoint/WPS 中直接打开和编辑；
- 当前项目名称存在，模板样本项目及其专属标题全部移除；
- 旧项目名称、Logo、人物、产品、案例和数据通过可编辑文字、媒体哈希与
  逐页渲染 OCR 三重扫描；
- 每一页的全部模板对象均完成页面闭环，每个保留对象有具体理由，未知对象为零；
- 无空白必填槽、孤立图标、装饰残影、人物产品错配和文字溢出；
- PDF 转换模板的交接证书、水印检查和最终复检均通过；
- 所有联网内容能够回指登记来源，重大数据满足来源门槛；
- 旧项目数字、原生图表缓存、嵌入工作簿和表格数据均通过残留扫描；
- 逐页容量预算与视觉 QA 通过，无溢出、重叠、错误裁切、空槽和重复套话；
- 最后一页引用资料、页面来源备注和机器审计记录三者一致。
- 受控责任声明文本框最多一个，正文槽位存在时不得新增。

任何模板样本残留、后台缺口提示、未知页面对象、无关网络来源、关键对象
不可编辑、残留 OCR 或水印复检失败都属于硬错误，不得以警告方式继续交付。
