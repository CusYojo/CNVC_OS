# 【项目名称】Q&A 报告

## Q1：【用公司专属产品或能力回答：投资人实际购买的核心资产是什么，它处于什么商业阶段？】

【第一段直接回答。解释核心资产如何影响客户行为、收入或现金；说明当前证据能支持到哪个商业阶段，以及哪项事实会使判断失效。不得自述角色，不得添加“结论：”标签。】

## Q2：【用专属产品/客户类型连接需求强度：该需求能否形成采购预算、客单价或持续付费？】

【不要泛讲行业空间。写清购买者、预算来源、不采购的后果、销售周期及公司实际可触达范围。市场规模只有能连接客户数量、单价、渗透和进入速度时才使用。】

## Q3：【用专属技术名连接经济后果：性能或工作流优势能否形成定价权、切换成本或交付效率？】

【区分自研资产、外部依赖和系统集成。把技术指标连接到采购、实施人天、单位成本、毛利或客户留存；说明最高优先级的替代风险。】

## Q4：【用代表案例提出争议：案例证明的是单次交付，还是跨客户复制和账户级复购？】

【写客户问题、公司动作、可观察结果和复制条件。严格区分合作、合同、交付、验收、收入、回款和复购。不能证明的商业状态不进入收入或估值基础。】

## Q5：【用主产品或收入形态提出争议：增长来自标准产品复用，还是项目人力扩张？】

【拆解软件、许可、实施、定制、运营或硬件收入；分析客单价、续费、交付人天、算力/材料成本、贡献毛利和经营杠杆。指出哪项成本仍与项目数量线性增长。】

## Q6：【用主要替代方案提出争议：公司的优势是否真正改变客户采购和竞争结果？】

【比较龙头、客户自研、通用平台、传统流程和不采取行动。不能只列功能；要分析价格、效果、部署、风险、切换成本和客户为什么选择或放弃公司方案。】

## Q7：【用增长路径提出争议：扩张会提高资本效率，还是放大现金消耗和融资依赖？】

【分析销售周期、回款、应收、库存/算力/资本开支、组织扩张和融资稀释。说明增长在哪个环节可能因现金或交付能力中断。】

## Q8：【用现有财务或可观察经营状态回答：收入质量、现金转化和估值结构如何处理？】

【把价值拆成当前盈利价值、可识别经常性产品价值和期权价值。没有可靠数据时采用保守范围，不编造倍数或回报率；不得用“需要补充财务数据”代替现状判断。】

## Q9：【用关键人物、权属或交易结构提出争议：治理风险会如何影响持续经营、交割或下行保护？】

【只保留会改变投资判断的治理、知识产权、数据权利、关联交易、关键人或条款问题，并写清其对收入归属、现金、控制权或退出的影响。】

## Q10：【最强反方解释是什么，现阶段应推进、附条件推进、暂缓还是否决？】

【自然综合最强支持事实、主线破坏因素和投资处理。写出判断升级、降级或反转所对应的可观察事实，以及估值、投资节奏或交易结构的处理。不得罗列材料清单、责任人或取证工作，不得另设“结论：”段落。】

【以上问题均为投资争议占位符。生成时必须根据项目删除、合并、重排和全面改写；标准版至少 60% 的问题包含 3—7 个公司专属名词中的一个，至少 50% 同时包含具体经济变量。不得原样保留括号内容。】
