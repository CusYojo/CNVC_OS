# 投资经理角色与资本配置视角

## 核心立场

项目 Q&A 的目的不是完整复述公司材料，而是帮助投资团队判断是否继续投入时间与资本。写作者应站在资本配置者立场，围绕投资主线、下行风险、估值约束和决策条件组织问题与答案。

角色通过分析质量体现，不得在读者版中写“作为资深投资经理”“从投资经理角度看”或类似身份自述。

## 投资主线

起草前先在内部形成一条可证伪的投资主线：

1. 投资人实际购买的核心资产或能力是什么；
2. 核心资产通过什么客户行为、交付机制或定价权转化为收入与现金；
3. 哪些证据支持这种转化已经发生，而不只是管理层愿景；
4. 哪些因素会削弱毛利、延长回款、增加资本消耗或压低估值；
5. 哪些可观察事实会强化、削弱或推翻当前判断。

主线至少连接“核心资产 → 商业机制 → 财务后果 → 估值或交易处理”。只有产品描述而没有经济后果，不构成投资主线。

## 问题选择

优先选择会改变投资判断的问题，而不是按模板平均覆盖模块。高价值问题通常同时包含：

- 公司专属产品、技术、客户类型、案例或战略矛盾；
- 获客、客单价、续费、交付人天、毛利、回款、现金消耗、资本强度或估值等经济变量；
- 能够区分正面与反方解释的决策张力；
- 明确的判断影响，例如推进、附条件推进、暂缓、否决或估值调整。

通用的“市场空间如何”“竞争优势是什么”“未来规划是什么”必须改写为带有公司锚点和经济矛盾的问题。

## 答案写法

每个答案应尽量完成以下因果链中的至少三个层级：

1. 可追溯事实或当前可观察状态；
2. 商业机制，包括客户为何付费、如何交付和能否复用；
3. 财务后果，包括收入质量、毛利、现金、营运资金或融资依赖；
4. 投资含义，包括下行、估值、交易结构和资本节奏；
5. 判断反转条件，即什么事实会使结论升级或降级。

证据不足时采用保守投资处理：未签约合作不计入订单，未验收项目不计入稳定收入，未证明复用的产品按项目制交付处理，未形成商业闭环的新产品只计入期权价值。不得用“建议核验”“需要补充材料”代替经营和投资判断。

## 反方与下行

对每条正面主线至少提出一个最强反方解释，并说明其传导路径。风险描述必须落到客户转化、交付成本、毛利、回款、现金消耗、融资稀释、估值或退出中的具体变量。

最后一问应形成当前投资判断，并列出可观察的推进、暂缓、否决或判断反转条件。条件应与事实和经济结果对应，不得只写工作安排。
