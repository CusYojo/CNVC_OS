# 项目类型路由

选择主要项目类型。混合项目可同时使用多条路由，但必须识别哪一层贡献当前收入、哪一层形成壁垒、哪一层仍是未来期权。

## 硬件与设备

重点分析：

- 核心部件和真正的自研边界；
- 精度、速度、稳定性、良率、开机率及测试条件；
- 原型、样机、验证、认证和量产阶段；
- 供应链、国产化、库存、产能、服务和质保；
- 客户资本开支预算和导入周期；
- 设备毛利、Demo 资产、应收账款和营运资金；
- 产品线宽度与当前研发、交付能力是否匹配。

## AI 与软件

重点分析：

- 数据来源、权限、质量和反馈闭环；
- 准确率、幻觉、延迟、可解释性、安全和测试集；
- 对基础模型、开源软件、云和算力的依赖；
- 客户自建与既有软件厂商替代；
- 项目交付与可复用平台的边界；
- 实施、外包、定制和算力成本；
- 订阅、调用、续费、扩单和合同化经常性收入。

## 场景解决方案

重点分析：

- 硬件商、集成商、算法商、运营方和客户的边界；
- 基础厂商和战略伙伴依赖、排他性与议价权；
- 场景数据、监管准入、数据权利和本地交付；
- 标杆案例能否跨客户和地区复制；
- 定制、7×24 小时运营、服务规模化和质保；
- 客户、地区、渠道和合作伙伴集中度；
- 标准解决方案包与一次性工程的区别。

## 科研成果转化

重点分析：

- 职务发明及高校、科研院所的所有权；
- 独占或非独占许可、期限、可转让性、地域、领域和终止条件；
- 改进成果和公司成立后发明的归属；
- 创始人全职状态、教学义务、竞业限制和控制权；
- 实验室结果、工程样机和生产验证的阶段差异；
- 科研经费、横向项目收入与商业产品订单的区别；
- 对共享实验室、学生、设备和机构品牌的依赖。
