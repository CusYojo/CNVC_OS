## 必须完成的分析链

投资版与投委会版使用以下逻辑：

```text
事实是什么
→ 为什么会改变客户行为或公司经营
→ 影响哪个财务变量
→ 如何改变投资主线或估值
→ 什么事实会使判断失效
```

将这条链写成自然叙述，不要逐项加标签。优秀答案不能只给产品分类或复述来源，而要解释经济后果。

可使用的财务和经营变量：

- 获客：线索质量、获客成本、销售周期、转化率；
- 变现：年合同额、模块增购、席位扩张、续费率；
- 交付：实施人天、定制比例、运维负担、人员利用率；
- 盈利：毛利率、算力成本、外包人力、经营杠杆；
- 现金：验收周期、应收账款、回款、营运资金；
- 壁垒：切换成本、数据权利、流程嵌入、定价权；
- 资本：库存、资本开支、研发强度、融资依赖；
- 估值：盈利质量、经常性收入溢价、集中度折价、期权价值。

## 投资争议型问题

问题必须包含足以改变决策的矛盾。优先从以下角度构造：

- 投资人真正购买的资产是数据、产品、渠道、客户关系还是交付能力？
- 专属产品改变了获客成本、客单价和续费，还是只改善了界面？
- 标杆案例证明了可复制性，还是仅证明单一客户愿意付款？
- 壁垒来自自有资产，还是依赖上游平台和公共模型？
- 用户规模能否转化为可触达的机构线索，还是不可变现的流量？
- 相邻产品是低成本交叉销售，还是争夺研发和交付资源的第二条业务线？
- 连续采购是自动续费、账户级复购，还是重复招投标？
- 哪项成本增长慢于收入，哪项成本仍与项目数量线性增长？
- 项目收入需要发生什么变化，才能获得软件质量的估值倍数？
- 哪项可观察结果会直接击穿投资主线？

投资版和投委会版至少一半问题应同时包含公司专属名词和经济张力。仅把公司名称加到“核心竞争力如何”中，不算专属问题。

## 从证据推演经营结果

把事实当作分析输入，而不是结论。

| 可观察事实 | 弱分析 | 投资分析 |
|---|---|---|
| 公开榜单产品关闭 | 转型已经启动 | 公司放弃低成本的产品驱动流量，转向销售驱动的机构获客；客单价上限提高，但销售周期和收入过渡风险同步上升。 |
| 同一客户连续两年采购 | 客户认可度较高 | 这属于账户级复购和预算留存，支持付费意愿，但不等于自动订阅续费。 |
| 产品包含看板、报告和 Agent 工作流 | 产品化方向明确 | 流程嵌入可提高切换成本和模块增购；真正价值取决于实施人天能否下降，而不是页面功能数量。 |
| 注册用户数量较大 | 获客潜力较大 | 经济价值等于目标机构占比×有效触达率×付费转化率×年合同额；缺少转化链时，用户数只是流量，不是 SaaS 规模。 |
| 接入第三方基础模型 | 技术能力较强 | 模型接入降低研发成本，但容易复制；壁垒必须位于数据权利、行业规则、评测、部署和工作流集成层。 |
| 采购包同时包含软件和服务 | 商业模式仍需观察 | 收入包含人力相关部分；只有单客户配置和交付人天下降，收入增长才会产生经营杠杆。 |

## 不用审计话术处理缺失信息

缺失信息只进入内部台账。正文描述可观察状态及其经营含义。

不要写：

> 由于续费率和标准产品收入占比未披露，本报告不使用纯 SaaS 估值框架。

改写为：

> 当前可识别合同以软件、数据和专业服务组合交付，收入增长仍会带动实施与研究人力。估值应先按利润和现金回收能力计量项目及服务收入，仅对合同中可识别的年度软件收入赋予软件溢价。

不要写：

> 迁移用户数和转化率未披露，因此转型结果未获公开证据证实。

改写为：

> 关闭公开榜单意味着获客方式从产品驱动转向销售驱动。新路径能否创造价值，取决于机构线索转化带来的客单价提升，能否覆盖更长销售周期与更高实施成本。

不要写：

> AiPin 产品化方向明确，但收入质量未获公开数据证实。

改写为：

> AiPin 已经从监测工具扩展到预警、研判和协同处置；只有规则、模板和 Agent 流程能够跨客户复用并减少实施人天时，功能扩展才会转化为更高续费和软件毛利。

使用以下边界表达方法：

- 锚定可观察的合同、案例、产品行为或客户动作；
- 使用“当前可识别”“现阶段呈现”“更接近”限定范围；
- 陈述条件性机制，不提出核验任务；
- 删除没有依据的精确数字，不解释数字为什么缺失；
- 把决定性缺口放入内部台账，不放入正文。

## 估值分层

把价值分为三层：

1. **当前盈利价值：** 项目、集成、研究、运营和专业服务收入，按照可持续利润和现金回收能力计量。
2. **经常性软件价值：** 可识别的年度许可、订阅、调用或合同化经常性模块，并根据续费、毛利和客户集中度调整。
3. **期权价值：** 智能体、数字人、新垂直行业、平台迁移和未签约产品线；形成可复制付费合同前，只作为上行期权。

必须说明收入为何归入某一层。不得对混合收入统一使用 SaaS 倍数。缺少精确数据时，只说明估值方向和结构，不得编造数字。

## 常见失败模式

出现以下模式时必须重写：

- 报告自述：“本报告认为、不认为、不判断”；
- 缺数自述：“由于未披露、无法获取、公开证据不足”；
- 标签式结论：“产品化方向明确”，但没有单位经济分析；
- 堆砌若干来源，却没有因果推论；
- 只写“直接影响估值”，不说明影响哪个变量；
- 用“一方面、另一方面”对称表述逃避主次判断；
- 问题可以不加修改地用于任何公司。

每个投资版和投委会版答案完成前，检查：

```text
删除证据免责声明后，是否仍有清晰判断？
读者能否说出受影响的经营或财务变量？
答案是否解释事实为什么会改变该变量？
估值处理是否与收入和交付方式一致？
是否只保留优先级最高的失效条件？
```
