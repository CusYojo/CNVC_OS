# 参考稿逐页学习与要求核对

## 原则

参考稿不是主题文件，而是设计与叙事证据。必须先回答“它为什么有效”，再把方法迁移到目标公司。不要只抽一个配色或字体，也不要逐页像素照抄。

## 逐页审计表

对参考稿每一页记录：

| 维度 | 要观察的问题 |
|---|---|
| 页面角色 | 行业定义、机制、产品、案例、财务、交易还是结论？ |
| 行动标题 | 是标签还是完整陈述？标题承担多少论证？ |
| 阅读起点 | 3 秒先看到图、标题、数字还是案例？ |
| 阅读路径 | 左→右、上→下、中心扩散、闭环或时间推进？ |
| 主视觉动作 | 照片、流程、迁移、瀑布、表格、案例还是时间轴？ |
| 信息密度 | 正文多少、图注多少、留白是否有功能？ |
| 视觉区域 | 实际有几块等权区域？是否存在主从？ |
| 表格/线条 | 用于比较/连接，还是仅作装饰？ |
| 图片角色 | 证据、场景、产品说明还是纯装饰？ |
| 语言 | state/explain、路演推销、审议判断还是公司宣传？ |
| 证据 | 来源、口径、日期如何呈现？ |
| 转场 | 与前后页如何连接？ |

完整审计后，提炼 5–10 条“可迁移语法”，例如：行业页先解释工作流再给市场数字；案例页用过程而非 Logo；密集表格只在财务出现；标题直接给结论；照片配图注。

## 候选稿与参考稿比较

不要问“像不像”，要在相同缩放或同 DPI 接触表上比较：

1. 章节层级与页数节奏。
2. 每页信息岛数量。
3. 主体字号与投屏可读性。
4. 页面密度分布是否稳定。
5. 母型多样性与重复率。
6. 表格/卡片/流程/照片的占比。
7. 行业、产品、案例、商业、财务、交易的解释深度。
8. 标题能否单独构成完整故事线。
9. 是否过度用颜色、框线和巨型数字强调。
10. 是否离开 Word 仍可理解。

若候选稿“很空”，先比较正文尺度、有效内容区、解释性文字和图片占比；若“很乱”，先比较信息岛数量和主次，而不是先减字。

## 对制作要求逐条验收

将用户给出的制作要求转成可勾选清单，不只在最后泛泛回忆：

- [ ] 面向投委会，不是融资路演/公司宣传册。
- [ ] 项目资料为主体，公开资料有来源。
- [ ] 每页一个核心结论。
- [ ] 不用四模块模板强分无关信息。
- [ ] 先决定投资人应理解什么，再选视觉形式。
- [ ] 案例、流程、财务、估值、交易、风险按内容使用不同构成。
- [ ] 风格统一但版式有变化。
- [ ] 文字、图表、流程和表格可编辑。
- [ ] 投屏/100% 缩放可读。
- [ ] 无溢出、覆盖、错位、低清图片、字体替换和误导图表。

## 差异报告的写法

向用户说明差异时必须具体到页和视觉现象，如“P7 三个等权框导致主结论不清”“P13 参考稿使用单条流程，我们用字段表导致阅读路径断裂”。不要只说“AI 味重”“不够高级”。给出根因、修改动作和预计效果。

## 参考边界

可以迁移：栅格、节奏、信息结构、视觉动作、图表语法、图文比例、来源系统。不可直接复制：Logo、品牌纹样、摄影、受版权保护的专有插图、公司事实和未经授权的整页设计。
