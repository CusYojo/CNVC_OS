# 证据、数据与口径规范

## 证据等级

### A 级：可验证正式证据

包括审计/财务报表、银行流水、合同与发票、工商与监管文件、客户书面确认、正式交易文件、政府或权威数据库。可以用确定陈述，但仍要标明日期、主体和口径。

### B 级：公司或管理层材料

包括 BP、内部报表、访谈纪要、预算、项目清单、技术文档、管理层提供的客户反馈。用“据公司材料/管理层口径”标示，不能自动升级为已审计事实。

### C 级：意向、线索与推断

包括销售管线、合作意向、公开新闻线索、行业推断、研究者测算。用“意向”“潜在”“预计”“据公开信息推断”等明确边界。C 级证据可以解释方向，不能当作收入或合同落地。

## 关键概念不可混用

- 意向 ≠ 订单。
- 订单 ≠ 合同额确认。
- 合同 ≠ 已执行收入。
- 收入 ≠ 回款。
- 客户数量 ≠ 复购客户数量。
- 管理层目标 ≠ 基准预测。
- 公共报道 ≠ 客户验证。
- 融前估值、投后估值、交易对价、公司新增现金不是同一个数。

## 数字字段最低要求

每个重要数字至少配：数值、单位、期间/截至日期、口径、实际/预测、来源等级。图表标题或脚注应能够回答“这是什么数”。

示例：

- 不充分：`收入 3,000 万`。
- 充分：`2025 年营业收入 3,000 万元（不含税，管理层初步口径，B）`。

## 必做交叉校验

### 财务

- 收入 − 营业成本 = 毛利润。
- 毛利润 ÷ 收入 = 毛利率。
- 现金变化与回款、融资、支出方向相容。
- 历史期与预测期边界清晰。
- 同一年度在不同页面使用同一口径。

### 订单与客户

- 客户数、合同数、项目数、设备数不混用。
- 签约额、执行额、确认收入、回款额分别汇总。
- 复购必须能识别同一客户的第二次真实购买或扩单。
- 管线按阶段分层，并对转化概率或不确定性作说明。

### 融资与股权

- 融前估值 + 新增投资 = 投后估值（无特殊结构时）。
- 投资金额 ÷ 投后估值与新增持股比例相容。
- 老股转让、增资、期权池、可转债分开建模。
- 各股东比例合计与四舍五入误差合理。

### 市场与行业

- TAM/SAM/SOM 的范围、地区、年份和计算方法明确。
- 市场规模预测不与公司收入预测混为一谈。
- CAGR 的起止年份与公式一致。
- 不用来源不明的“大市场”数字充当核心论据。

## 预测表达

将预测分为：管理层目标、基准情景、保守情景、上行情景。每种情景说明驱动因子，如交付数量、单价、复购、毛利率、人员与研发投入。不要只画一条光滑上升曲线。

预测页应回答：增长从哪里来、哪个假设最敏感、已有订单能覆盖多少、尚未验证的环节是什么。保持 explain 语气，不写“空间巨大、确定性极强”。

## 缺失数据

无法获得详细财报或客户验证时：

1. 明确公开数据边界。
2. 用现有可验证数字构建最小事实集。
3. 把缺口变成尽调问题或后续验证事项。
4. 不用同业平均数伪装成公司数据。
5. 必要时减少财务结论强度，而不是填充虚构数字。

## 页面脚注

推荐使用 `[A]`、`[B]`、`[C]` 或更具体的来源编号。正文中需要区分证据强度时就近标注，页脚列出资料名称与日期。来源字号可小于正文，但投屏 100% 仍应辨认；不要压成装饰性灰线。
