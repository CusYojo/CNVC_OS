# 版式母型库

母型是信息语法，不是可反复填空的模板。每页先确定“读者需要看见什么关系”，再选母型。同一套 PPT 建议使用 6–10 种母型，保持字体、边距、色彩和页脚一致。

## 1. 图像 + 解释链

适用：行业场景、产品用途、客户工作流。

结构：一张高相关大图占 35%–50%，另一侧是一段导语 + 3–4 个解释节点，底部用短路径或结论收束。不要把解释节点做成四张独立卡片。

## 2. 源头变化 → 行业结果

适用：行业为什么现在发生变化。

结构：左侧或上方说明过去约束，中间用时间/技术/成本变化，右侧落到客户工作流或市场新需求。市场规模只是其中一项证据，不是页面唯一主角。

## 3. 瓶颈对照

适用：数据数量 vs 可用性、视觉 vs 触觉、单点工具 vs 完整链路。

结构：两条连续区域共享一个标题和底部结论，比较维度对齐。避免两个大卡片各讲一套无关内容。

## 4. 连续能力栈

适用：多层产品/技术架构。

结构：自下而上或自左向右的连续层，标明商业化顺序、数据流或依赖关系。使用细分隔与标注，不用四块等权矩形。

## 5. Real–Sim–Real / 反馈闭环

适用：数据采集、仿真生成、训练、真机验证、失败样本回流。

结构：主路径占页面中部，回流路径清楚但不与文字相交；用位置和色彩区分真实/仿真阶段。中心模块不得过度突出导致两端失衡。标签、箭头和说明保持统一基线与间距。

## 6. 客户案例叙事

适用：验证、复购、交付结果。

结构：客户起点 → 问题/需求 → 公司交付 → 结果 → 后续复购/扩展。可以加入照片、订单/回款数据和现场反馈，但围绕一个案例结论。多个案例时使用并行泳道或共性路径，不做 Logo 墙。

## 7. 商业接力

适用：硬件入口、数据复购、训练复用、模型授权等多阶段收入。

结构：用接力/阶梯/路径表达前一环节如何生成后一环节的资产或收入。每步同时说明交付物、付费主体和可重复性。

## 8. 收入结构迁移

适用：历史到预测、一次性收入到复购/服务收入。

结构：堆叠柱、河流图或阶段带；每个期间必须有年份、总值、实际/预测标记。旁边解释结构变化的业务原因，不能只画柱子。

## 9. 经营质量桥

适用：收入 → 毛利 → 费用 → 经营结果，或订单 → 交付 → 收入 → 回款。

结构：真正的瀑布/桥接，正负方向正确；或明确命名为“核心经营指标”，不要把向上柱误称价值桥。主图旁保留口径和变化原因。

## 10. 订单确定性漏斗

适用：线索、意向、订单、交付、收入。

结构：按阶段缩减的漏斗或流量路径，明确每层口径、金额/数量和日期。不能把所有管线合成“订单”。

## 11. 交易资金流

适用：增资、老股、期权池、融资前后估值。

结构：资金从投资方到公司/老股东的流向 + 融资前后所有权变化。把估值、投资额、持股比例放在路径节点内，不用纯字段表。

## 12. 治理与里程碑路线图

适用：董事会席位、关键条款、资金用途、投后验证。

结构：按时间/责任主体排布，节点说明决策或验证，不要做五张相同卡片。可以使用双泳道：公司执行与投资人治理。

## 13. 团队能力来源

适用：核心创始人、科研背景、产业经验。

结构：人物照片/姓名只是入口，重点用经历 → 能力 → 当前职责 → 与公司问题的连接。避免整页证件照和履历表。

## 14. 审议摘要与结尾

适用：开头总览、最后决策落点。

结构：单一主结论 + 一条贯穿全稿的证据链。开头可以是行业变化 → 公司路径 → 商业验证 → 交易状态；结尾可以是已验证 → 本轮交易 → 下一阶段里程碑。不要做四宫格 SWOT 或“感谢聆听”。

## 表格何时保留

只有当读者需要沿行/列精确比较多项同构信息时使用表格，如多年财务、股东清单、同行参数。减少外框与竖线，用字重、底色、缩进和少量横线建立层级。表格右端线条不得多伸出，文字与分隔线需留安全距离。

## 母型选择问句

- 是时间变化吗？用时间轴/迁移。
- 是因果或流程吗？用路径/闭环/泳道。
- 是组成关系吗？用堆叠/结构带。
- 是正负贡献吗？用瀑布。
- 是阶段筛选吗？用漏斗。
- 是资金/股权流向吗？用资金流/所有权桥。
- 是精准多维比较吗？才用表格。
