# 输入资料与来源审计

## 资料盘点

递归列出文件并按类型建立索引：DOCX、PDF、PPTX、XLSX/CSV、图片、网页快照、压缩包、音视频和邮件记录。对压缩包先解压到项目工作区，保留原包只读。

记录每个文件的名称、日期、作者/主体、版本、是否正式、与公司/行业/交易的关系、是否含敏感信息。

## 读取策略

### Word

抽取段落、标题、表格、页眉页脚、批注和图片说明；同时渲染页面检查视觉层级。若用户指定某个 Word“为准”，它是内容基准，但新增尽调可补充或纠正，修改必须留下来源。

### PDF

先检查是否可搜索；扫描版做 OCR。内容审计用文本抽取，视觉学习用逐页渲染。参考 PDF 的价值在于：每页讲什么、信息如何展开、标题如何陈述、图文比例、表格/流程使用频率、来源与页脚习惯。

### PPTX

抽取每页文本、备注、图片数量、字体、字号、位置和母版；再用 PowerPoint 原生 PDF 查看真实换行和渲染。不要只看幻灯片缩略图。

### 表格

保留原始工作簿，另建只读快照或抽取表。记录单位、币种、税口径、期间、实际/预测、合并/单体。不要把格式化百分比当原始值。

### 图片

区分公司自有、公开报道、示意图、图库和生成图。Logo/产品照片优先来自公司或官方主体。行业背景图可以使用相关公开素材，但要记录来源，避免同一图片在多页重复形成模板拼装感。

## 网络补充

只有在项目资料不能解释行业、产品或关键事实时联网补充。优先级：监管/政府/标准组织 → 公司与客户官网 → 论文/专利 → 权威研究机构 → 主流媒体。模板和设计站仅用于视觉灵感，不能作为业务事实来源。

为每条网页记录：标题、URL、访问日期、支持的具体句子/图表、是否为推断。引用必须靠近对应页面内容。

## 冲突处理

常见冲突包括：不同版本收入、订单口径、客户数量、估值、股权比例、融资前后金额、预测期间。处理方式：

1. 不覆盖旧值，保留来源与日期。
2. 判断是否是时间更新、含税/不含税、签约/执行、集团/主体、实际/预算等口径差异。
3. 选择最接近汇报日期且最正式的口径。
4. 在 PPT 中用简洁脚注解释，不把争议隐藏。
5. 无法确认时标记“待核验”，而不是猜一个更顺眼的数字。

## 内容保留审计

把基准 Word/框架中的所有金额、百分比、数量、日期、客户/订单/项目名称、关键限定词、商业模式、技术路径、团队履历、股权交易条款、风险与后续验证事项加入指标清单。

PPT 可以改写和合并，但每项必须在逐页蓝图中标记去向。删除时记录原因：重复、过时、错误、与投委会问题无关或证据不足。

## 保密与可复用边界

技能包可保存方法、模板和经用户授权的示例；不要把其他项目的隐私材料、未公开客户名单或交易数据复制进通用资产。公开示例仍需保留来源和版权边界。
