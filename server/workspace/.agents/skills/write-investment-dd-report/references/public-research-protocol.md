# 公开信息穷尽检索规范

## 适用范围

当报告使用公开信息、融资材料或管理层口径，或者涉及可由外部来源核实的主体、团队、产品、客户案例、融资、知识产权、合规及竞争事实时，必须执行本规范。公开检索的目标是补足外部事实，不是伪造私有财务、合同或银行数据。

## 检索顺序

每个重大投资问题至少覆盖以下来源中的三类；主体、融资、客户案例和知识产权必须优先使用一手来源：

1. 公司官网、产品官网、官方文档、备案页和官方账号；
2. 国家企业信用信息、公示备案、监管、法院、知识产权、招投标及政府采购平台；
3. 客户、供应商、合作方、产业方和投资机构官网；
4. 主流媒体、专业媒体及可识别作者的访谈；
5. 云市场、应用市场、开发者平台和产品价格页；
6. 行业政策、技术标准、学术论文和权威研究。

不得把多个转载同一稿件的页面视为独立交叉验证。公司宣传稿只能证明公司作出过该项陈述；客户或合作方官网对项目、部署或成果的描述，证据等级高于公司自述。

## 必须覆盖的八个问题域

- 主体：成立时间、注册资本、法定代表人、经营地址、备案与关联主体；
- 团队：核心人员、公开任职、机构背景和交叉任职；
- 产品：功能、上线时间、运营主体、收费入口、备案及版本更新；
- 客户与案例：客户或合作方名称、项目时间、交付内容、运营主体及成果；
- 融资：轮次、投资方、时间及投资机构对项目的公开说明；
- 知识产权：专利、商标、软著、域名、算法备案及权利主体；
- 合规：适用监管、备案、许可、司法和行政记录；
- 市场与竞争：可比产品、收费方式、行业变化及客户替代方案。

对每个问题域至少设计两个不同目的的查询：一个实体精确查询和一个“实体+字段事项”查询。例如：`"公司全称" 股东`、`"公司全称" 注册资本变更`、`"产品名" 客户`、`site:客户官网 "公司简称"`、`"公司全称" 专利`。每个查询必须绑定 `field_ids`，不能只标记到宽泛的问题域。

最低字段覆盖见 [diligence-data-schema.md](diligence-data-schema.md)。例如，主体域必须分别覆盖 `entity.basic_registry` 和 `ownership.public_ownership`；知识产权域必须覆盖 `product.ip_schedule`；市场与竞争域必须覆盖 `market.competitor_matrix`。

## 研究日志

在任务目录建立 `public-research.json`，记录：

- 法律主体、截止日期；
- 查询 ID、问题域、目标字段 `field_ids`、检索式、检索日期、结果数量和采用的来源 ID；
- 来源 ID、标题、发布方、网址、发布日期、访问日期、来源等级和绑定主体；
- 每条来源的 `supports` 使用结构化对象，逐项记录 `field_id`、原子事实 `claim` 和 `as_of_date`；不得用“支持公司情况”“支持产品矩阵”等宽泛文字代替；
- 每个问题域的处理结果：已找到可靠事实、检索无结果、与其他来源冲突或不适用；
- 每个处理结果绑定具体 `field_ids`；对正文的处理只能为直接事实、分析依据、估值处理、交易条件或省略。

执行：

```bash
"$DD_PYTHON" "$DD_SKILL_ROOT/scripts/audit_public_research.py" public-research.json
```

报告主要依赖公开信息时，审计必须为零错误、零警告后才能起草正文。

## 从检索结果到投资语言

正文只写四类内容：已观察事实、商业机制、财务或估值后果、交易安排。检索没有找到某项私人数据时，不得把检索失败写成报告内容。

错误：

> 本报告基于公开资料编制，未获取客户台账和银行流水，当前不具备形成投资结论的条件。

专业表达：

> 公司已形成机构项目交付和标准化产品入口。本轮按投资主体可归属的合同毛利与回款定价，平台化业务仅在复购、贡献毛利和履约效率达到约定门槛后释放估值。

错误：

> 公开信息未显示关联交易，实验室与公司之间的人员、设备、数据和知识产权关系需厘清。

专业表达：

> 公司技术与高校团队保持紧密协同。交易文件应将核心人员服务、职务成果归属、数据授权和设备使用边界一次性固化；未由投资主体控制的成果不进入估值，交割后新增成果按协议自动归集。

错误：

> 产品—市场匹配尚未确立，建议补充运营数据后再评估报价。

专业表达：

> 当前商业证据集中在项目交付和产品上线，报价以已实现合同毛利和现金回收为锚；平台交易密度、复购和履约效率达到约定指标后，通过下一期投资释放平台溢价。

## 不可替代边界

网络检索不能创造审计财务、银行流水、完整客户台账、未公开合同条款或资本化表。遇到这类私有数据时：

1. 使用已核实的外部经营代理指标形成阶段判断；
2. 缩窄估值口径，不把远期或关联方价值计入本轮价格；
3. 用分期投资、可转安排、价格调整、交割条件和终止权控制风险；
4. 将具体资料请求保留在内部工作底稿，不写进投资概要和结论。
