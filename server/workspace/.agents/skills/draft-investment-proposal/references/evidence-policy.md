# 项目与联网 Evidence 契约

## 来源优先级与边界

使用当前任务、当前 `projectId` 且不晚于 `sourceCutoffDate` 的授权资料，并通过联网检索补充公开信息。冲突时按以下优先级组织，不得静默覆盖：

1. 用户在本次任务中明确给出的项目数据和事实，来源名为`用户补充输入`；
2. 当前项目结构化字段；
3. 当前项目授权档案和知识库；
4. 联网公开信息和检索记录；
5. 基于以上证据形成的审慎分析。

模板只提供结构、格式和风格，不能进入 Evidence。其他项目和模型训练知识不得补齐当前项目事实。联网公开信息只作为`待核验`线索，不能替代工商底档、合同、审计报告、交易文件等原始证据。

进入 RAG 前排除模板文件、非当前项目资料、越期资料、重复/测试/占位/损坏片段、主体无法对应当前项目的孤立事实。公开网页必须保留 URL 或可追溯标识；`待核验`占位值本身不是证据。

联网检索固定覆盖公司基本情况、核心团队、股权与融资、产品技术、客户运营、财务、本轮交易、预测退出、行业可比和风险合规。每个主题保留检索式、结果数量和日期；联网服务全部失败时终止任务，不继续生成。

## 章节 Evidence Packet

为 14 个叶子节点独立评分并选取最多六个片段，同一来源最多三个片段。表格章节优先使用结构化财务、融资、估值、股权或预测资料。

每个 Packet 保留：

- 全局 source index；
- source name/type/id；
- 片段 locator；
- 版本或日期；
- 用于生成的原文；
- 章节覆盖状态。

一个事实只能引用当前节点 Packet 中的来源。亮点、风险和结论可以综合前文证据，但仍需在自身 Packet 中显式提供相应来源。

## 事实、数字与分析

- 直接事实需有证据明确支持主体、动作、时点和口径。
- 数字必须逐字存在于引用原文；不得擅自计算 IRR、MOIC、增长率、比例、市场规模、估值或预测。
- 分析只能说明已引事实的含义、条件、影响和约束，用户可见状态为`分析判断`。
- 仅由`public_web`来源支持的正文和表格一律标记`待核验`，不得升级为`资料记载`或`分析判断`。
- 公司自述、管理层预测、意向订单、框架协议、未审计财务和拟议条款应标记`待核验`或条件性`分析判断`。
- 竞争优势需有专利、客户、性能、成本、交付或第三方验证等项目证据，不得把自述升级为客观领先。
- 融资用途不得从融资金额反推；风险不得虚构已发生事件。

## 冲突与缺口

来源冲突时并列披露双方口径、日期和来源，标记`待核验`，并说明需要核对的原始文件。不得私自选取更有利的数据。

公开检索已执行但未发现可直接引用结果时，引用该主题的检索记录，输出`待核验`事项，说明不能据此证明事项不存在，并列明应取得的原始资料。

项目证据和联网检索记录均不可用时，不生成安全缺口文档，直接终止并提示恢复联网服务或补充项目资料。不得用模板事实、模型常识、无来源行业平均值或“合理假设”代替。
