# 决策级内容标准

## 投资闭环

全文必须让投委会在一次阅读后回答五个问题：

1. Why now：需求、政策、技术或供给在什么时点发生变化。
2. Why company：当前公司相对替代方案的项目特定优势是什么。
3. Why price：本轮价格由哪些已核验指标、历史融资、风险折扣和交易工具支撑。
4. Value creation：投资后哪三至五个里程碑会提高收入质量或估值。
5. Downside：哪些事实不成立会使项目退化，以及如何通过价格、付款、治理或终止控制。

## 八项覆盖

| 主题 | 必须回答 |
|---|---|
| commercialization | 收入构成、客户集中、合同—交付—验收—开票—回款、客单价、毛利、复购、销售周期 |
| financials | 历史三表、现金余额、月度消耗、应收账龄、费用结构、预测假设和盈亏平衡 |
| technology | 产品名称、可复测指标、成熟度、成本/效率、知识产权、代码/模型/数据归属 |
| market_competition | 市场边界、买方预算、替代方案、竞争主体、差异和可比选择逻辑 |
| cap_table | 股东、控制权、期权池、代持/质押、特殊权利、历史变更和完全稀释口径 |
| transaction | 金额、工具、投前/投后、价格、股比、用途、交割、治理和保护条款 |
| returns | 持有期、退出路径、后续融资稀释、退出估值/倍数、MOIC、IRR 和下行情景 |
| team | 核心职责、全职投入、互补性、激励、关键人依赖和成果归属 |

每项状态只能是 supported、partial 或 gap。gap 必须同时给出 missing、impact、action 和 transaction_response；只写“待核验”不合格。

## 内容密度

- 开篇两段内写清主方案和授权边界。
- 一个段落只承担一个中心意思；同一缺口不跨章重复。
- 公司、团队、产品和运营写事实，避免每段追加尽调建议。
- 风险控制章节写合同与治理工具；风险提示章节写业务触发情形及影响，两者不得重复条款全文。
- 结论用可执行边界收束：最高金额/估值或价格、最低权益、付款节点、关键治理权、不可豁免条件和终止条件。

## 缺口的正确形态

错误：`财务资料不足，建议进一步核查。`

正确：`2025年营业收入存在1,000万元和1,381万元两套口径，且合同额、验收、开票和回款未完成勾稽，当前收入质量不能作为5亿元投后估值的单独依据；交割前应由会计师核对总账、合同、验收单、发票和银行流水，未达到约定口径时相应调减估值或后续付款。`

## 计算与情景

机械派生值可以计算，但必须披露公式。情景值允许作为投资分析，不得伪装成证据。基础、审慎、乐观情景至少改变退出收入/倍数、持有期或后续稀释中的两个变量，并计算 MOIC/IRR；输入不足时明确哪个变量缺失以及它如何影响授权边界。
