# 不可变 Document Blueprint

## 固定块

开篇顺序固定为：主标题、`各位投资决策委员会成员：`、当前项目提案说明、审议授权边界。结尾顺序固定为：条件式结论、`浙江赛智伯乐股权投资管理有限公司`落款、年月、`免责声明及风险提示`、`引用资料`。

固定无资料文本为：`当前项目暂无相关资料。`

## 章节树

以下 28 个节点的标题、编号、层级和顺序不可改变：

1. `一、基本情况简介`
   1. `（一）公司简介`
   2. `（二）核心团队`
   3. `（三）公司股权结构`
   4. `（四）产品及技术`
   5. `（五）运营摘要`
      1. `1. 商业模式分析`
      2. `2. 竞争优势分析`
   6. `（六）财务摘要`
2. `二、交易条件`
   1. `（一）历史融资情况`
   2. `（二）本轮公司估值和投资方案`
      1. `1. 融资用途分析`
   3. `（三）风险控制及保护性条款`
      1. `1. 回购权`
      2. `2. 优先清算权`
      3. `3. 其他保护性条款`
3. `三、公司业务计划`
   1. `（一）经营预测与回报测算`
   2. `（二）市场空间分析`
   3. `（三）可比公司估值比较`
4. `四、项目亮点总结`
   1. `（一）投资逻辑分析`
   2. `（二）投资亮点总结`
5. `五、风险提示与对策`
   1. `（一）风险自动归纳`
   2. `（二）风险应对与核验措施`
6. `六、结论`

前五个一级章是结构容器，只输出标题；`六、结论`承载结论正文。三个带三级子节点的二级章仍须承载自身概览：`（五）运营摘要`写运营事实，`（二）本轮公司估值和投资方案`写交易概览和投资方案表，`（三）风险控制及保护性条款`写整体保护安排；其三级子节点分别承载专项分析，不得重复父节内容。

## 七项必做分析

商业模式、竞争优势、市场空间、融资用途、投资逻辑、投资亮点和风险归纳必须各自出现在上述固定节点。必做不等于允许猜测：没有章节 Evidence 时仍保留节点并明确写`当前项目暂无相关资料。`

## 表格槽位

- 公司股权结构：股东、出资/股份、持股比例。
- 财务摘要：期间、收入、成本/毛利、净利润，注明单位及是否审计。
- 历史融资：时间、轮次、金额、投后估值、投资方。
- 本轮投资方案：投资形式、金额、投前/投后估值、股比。
- 经营预测与回报：年度、A/E、收入、利润、退出估值/倍数。
- 可比公司估值：公司、数据时点、口径、市值/估值、核心倍数。

无同口径结构化 Evidence 时不创建表格。

## 标题

默认主标题为`关于对[目标公司]实施股权投资的提案`。只有当前项目 Evidence 明确给出投资主体时，才可使用`关于[投资主体]对[目标公司]实施股权投资的提案`。不得猜测基金名称。
