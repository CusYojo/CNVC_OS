# 不可变 Document Blueprint

## 固定块

开篇顺序固定为：主标题、`各位投资决策委员会成员：`、当前项目提案说明、审议授权边界。

结尾顺序固定为：条件式结论正文、机构落款、年月。此后不得增加`免责声明`、`引用资料`或其他模板外板块。

默认主标题为`关于对[目标公司]实施股权投资的提案`。仅当证据明确给出投资主体时，可使用`关于[投资主体]对[目标公司]实施股权投资的提案`。固定无资料起始文本为`当前项目暂无相关资料。`

## 标准 17 节目录

以下标题、编号、层级和顺序不可改变：

1. `一、基本情况简介`（容器）
   1. `（一）公司简介`
   2. `（二）核心团队`
   3. `（三）公司股权结构`
   4. `（四）产品及技术`
   5. `（五）运营摘要`
   6. `（六）财务摘要`
2. `二、交易条件`（容器）
   1. `（一）历史融资情况`
   2. `（二）本轮公司估值和投资方案`
   3. `（三）风险控制及保护性条款`
3. `三、公司业务计划`（容器）
   1. `（一）经营预测与回报测算`
   2. `（二）可比公司估值比较`
4. `四、项目亮点总结`
5. `五、风险提示与对策`
6. `六、结论`

前三个一级章是容器，只输出标题；其余十四个节点均为叶子并承载内容。标准树不增加三级标题。

## 章节任务

| 叶子章节 | 必须回答 |
|---|---|
| 公司简介 | 主体是谁、做什么、成立/发展阶段、核心业务与基本资质 |
| 核心团队 | 核心成员、职责、经验、互补性、稳定性与关键人风险 |
| 公司股权结构 | 股东、持股、控制关系、历史变化及待核验事项 |
| 产品及技术 | 客户问题、产品方案、技术路径、成熟度、知识产权与壁垒 |
| 运营摘要 | 获客、订单、交付、生产/服务、变现、客户集中与运营指标 |
| 财务摘要 | 历史收入、利润、现金流、资产负债、口径、审计状态和异常 |
| 历史融资情况 | 时间、轮次、金额、估值、投资方、工具和历史条款 |
| 本轮公司估值和投资方案 | 金额、投前/投后估值、投资工具、股比、资金用途和交割安排 |
| 风险控制及保护性条款 | 先决条件、陈述保证、治理权、反稀释、回购/退出等保护安排 |
| 经营预测与回报测算 | 历史/预测分离、关键假设、预测区间、退出口径、回报与敏感性 |
| 可比公司估值比较 | 可比逻辑、数据时点、估值口径、关键倍数、差异和局限 |
| 项目亮点总结 | 证据支撑的亮点、投资含义、成立条件及与前文的对应关系 |
| 风险提示与对策 | 每项风险的触发条件、潜在影响、缓释/核验动作、责任主体和时点 |
| 结论 | 条件式建议、前置条件、关键待核验事项和授权边界 |

## 表格槽位

- 公司股权结构：股东、出资/股份、持股比例。
- 财务摘要：期间、收入、成本/毛利、净利润、现金流，注明单位和审计状态。
- 历史融资：时间、轮次、金额、投后估值、投资方、工具。
- 本轮投资方案：投资形式、金额、投前/投后估值、股比、资金用途。
- 经营预测与回报：年度、A/E、收入、利润、退出估值/倍数、回报指标。
- 可比公司估值：公司、数据时点、口径、市值/估值、核心倍数。

无同口径结构化证据时不创建表格。
