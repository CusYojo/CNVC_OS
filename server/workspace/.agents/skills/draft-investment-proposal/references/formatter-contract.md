# Formatter 与 Word 契约

## 页面与字体

| 角色 | 固定值 |
|---|---|
| 页面 | A4 竖版，11906 × 16838 DXA，单节 |
| 页边距 | 上 1440、右 1800、下 1440、左 1800 DXA |
| 页眉/页脚距离 | 各 720 DXA |
| 主标题 | 16 pt，黑体，加粗，居中 |
| 一级标题 | 14 pt，黑体，加粗，Heading1 |
| 二级标题 | 14 pt，楷体，Heading2 |
| 三级标题 | 12 pt，仿宋，加粗，Heading3；标准树不创建 |
| 正文 | 12 pt，仿宋，两端对齐，首行缩进 480 DXA |
| 段落 | 固定 24 pt 行距（480 twips），段前段后 0 |
| 表题 | 12 pt，仿宋，加粗 |
| 表格 | 10.5 pt，仿宋；表头加粗、D9D9D9 灰底、黑色边框 |
| 注释/引用 | 10.5 pt，仿宋 |
| 页眉 | 10.5 pt，宋体，机构名称居中，下方细黑线 |
| 页脚 | 10.5 pt，Times New Roman，PAGE 域居中 |

中文字体不可用时可使用受控字体映射，但层级、字号和黑白公文式视觉必须保持。

## 固定格式

- 页眉为受控机构名称，默认`浙江赛智伯乐投资管理有限公司`。
- 页脚为居中 PAGE 域。
- 不创建独立封面；主标题在正文首段自然换行。
- 不创建独立目录页或模板外 TOC 域。
- 正文自然流排；标题与下一段同页，表格行不得跨页拆分。
- 保持中文编号`一、`、`（一）`，不得转为自动英文编号。
- 文末依次为机构落款和日期，此后不得生成`免责声明`或`引用资料`板块。
- 实际使用的项目来源、文件标识、资料日期和核验状态写入任务来源表及产物审计元数据，不在正文末尾重复列示。
- finding 与表格的证据状态仅供内部审计，正文和表格附近不得渲染`〔资料记载〕`、`〔分析判断〕`、`〔待核验〕`、`〔资料缺口〕`或同义状态标签。
- Formatter 在写入 DOCX 前必须清除并拒绝 Evidence、文件名、资料库、项目资料、会议纪要、原始文件、检索路径、来源类型和核验过程等内部措辞；不得通过脚注、批注、表格备注或隐藏文本泄露。
- Formatter 必须先规范化中文排版空格再创建 TextRun，覆盖正文、表题、表头和全部表格单元格；Word Reviewer 发现异常空格时必须阻断交付。

## 表格

表格必须是 Word 原生可编辑表格，固定总宽 8306 DXA、固定布局、2–8 列。表头重复显示，行禁止跨页拆分，不设置导致文本裁切的固定行高。无结构化 Evidence 时不创建空表。

## Word

必须设置真实 Title、Heading1、Heading2、Heading3 样式、可编辑正文和表格、无损 Unicode 中文、A4 几何、页眉、页脚和 PAGE 域。`updateFields=true`可以保留以更新页码，但不得包含目录域。

Formatter 输入前必须完成正文净化：去掉 Markdown、PDF/PPT 页码、页眉页脚、目录导航、孤立编号和粘连目录串，并修复 `AI- Core- Tech`、`C OO`、`4 D` 等可确定的断词。核心团队和产品及技术只渲染完整段落或原生表格，不把幻灯片字段、标签和目录编号直接拼进段落。

不得复制会与运行时冲突的模板样式部件；依据受控令牌安全重建。

## 单产物交付

投资提案只生成、登记并交付一份 DOCX。不生成或登记 PDF、Markdown、PPT/PPTX、重复 DOCX 或预览产物；版式与内容质量直接由 Word Reviewer 校验。
