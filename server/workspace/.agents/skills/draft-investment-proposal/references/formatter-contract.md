# Formatter 与 Word 契约

当任务要求复刻案例时，先完整执行[案例精确版式契约](exact-case-style.md)。下列通用值只适用于没有用户指定案例的任务，不得覆盖案例权威。

## 页面与字体

| 角色 | 固定值 |
|---|---|
| 页面 | A4 竖版，11906 × 16838 DXA，单节 |
| 页边距 | 上下 1440、左右 1800 DXA |
| 页眉/页脚距离 | 各 720 DXA |
| 主标题 | 16 pt，黑体类字体，加粗，居中 |
| 一级标题 | 14 pt，黑体类字体，加粗，Heading1 |
| 二级标题 | 14 pt，楷体类字体，Heading2；视觉上不得与正文相同 |
| 正文 | 12 pt，仿宋类字体，两端对齐，首行缩进 480 DXA |
| 段落 | 固定 24 pt 行距，段前段后 0 |
| 表题 | 12 pt，仿宋类字体，加粗；默认自然引导，不机械添加“表1” |
| 表格 | 10.5 pt，仿宋类字体 |
| 页眉 | 10.5 pt，宋体类字体，机构名称居中，下方细黑线 |
| 页脚 | 10.5 pt，Times New Roman，PAGE 域居中 |

字体按角色选择受控候选：黑体类、楷体类、仿宋类、宋体类分别映射，禁止因为缺少某个字体而把二级标题和正文映射为同一字体。渲染后以视觉层级为最终 oracle。

## 表格

- 跨模板复用表格组件时，样式ID不是全局标识。先验证源样式的`w:type`，将辅模板样式复制到主模板中的唯一ID，再让`tblStyle`引用该ID；禁止引用同名或同号但类型不同的样式。
- 所有生成表格必须写入`tblGrid`、各单元格`tcW`和`tblLayout=fixed`，确保列宽计划在Word/WPS/LibreOffice中保持一致。

每张表必须携带 `style`、`caption_policy` 和 columns 中的 `role`、`width_weight`。合法 role：`label`、`date`、`numeric`、`percent`、`narrative`、`status`。

- `grid`：表头加粗、D9D9D9 或模板主权威 C0C0C0 灰底、0.5 pt 黑色全框线。
- `three-line`：白底表头、表顶线、表头下线和表底线，不使用竖线；适用于财务、预测和回报数据。
- 表头统一居中；`numeric` 和 `percent` 正文右对齐，`date`、`label`、`status` 居中，`narrative` 左对齐。
- 所有单元格垂直居中，左右内边距至少 100 DXA，上下至少 80 DXA。
- 禁止等宽：列角色或典型内容长度不同而 grid width 相等属于硬错误。
- 表格总宽默认 8306 DXA；全部为短数字或标签的 2–4 列表可缩至 6600–7600 DXA，但必须与正文左边界对齐或按模板规则居中。
- 表头重复显示，行禁止跨页拆分，不设置固定行高。
- 不为了让整张表落在下一页而强制分页；允许自然跨页并重复表头。只有表题与首行无法同页时才整体移至下一页。

详细算法见 [自适应表格系统](adaptive-table-system.md)。Formatter 不得忽略 `width_weight`，也不得把 numeric 列当作普通文本左对齐。

## 固定格式

- 固定中文编号`一、`、`（一）`。
- 主标题、称谓、提案说明、授权边界自然衔接，不创建封面或目录。
- 页眉使用确认的投资主体或机构名称；未知时才使用`浙江赛智伯乐投资管理有限公司`。
- 文末依次为机构落款和日期，之后不生成免责声明或引用资料。
- 不显示证据状态、来源路径、文件名、Manifest 或 Reviewer 信息。
- Word 使用真实 Title、Heading1、Heading2、Heading3 样式、原生表格、PAGE 域和 `updateFields=true`。
