# Formatter、Word 与 PDF 契约

## 页面与字体

| 角色 | 固定值 |
|---|---|
| 页面 | A4 竖版，11906 × 16838 DXA |
| 页边距 | 上 1440、右 1800、下 1498、左 1800 DXA |
| 页眉/页脚距离 | 各 720 DXA |
| 主标题 | 22 pt，黑体，加粗，居中 |
| 一级标题 | 14 pt，黑体，加粗，Heading1 |
| 二级标题 | 14 pt，楷体，Heading2 |
| 三级标题 | 14 pt，仿宋，加粗，Heading3 |
| 正文 | 14 pt，仿宋，两端对齐，首行缩进 560 DXA，1.5 倍行距 |
| 表格 | 10.5 pt，仿宋；表头加粗、D9D9D9 灰底、黑色细边框 |
| 注释/引用 | 9–10 pt，宋体，灰色 |

中文字体不可用时允许部署环境通过受控字体映射替代，但层级、字号和黑白公文式视觉必须保持。

## 固定格式

- 页眉为`浙江赛智伯乐投资管理有限公司`，居中，下方细黑线。
- 页脚为居中 PAGE 域。
- 开篇不得创建通用封面；主标题自然换行。
- 在开篇说明后插入真实可更新 Word 目录域，目录范围为 Heading1–Heading3。
- 正文按模板自然流排，不按章节数量强制分页；标题与下一段同页，表格行不得跨页断开。
- 保持中文编号`一、`、`（一）`、`1.`，不得转为英文数字自动编号。
- 文末先落款与日期，再免责声明及风险提示，最后是正式一级标题`引用资料`。
- 引用只列正文或表格实际使用的当前项目来源，同一文件的多个片段合并列示。

## 表格

表格必须是 Word 原生可编辑表格，固定总宽 8306 DXA、固定布局、2–8 列。表头重复显示，行禁止跨页拆分；不设置可能导致文本裁切的固定行高。无结构化 Evidence 时不创建空表。

## Word

必须设置：

- `updateFields=true`；
- Title、Heading1、Heading2、Heading3 的真实 Word 样式；
- 可编辑正文和表格；
- 无损 Unicode 中文；
- A4 页面几何、页眉、页脚和 PAGE 域。

不得复制会与运行时冲突的模板样式部件；以 Template Parser 提取的精确令牌安全重建。

## PDF

PDF 只能从最终通过 Word Reviewer 的 DOCX 转换，不允许从另一份 HTML、Markdown 或模型文本另行排版。转换时使用隔离的 LibreOffice 用户配置。必须保留可搜索中文文本层，并通过与 DOCX 的章节、正文和固定内容对照。
