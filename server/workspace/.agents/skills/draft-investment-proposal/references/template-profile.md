## 稳定风格

- 正式、克制、黑白公文式投委会语气。
- 章节以公司事实、交易条件、业务计划、亮点、风险、结论递进。
- 先给明确判断，再列证据和限制；不写营销文案。
- 财务、股权、融资、交易、预测和可比估值优先使用原生表格。
- 风险不是附注；必须写进正式章节并影响结论。
- 不使用通用封面、彩色卡片、彩色状态标签、英文数字章节或任意装饰图。

## 模板事实隔离

下列模板项目名称以及其人物、客户、合同、财务、估值、交易条款、预测、风险和结论不得出现在其他当前项目文档中：佳量脑科学、飞阔科技、轻蜓光电、普雷赛斯、微纳核芯、中数睿智、德塔智能、蓝成应急。只有当名称本身就是当前项目主体且相应事实也出现在当前项目 Evidence 时才能使用。

不得复制模板完整句子再替换公司名。固定称谓、通用授权边界、免责声明、章节名和排版令牌不属于项目事实，可按 Blueprint 原样保留。
