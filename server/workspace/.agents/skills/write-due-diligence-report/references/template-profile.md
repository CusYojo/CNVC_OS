## 1. 模板来源与权威顺序

模板目录为 `docs/尽调报告/`。使用时按以下顺序处理冲突：

1. **版式主模板**：`佳量脑科学业务尽调报告6月.docx`。它控制 A4 页面、封面、目录、分节、页码、标题字体、正文、表格和图示节奏。
2. **业务结构样本**：目录内名称包含“业务尽调报告”或“尽职调查报告”的 DOCX/PDF。它们用于归纳商业尽调的共同章节、论证次序和表达口径。
3. **专项补充样本**：财务内部调研报告只补充财务核查维度；法律尽职调查报告只补充法律资料清单和责任边界；IC 报告只补充结论先行方式。它们不控制商业尽调主结构和 DOCX 版式。

不得把任一模板中的公司名称、人物、产品、客户、数字、日期、估值、判断或结论当作当前项目证据。模板只提供结构、表达方法和视觉规则。

## 2. 文档版式基线

### 页面系统

- 纸张：A4 纵向，8.27 × 11.69 英寸。
- 页边距：左 1.25 英寸，右 1.25 英寸，上 1.00 英寸，下约 1.04 英寸。
- 分节：封面、目录、正文至少三个分节；正文页码从 1 重新开始。
- 页眉页脚：正文使用克制的单色页眉线或公司标识区域；页码置于页脚，不使用彩色卡片或互联网报告风格。
- 配色：黑、白、灰为主。除必须区分的证据状态外，不使用大面积彩色底纹。

### 封面

- 第一行居中放公司全称或项目名称。
- 公司全称使用宋体、22 pt、加粗、居中。
- 报告标题使用逐字纵排的“尽职调查报告”；六个字分别占六个独立段落，使用宋体、22 pt、加粗、居中。
- 下方依次放报告年月和投资机构名称。
- 报告年月和投资机构名称使用宋体、16 pt、加粗、居中。
- 封面不放执行摘要、彩色装饰、生成时间、Skill 名称、模板版本或内部技术字段。

### 字体与段落

主模板采用自定义 `星实-*` 样式体系：

| 角色 | 字体 | 字号 | 字重与段落 |
|---|---|---:|---|
| 一级标题 | 黑体 | 14 pt | 加粗，左对齐，1.5 倍行距 |
| 二级标题 | 楷体 | 14 pt | 加粗，左对齐，1.5 倍行距 |
| 三级标题 | 仿宋 | 14 pt | 加粗，左对齐，1.5 倍行距 |
| 四级标题 | 仿宋 | 14 pt | 加粗，左缩进约 20 pt，1.5 倍行距 |
| 正文 | 仿宋 | 14 pt | 两端对齐，首行缩进 2 字（约 28 pt），1.5 倍行距 |
| 来源批注 | 仿宋 | 10.5 pt | 灰色或黑色，紧随所支持内容 |

渲染器应真实引用主模板的样式 ID 与编号定义，不能只复制 `styles.xml` 后继续使用另一套通用样式。

### Word / WPS 字体兼容

- 在 macOS WPS 实机复核中，主模板和生成文档均可识别黑体、楷体、仿宋和宋体的样式名称；正文应显示为仿宋四号。
- 若审阅机未安装模板使用的 Windows 中文字体，WPS 会提示字体缺失并自动回退，可能改变字宽、换行、表格高度和总页数。
- 正式交付机优先安装合法授权的宋体、黑体、楷体和仿宋；西文统一使用 Arial。
- 仅用于兼容阅读时，可按宋体→Songti SC、黑体→Heiti SC、楷体→Kaiti SC、仿宋→STFangsong 回退。回退后的文档必须重新检查分页和表格。
- 最终交付同时保留可编辑 DOCX 和在目标字体环境确认后的 PDF。

## 3. 内容结构基线

业务尽调主文采用八个一级章节，十六个内容模块作为二级标题。目录与正文顺序必须一致。

| 一级章节 | 二级内容模块 |
|---|---|
| 1、投资概要 | 投资概要 |
| 2、公司概况 | 公司概况；股权结构及融资历程；公司治理与管理团队；法律合规与资质 |
| 3、产品与技术 | 产品与核心技术 |
| 4、业务情况 | 商业模式与经营情况；客户与商业化进展 |
| 5、行业和市场 | 行业概况与市场空间；产业链与竞争格局 |
| 6、未来发展规划 | 财务分析 |
| 7、投资方案 | 估值合理性分析；投资方案；投资亮点 |
| 8、风险提示与对策 | 风险分析；资料缺口与后续核验 |

执行摘要放在目录之后、第一章之前。它只给出初步判断、三项以内的核心依据、关键前提和最大未决事项，不复述各章。

不适用的模块仍保留。没有证据时写明确的资料缺口和补证要求，不用模板事实填空。

## 4. 表格、图示与来源

- 公司基本信息、股权结构、融资历程、核心团队、财务数据、客户验证、竞品对比、估值测算和交易方案优先使用表格。
- 表格采用细边框、浅灰表头、黑色正文；窄字段保持紧凑，长文本列留足宽度；跨页表重复表头。
- 图示只在输入含有可复用的结构化数据或已授权图片时生成。不得从模板复制项目图片、人物、产品图、截图或样本图表。
- 市场规模、财务预测和估值图表必须同时保留期间、单位、口径、来源和关键假设。
- 每个事实只保留最接近事实位置的状态和来源标签。文尾“引用资料”只列正文实际使用的来源，同一文件的多个片段合并列示。

## 5. 写作风格

### 基本句式

每节按“结论—证据—分析—限制”组织：

1. 用一句话给出证据强度匹配的初步结论。
2. 写明截至日期、资料口径、可核对的事实或数字。
3. 说明事实对业务、竞争、现金流、交易或风险的含义。
4. 在证据不足处明确列出待核验事项或资料缺口。

### 语气

- 使用投资机构内部报告语气：客观、克制、明确，不使用营销口号。
- 区分“公司提供”“管理层表示”“工商或原始记录显示”“第三方资料显示”和“据此分析”。
- 使用“初步判断”“现有资料显示”“基于上述资料推断”“尚需核验”等限定语。
- 正面结论必须同时说明成立条件；风险必须写清触发条件、潜在影响和核验或缓释动作。
- 不使用“行业领先”“巨大空间”“商业化成熟”“退出清晰”等无量化依据的空泛结论。

### 数字

- 每个数字同时写明期间、币种或单位、含税口径、合并范围、审计状态或预测属性。
- 严格区分合同额、订单、交付、开票、收入确认、回款和销售管线。
- 严格区分历史实际、管理层预测和 AI 情景测算。
- 百分比、估值倍数和增长率必须能回溯到分子、分母或计算假设。

## 6. 模板使用边界

- 商业尽调不得给出法律意见、审计意见、技术鉴定或独立市场认证。
- 法律专项只允许转化为“证据观察、待核验事项、资料缺口和需专业复核的事项”。
- 财务专项只允许转化为“数据、口径、异常、现金流影响和补证要求”。
- IC 演示中的口号式标题不得直接进入正式报告。
- 模板正文属于跨项目样本，不属于运行时证据；即使与当前项目相似，也不得复制、近似改写或替换名称后使用。

## 7. 交付验收

生成后必须确认：

- 封面、目录、正文三分节完整，正文页码重启；
- 封面公司名和纵排标题为宋体 22 pt 加粗，日期和机构为宋体 16 pt 加粗；
- 八个一级章节及十六个二级模块顺序正确；
- 黑体、楷体、仿宋层级和 14 pt、1.5 倍行距、正文 2 字缩进生效；
- 每个模块都有结论、发现或明确补证要求；
- 来源状态、来源索引、资料截止日和责任声明可见；
- 文尾引用只包含实际使用来源；
- 不含任何模板项目事实、模板图片、技术元数据、损坏字符或占位文本；
- 渲染后的每页无裁切、重叠、表格断裂、孤立标题或异常大空白。
- 在 Word/WPS 中复核字体替换提示、目录更新、总页数、封面纵排和表格分页；使用回退字体时不得宣称与主模板完全一致。
