# 尽调报告叙述风格

本文件只控制客户可见正文的叙述方式。模板样本只用于学习句式、段落节奏和分析方法，不得复制其中的项目事实、数字、人物、产品或结论。

## 模板风格基线

对 `docs/尽调报告` 中七份业务尽调样本的正文抽样显示：

- 句子中位长度约 43–64 个汉字，通常用一至三句话完成一个事实单元；
- 正文几乎不出现“项目资料”“项目资料库”“现有资料”“根据资料”等取证过程；
- 常用“截至某日”“股权方面”“融资方面”“从产品形态看”等自然主题衔接；
- 判断通常紧跟事实，使用“若……则……”“尚未……”“仍需……”限定成立条件；
- 只有在披露属性会影响事实强度时，才使用“据公司披露”“管理层表示”“工商登记显示”等必要归因。

## 先消化、后写作

1. 先在系统内部把输入证据整理成事实卡，统一主体、时间、关系、事件阶段、数字口径和来源索引。
2. 合并重复事实，区分已发生事实、公司陈述、管理层预测、外部验证和投资分析。
3. 再把事实卡改写成面向投资经理的正文；不得把证据分片、文件标题、网页摘录或取证过程直接搬入文档。
4. 来源索引和证据状态只保存在 JSON 审计字段，不得转写为正文说明。

## 句式与段落

- 事实段以具体主体开头：`截至 YYYY 年 M 月，公司……`、`公司成立于……，主要……`。
- 专题段可用一次自然导语：`股权方面，……`、`融资方面，……`、`从产品形态看，……`。
- 整个模块需要覆盖事实、影响和边界，但不要让每个段落都复制同一结构。事实段可以只说明主体、时间和事件，分析放在确实改变投资判断的位置。
- 风险段直接写风险触发条件和影响：`若……，则……；推进前应……`。
- 一个 finding 保持一个中心结论，可用一至三句话展开；不把一句话拆成多个口号式短句。
- 同一小节避免连续使用相同句首，不机械重复“整体来看”“综合来看”“这意味着”。
- 不以“该信息”“该信号”“该口径”“该能力”“该模式”“该表述”反复承接上句；直接写公司、产品、客户或事件。
- 不把“但”“若”“尚未”“仍需”当成每段必备收尾；同类限制和核验动作在模块末尾集中表达一次。

## 建议的自然写法

- 执行摘要只明确表达一次处置结论，并把结论与一项具体项目事实写在一起。可以先写最能支撑判断的进展，再自然落到`公司现阶段建议继续跟踪`；不得让所有报告都以`建议继续跟踪该项目`等固定句式开头。
- 不得出现`阶段与推进建议：……`、`主建议：……`、`最强依据是……`、`反向证据是……`、`前置条件为……`等标签化串联。
- 投资概要只说项目当前处于什么阶段、为什么暂不进入下一阶段，不再复述执行摘要中的建议句。
- 执行摘要用三至五个完整句子串联判断、核心事实、主要制约和下一步行动，不按“建议—依据—风险—条件—动作”逐项报幕，也不要求每份报告使用相同的句序。

## 禁止的客户可见表达

不得出现取证或生成过程：

- `项目资料`、`项目材料`、`项目资料库`、`项目知识库`、`资料库`、`知识库`；
- `现有资料`、`当前资料`、`根据资料`、`资料显示`、`证据显示`、`证据不足`；
- `本节`、`本初稿`、`初步梳理`、`检索问题`、`联网检索`、`来源索引`、`状态标签`；
- `资料记载`、`AI推断`、`待核验`等内部状态名称。

避免明显的模型化套话：

- `值得注意的是`、`需要强调的是`、`不难发现`、`由此可见`、`综上所述`；
- `阶段与推进建议`、`主建议`、`最强依据是`、`反向证据是`、`前置条件为`等写作标签；
- 无事实支撑的`赋能`、`生态闭环`、`强大壁垒`、`巨大空间`、`全面领先`、`团队豪华`；
- 连续三段使用相同的“从……来看”“整体来看”“有望……”句式；
- 先给空泛评价、后堆事实，或用三段式口号代替分析。

## 必要归因

仅在以下场景保留归因：

- 公司单方披露且尚无独立材料交叉验证；
- 管理层预测、经营计划、意向订单或未完成融资；
- 工商、监管、司法、学校或实验室等权威记录；
- 不同来源之间存在冲突。

归因必须具体，不写“根据项目资料”。优先使用`据公司披露`、`管理层预计`、`工商登记显示`、`监管公告显示`或直接写具名文件和日期。

## 交付前检查

逐项确认：

1. 正文不含任何取证、检索、资料库或生成过程；
2. 每段首句落到具体主体、产品、人员、客户、融资事件或数字；
3. 处置建议只在执行摘要中自然表达一次，不含“主建议”或“阶段与推进建议”标签；
4. 事实、分析和限制按内容自然分布，不是每段都采用三段式；
5. “该信息/该信号/该口径”、“但/若/尚未/仍需”和核验要求没有机械重复；
6. 套话、宣传词和机械连接词未形成重复；
7. 模板样本只影响文风，没有进入当前项目事实。
