# 尽调报告叙述风格

本文件控制客户可见正文。写作风格以 `docs/尽调报告/德塔智能尽职调查报告(1).pdf` 为主：具体、克制、事实密集、结构清楚，像熟悉项目的投资经理一次写成，而不是模型分段拼接。

## 1. 先消化事实

写作前先在内部统一主体、人物关系、时间线、数字口径和事件状态，合并重复事实并标记冲突。正文只呈现消化后的事实与判断，不呈现文件名、检索动作、证据标签、片段编号或模型过程。

## 2. 句子和段落

- 优先用公司、人物、产品、客户、合同、日期、金额和比例开句。
- 一段只处理一个中心。通常用一至四句完成，长短随事实复杂度变化。
- 事实足以说明问题时直接结束；只有投资含义会改变判断时才补充影响、边界或条件。
- 自然使用“截至某日、股权方面、融资方面、产品方面、客户方面”等主题衔接，但不要每段使用同一种开头。
- 连续的时间、股权、团队、客户、产品、财务和风险信息应优先表格化；表格前后保留必要分析，避免表格堆砌。

## 3. 专业判断

- 执行摘要先呈现最关键的公司、产品、客户、经营、财务或交易事实，再说明投资价值、主要制约和关键条件。
- 投资结论回答：投资逻辑是否成立、成立依赖什么、主要风险是什么、交易条件应如何设置、还需完成哪些实质工作。
- 不使用系统状态词替代判断。例如不要写“现阶段建议启动尽调”，应直接写“公司已形成何种产品和客户验证，但收入质量、知识产权权属或交易估值仍需满足哪些条件”。
- 风险必须写清风险对象、事实依据、可能影响和具体对策；不得只列“市场风险、技术风险、管理风险”等空泛标签。
- 未明确事项写具体要取得的合同、清单、底稿、审计材料或访谈对象，不写“资料不足、待补充资料”。

## 4. 去除 AI 腔

禁止使用：

- “值得注意的是、需要强调的是、不难发现、由此可见、综上所述、显而易见、毋庸置疑”；
- “该信息、该信号、该口径、该能力、该模式、该表述”反复承接；
- “形成闭环、赋能、抓手、持续发力、构建壁垒、打开空间”等无事实支撑的宣传语言；
- “最强依据是、反向证据是、前置条件为、阶段与推进建议、主建议”等报幕标签；
- “直接关系到进入下一阶段、将直接影响项目推进、投资团队应据此、相关事项已纳入本轮尽调”等可套用到任意项目的句子；
- 连续多段都以“整体来看、综合来看、这意味着、有望”开头；
- 每段机械追加“但、若、尚未、仍需”以及相同的核验动作。

## 5. 防重复

- 同一事实只在职责最匹配的模块完整出现一次。
- 执行摘要只做综合判断，不复述正文段落；投资亮点和风险只保留决定性内容。
- 不把同一句事实分别改写为“优势、亮点、意义、价值”四次。
- 同一数字重复出现时，必须服务于不同且必要的分析；否则保留第一次完整表述。
- Reviewer 发现跨章节相似句时，应保留信息最完整、位置最正确的一处，删除其他重复，不做换词改写。

## 6. 表格与正文节奏

表格用于可比较或可查阅的数据，正文用于解释原因、联系和判断。资料充分时应形成接近主模板的高表格密度，但不得为凑数量造表。表格标题应具体，例如“截至 2026 年 6 月公司股权结构”，不要使用“相关情况、主要信息”等泛标题。

表格之后的正文不再逐行复述，应指出对控制权、治理、商业化、现金流、估值或风险判断最重要的变化。

## 7. 交付前语言检查

定稿前逐项检查：

1. 是否存在内部项目阶段、系统流转或生成过程词；
2. 是否存在模板项目事实或其他项目内容；
3. 是否把预测、意向、测试、合同、交付、收入、开票和回款混为一谈；
4. 是否存在没有主语的孤立数字、短语或资料标题；
5. 是否跨章节重复同一事实、数字、风险或工作要求；
6. 是否出现统一句式、固定结尾或宣传化表达；
7. 执行摘要、正文、风险和投资结论是否一致；
8. 读者能否仅凭正文理解公司做什么、由谁控制、为何有价值、关键事实是什么、主要制约是什么、交易条件是什么。
