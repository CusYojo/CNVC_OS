# 商业尽调报告输出契约

## 输入

必须提供：

- `project`：已获授权的项目字段。
- `sources`：本次运行输入的有序证据数组，包含项目资料和联网公开信息。
- `sourceCutoffDate`：格式为 `YYYY-MM-DD` 且不晚于运行日期的资料截止日。
- `parameters.diligenceScope`：`商业尽调`。
- `parameters.userInstructions`：可选的受众、篇幅、关注重点和交易背景。

不得使用 `sourceCutoffDate` 之后形成的证据。用户补充输入不得替代事实证据。不得读取或复制 `docs/` 中特定项目的示例正文；这些内容既不是运行时证据，也不是可复用的报告文本。

## JSON 结构

仅返回一个包含下列键的 JSON 对象：

```json
{
  "title": "项目名称商业尽调报告",
  "executiveSummary": "一段说明初步结论、主要依据和关键条件的摘要。",
  "sections": [
    {
      "title": "投资概要",
      "summary": "本节的一句话结论。",
      "findings": [
        {
          "text": "可复核的尽调发现。",
          "status": "资料记载",
          "sourceIndexes": [0]
        }
      ]
    }
  ],
  "highlights": ["有证据支撑的项目亮点"],
  "risks": ["可能影响交易或投资判断的风险"],
  "missing": []
}
```

不得增加附录、来源对象、表格、图表、法律意见或文件版式等字段。当前渲染器仅使用上述 `BusinessContent` 结构；版式和目录由渲染器按照核心规范生成，来源明细由系统审计记录保存。

## 必需章节顺序

每个章节必须且只能出现一次，并严格按照以下顺序返回：

1. 投资概要
2. 公司概况
3. 股权结构及融资历程
4. 公司治理与管理团队
5. 行业概况与市场空间
6. 产业链与竞争格局
7. 产品与核心技术
8. 商业模式与经营情况
9. 财务分析
10. 客户与商业化进展
11. 法律合规与资质
12. 估值合理性分析
13. 投资方案
14. 投资亮点
15. 风险分析
16. 后续核验事项

十六个模块的名称、顺序和归章关系必须与核心规范一致。每节使用二至六项发现，最多不得超过八项。每节摘要均应结论先行。`highlights`和`risks`应分别包含三至八个非空字符串；`missing`固定返回空数组。

同一事实、数字、客户进展、风险或后续核验事项只能在最相关章节完整出现一次。执行摘要、投资亮点、风险分析和后续核验不得换词重复正文。不得输出目录、页眉页脚、测试文字、缺口占位语、连续复制内容或整段证据原文。

## 发现状态与引用

仅可使用以下状态：

- `资料记载`：由一项或多项输入来源直接支持的表述；必须至少包含一个有效索引。
- `AI推断`：基于已识别证据形成的合理分析；必须包含支持该分析的索引，并将其表述为分析而非事实。
- `待核验`：已有初步依据，但仍需原始文件、第三方材料、专业人士或访谈确认的表述。

`sourceIndexes` 是输入 `sources` 数组中从零开始的位置。只能使用整数；不得在该字段中输出 `S0` 等标签、来源名称、文件路径或虚构索引。

## 专题要求

- 股权与融资：区分公司陈述、最新工商登记、已签署协议和付款凭证。
- 市场与竞争：注明资料日期、地域范围、品类定义，并区分第三方数据和管理层估算。
- 财务：保留期间、币种、含税口径、合并范围和审计状态，并区分收入、开票和回款。
- 客户：区分线索、试用、已签合同、交付、收入确认、续约、集中度和现金回款。
- 产品与技术：区分已展示能力、管理层主张、知识产权权属、外部验证和商业化成熟度。
- 法律合规：仅报告证据、联网公开信息和待核验事项，不得作出法律结论。
- 估值与投资条款：明确假设，并将无证据支持的条款标记为`待核验`。

## 渲染与验收

渲染后的中文 DOCX 必须包含：

- 按顺序排列的全部十六个章节；
- 资料截止日；
- 清晰可见的发现状态和来源标签；
- 封面、纵排报告标题、Word/WPS 可更新目录、三分节、正文页码重启、无文字细线页眉、黑体/楷体标题、仿宋正文和表格节奏符合核心规范；
- 文末不包含免责声明、责任声明或引用资料章节；
- 来源索引、网页地址和核验状态保存在系统审计记录中。

凡将无证据支持的主张转化为事实、缺少来源追溯，或暗示尽调已经完成的报告，均应判定为不合格。
