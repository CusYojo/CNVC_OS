# 法律、业务、财务和交易勾稽

## V22本轮交易勾稽

- 先形成交易文件版本链，再抽取金额、估值、增资/老股结构、投资人、投后权益和保护条款；文件正文出现次数不能替代版本判断。
- `1.2`、`7.2`与末章逐项使用同一`current_round_id`和同一批`report_assertions`。历史融资条款只能进入历史沿革/历史融资，不得作为当前交易摘要。
- 当前材料只给区间或计算公式时保留区间/公式。不得为了满足模板而推造单点投前估值或精确投后股比。
- 新增交易文件后，`1.2`、`7.2`、结论、估值、投后股权、交易风险和相关治理节点全部失效并重算。

## 主体与股权

- 营业执照、工商档案、章程、股东名册、增资/转让协议和最新Cap Table逐项核对。
- 注册资本、实缴资本、认缴期限和股东名称前后一致。
- 历史沿革的每次变更与协议、决议、章程和登记日期对应。
- 实控人判断同时考虑直接持股、员工持股平台控制、表决权安排、一致行动和董事会控制。
- `2.3.1 公司股东`按报告基准日已经生效的股权安排合计100%，区分工商已登记、已签署生效但尚未登记的历史融资与本轮拟实施交易；表头使用`股东｜认缴注册资本（万元）｜持股比例`。
- 本轮投后股权只在`7.2 公司估值与投资方式`及结论中按完全稀释口径说明，包括期权池、可转工具和同轮融资影响；正文直接写`投后`，不使用`模拟投后`。

常用计算：

- `投后估值 = 投前估值 + 本轮进入公司的全部增资额`
- `每股价格 = 投前估值 / 交易前完全稀释股本`
- `投资人新增股数 = 增资金额 / 每股价格`
- `投后持股 = 投资人投后股数 / 交割后完全稀释股本`

老股不进入公司，不得计入投后估值增量；老股比例与增资比例必须在同一交割后口径下合并。

## 法律与合规

- 核心许可是否与实际业务匹配；“无需许可”必须有业务事实基础。
- 核心知识产权登记人、发明人、前雇主、开源许可、合作开发和数据权属是否一致。
- 重大合同检查主体、期限、金额、验收、付款、违约、排他、控制权变更和知识产权条款。
- 核心人员全职/兼职/顾问、竞业、保密、成果归属和社保个税口径交叉核对。
- 关联方、关联交易、担保、诉讼仲裁、处罚、税务、外汇和劳动风险按基准日说明。
- 制度文件存在与制度实际执行分开评价。

## 业务与客户

- 合同台账与合同原件、发票、验收、银行回款和财务收入逐项目勾稽。
- 报价单、意向、框架、PoC、在手订单、已交付、已验收、已开票、已回款分别命名。
- 客户访谈只能证明访谈对象的陈述；未经合同或业务记录验证，不写成确定订单。
- 供应商集中度、交付周期、替代性、预付款、质量责任和关键硬件/服务依赖需结合采购合同与账务。

## 财务

- 先确认合并范围、会计期间、币种、单位、审计状态和报表版本。
- `毛利 = 营业收入 - 营业成本`，`毛利率 = 毛利 / 营业收入`。
- 资产负债表满足`资产 = 负债 + 所有者权益`；现金流期末现金与资产负债表现金勾稽。
- 利润表净利润、权益变动和现金流间接法调整在适用时互相勾稽。
- 合同额、含税收入、不含税收入、开票、回款和应收余额不得混用。
- 关注收入截止、关联交易、资本化研发、预付款、其他应收、存货、固定资产、政府补助、税务和或有负债。
- 财务尽调不是审计时，仅在财务章节最相关位置准确说明一次其非审计性质；调整前后口径分列，不在各表重复来源、核验或排除说明。

## 预测

- 历史实际标`A`，预测标`E`，预算标“预算”或单列来源。
- 预测收入拆到可验证的价格、销量、客户/项目、转化率或交付能力；不使用无来源复合增长率作唯一依据。
- 人员、薪酬、研发、设备、算力、采购和资本开支与业务规划匹配。
- 大幅跳升必须有订单、产能、招聘或融资假设支撑；否则作为敏感性或风险呈现。
- 不为形式完整强制计算DCF、MOIC或IRR。只有投资额、退出值、持有期和现金流口径可靠时计算。

## 交易与基金合规

- 核对投资主体、基金合伙协议、投资方向、地域返投、集中度、关联交易、禁止事项和决策权限。
- SPV同时披露SPV层出资、费用/收益安排、标的层持股和基金穿透权益。
- 交易协议条款与报告摘要一致；不自行创造回购利率、清算倍数、董事席位或业绩承诺。
- 付款、交割、工商变更和权利义务使用“安排、条款、支付、办理、实施”等交易语言；“口径”只用于财务、估值和计算基础，不用于描述合同履行。
- 本轮金额、投前/投后、股比在投资概要、方案、合规说明和结论中一致。

## 风险分级

- 高/重大：可能改变是否投资、交易主体、控制权、核心资产、估值或本金安全；终稿前必须形成接受、排除、交易控制或阻断结论；
- 中/重要：已经落实为交割条件、条款保护或责任与时点明确的投后事项；
- 低/一般：可常规跟踪，不改变核心投资判断。

同一风险只保留一个主记录，其他章节引用其事实或影响，避免重复堆叠。风险表直接写已形成的具体控制安排、责任主体和时点，不写“建议核验”“仍需补充”等调查任务，也不写“状态：已接受/已落实/交割条件/投后事项”等过程标签。
