# 投资经理决策层写作契约

本契约约束上会尽职调查报告的叙述阶段与投资经理视角。默认交付物是尽调完成后、由投资经理向投委会提交具体投资建议的终稿，不是尽调过程记录、补件清单或外部顾问意见。证据真实性、重大风险披露和预测属性不因采用确定性语气而降低。

## 一、报告阶段

默认使用`investment-recommendation`：

- 投资团队已经完成本轮尽调并形成明确投资倾向；
- 交易金额、估值、结构、投资主体和投后权益具有可采用口径；
- 可能反转投资结论的重大事实已经核实、裁决或落实为交易安排；
- 正文只呈现决策层事实、分析、投资影响和已经形成的控制安排，末章以具体交易条件形成投资建议。

用户明确说明投委会已完成决策、已经决定投资、确定投资、本轮要投或要求按已决定投资的投资经理视角写作时，使用`final-investment-decision`。报告阶段与文件法律状态分别判断：意向书仍可准确写成框架条款，不能因叙事已决策而冒充正式协议已生效。只有用户明确要求初稿、进行稿、问题清单或补件报告时，才使用`dd-in-progress`。进行稿必须在文件名和正文定位中明确其阶段，不得伪装为可交付终稿。

## 二、终稿就绪门禁

起草终稿前，为每个重大事项记录下列一种闭环状态：

1. `verified`：已由足以支持结论的资料核实；
2. `accepted_adverse_fact`：已确认不利事实，投资团队已经评估并接受其投资影响；
3. `transaction_controlled`：已写入交易结构、交割条件、分期安排、陈述保证、赔偿或治理权利；
4. `post_investment_owned`：已形成责任主体、完成时点和验收标准明确的投后事项；
5. `excluded_from_thesis_or_valuation`：内部裁决为不作为本轮投资逻辑、估值基础或收益测算；该标签只留在台账，不直接生成正文句子；
6. `immaterial`：经判断不影响本次投资结论，仅保留在内部台账。

下列情形不得进入终稿：

- 交易金额、估值、结构、主体或投后权益仍无可采用口径；
- 主体资格、控制权、核心知识产权、收入质量、现金、重大负债或合规结论存在未裁决的重大冲突；
- 关键投资逻辑仍依赖待核验事实；
- 已知事实可能构成否决性风险，且尚未形成投资团队的明确处置结论。

遇到上述事项时停止终稿构建，返回事实台账或补件流程。不得通过删除风险、虚构核验或把开放事项改写成肯定句来通过门禁。

## 三、可见决策层与内部审计层

### 可见决策层：DOCX/PDF

只承载：

- 已核实的公司、业务、技术、法律和财务事实，以直接陈述呈现；
- 已经形成的项目判断和投资价值，不额外标注“投资团队认为/判断”；
- 交易金额、估值、结构、权益和资金用途；
- 已确认风险及其投资影响；
- 已落实、已约定或已接受的控制安排；
- 直接、确定的投资总结；不使用审批式“同意投资”句式。

### 内部审计层：事实台账、冲突表、`open_issues`和QA日志

承载：

- 来源层级、文件定位、内部证据编号和取证过程；
- 补件记录、失败解析、待办任务和复核责任；
- 不影响投资结论的资料覆盖限制；
- 已裁决冲突的备选口径与裁决依据；
- 未进入投资逻辑、估值或预测的主张及其排除理由；
- 尚未闭环并因此阻断终稿的重大事项。

内部审计层不得以“报告基础与范围”、表后说明、脚注、尾注、`SRC-*`或重复免责声明进入默认交付物。

## 四、投资经理叙述视角

- 报告的视角由内容和结论体现，不通过反复书写“投资团队认为/判断/据此采用”来标记叙述者。
- `中心判断：`、`事实基础：`、`分析判断：`、`投资影响：`、`核心逻辑由…项事实构成`等是内部写作脚手架，不得出现在可见正文或表格。行业和投资判断直接写成自然句。
- 事实直接写结果，例如“2025年度调整后营业收入为878.30万元”；不写“经财务尽调勾稽、本次据此采用……口径”。
- 业务阶段使用中性现状，例如“4项发明专利处于申请阶段”“触觉产品处于工程化阶段”；不追加“不计入估值”等内部排除过程。
- 估值依据只在投资价值、投资方案或结论中集中说明一次，不渗入人员、产品、客户、供应商等事实性表格。
- 已落实安排直接写条款、交割事项或投后责任，不在句末追加“状态：已接受/交割条件/投后事项”。
- 付款、交割和工商变更属于交易义务，直接写“支付、办理、实施、完成”等动作和条件；不得用“按……口径执行/办理”替代具体交易安排。“口径”仅用于财务、估值和计算基础。
- 投资理由一项只表达一条项目特定的正向投资逻辑及必要证据，不追加防御性尾句。
- 行业事实必须落到目标公司的需求、竞争位置或商业机会，不写“行业热度、政策或同业融资不能证明公司价值”一类空泛否定。
- 风险可以是负面事实，但必须是已经核实和完成投资处置的事实；不得写成调查任务或将来才形成的判断。
- 重大不利事实不得隐匿，但执行“一个事实一个主要归属章节”。原始亏损、负现金流和财务调整金额只在财务分析或风险章节披露一次；概要、关联交易、综合评估和结论仅回扣其决策影响。
- 小额、已结清且不涉及资金占用、利益输送、税务、竞业、控制权或知识产权冲突的个人报销/垫付款归入`immaterial`内部台账，不进入正文。
- 2.6只写关联身份、控制/持股/任职事实、重大往来和已形成安排；不在句末追加“避免/防范……冲突”或“不利后果”等风险解释。实质性风险只在第8章归位一次。
- 4.1只回答产品/服务、收费/收入、获客/销售和交付方式，不使用“商业验证”固定列；合同、验收、开票、回款和复购集中归入4.2。

## 五、终稿禁用表达

以下表达及语义等价表述不得出现在`investment-recommendation`或`final-investment-decision`正文中：

- `建议补充/核验/确认/取得/复核/关注/跟踪/整改`；`investment-recommendation`仅允许在`投资结论及建议`的最后一段出现一次与具体金额、估值或交易方式绑定的投资建议；
- `待核验`、`待验证`、`待确认`、`待复核`、`待补充`；
- `仍需`、`尚需`、`需进一步`、`后续需`、`最终仍应核实`；
- `方案尚未确定`、`交易结构尚未确定`、`不能测算`、`无法核对`、`无法判断`；
- `若未达标则延期投资/降低估值/分期付款`等尚未落地的处置设想；
- `不能直接证明公司份额和估值`、`不能据此推演规模收入`等把尽调不足留给投委会的泛化否定。
- `根据/据某资料`、`某尽调报告显示/确认`、`经尽调/勾稽/核验`、`据此判断`等取证过程语言；
- `投资团队认为/判断/据此采用`、`本报告/本文仅……`等叙述者或写作元话语；
- `不纳入`、`不计入`、`不使用`、`不将`、`本次仅以`等内部估值/测算排除过程。未经支持的主张直接不写，而不在正文说明为何没有使用；
- `模拟投后`、`模拟注册资本`、`模拟持股比例`。有可采用交易方案时写`本轮投后`或`投后`；没有可采用方案时不生成决策终稿；
- `状态：已接受`、`状态为交割条件`等内部闭环标签。
- `付款/交割/工商变更按……口径执行（办理）`等把合同履行写成分析口径的表达。
- `中心判断：`、`事实基础：`、`分析判断：`、`投资影响：`等可见推理标签，以及`核心逻辑由…项事实构成`等提纲式AI总结。

预测、预算、Pipeline、拟任人员和未签署交易文件仍须保持其真实属性。属性限定不是开放式尽调措辞；不得为了语气确定而把预测写成实际、把意向写成订单、把拟任写成已到岗。

## 六、闭环改写示例

| 进行稿表达 | 终稿表达 |
|---|---|
| 建议纳入交割前提 | 已纳入本轮交易交割条件 |
| 仍需核验客户收入 | 2025年度调整后营业收入为……万元，其中某项目当年确认收入为……万元 |
| 该技术主张仍待验证 | 删除该主张；如其对投资判断具有实质影响，则阻断终稿而不将它改写成可见限制 |
| 若未达标则延期投资 | 本轮采用分期交割，第二期付款以……里程碑完成为条件 |
| 建议推进本轮投资 | `investment-recommendation`的最后一段写为“综合考虑公司的业务基础、产品能力和团队配置，建议由……按本轮最新文件所列估值类型/区间、以增资/老股方式投资……万元”；其他章节不使用“建议” |
| 风险控制建议 | 风险控制安排 |

## 七、结论与风险表

- `investment-recommendation`的一级标题使用`投资结论及建议`，必须为三个自然段：公司/产品定位；行业、商业、团队基础；具体交易建议。
- 第三段必须写明投资主体/载体、金额或区间、当前资料支持的估值类型/区间、交易方式和投后权益或计算机制，并仅在该段出现一次具体投资建议。结论不复制风险表或控制安排清单，不使用`核心逻辑由…项事实构成`或`本项目投资结论为同意……`。
- `final-investment-decision`在用户明确表达已决定投资时使用`投资结论`，直接记录本轮交易方案和决策基础，不使用`建议`、`原则上同意`、`有条件推进`或`待复审`。金额、估值和投后权益可按当前来源保留区间或计算机制，不得补造单点值。
- 第27表表头使用`风险类别｜具体风险描述｜风险控制安排`。
- 风险控制安排必须是具体交易条款、交割事项、治理权利或责任主体明确的投后安排；不以“状态：已落实/交割条件/已接受”替代安排内容。
- 同一控制安排只出现一次；投资概要仅回扣对决策有影响的结果，默认投资结论及建议不重复风险或任务清单。
