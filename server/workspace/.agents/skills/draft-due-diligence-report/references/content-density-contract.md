# 逐表内容颗粒度契约

本契约防止报告只保留27张表的外形，却把分析压缩成提案式短句。目标项目事实仍以资料包为准；参考报告只定义应回答的维度和论证深度，不提供任何可复制事实。

## 一、共同规则

- 每个重大判断在内部写作检查中按`事实依据—分析判断—投资影响—已形成处置`核验。证据来源、备选口径、排除理由和内部闭环标签不生成可见正文；正文只在样例已有槽位中呈现直接事实、投资意义与具体控制安排。
- 严格样例模式禁止为增加字符量新建“行业判断”“项目判断”“本节判断”“报告基础与范围”等模块，禁止在表格后机械追加总结段或`SRC-*`证据串。内容深度通过既有表格和既有章节完成。
- `中心判断：`、`事实基础：`、`分析判断：`、`投资影响：`和`核心逻辑由…项事实构成`仅用于内部检查，不生成为正文或表格文字。可见内容直接写成自然句和自然段。
- 单元格包含多个独立论点时，建立多个真实段落；不得把全部论点塞进一个run或用软换行伪装段落。编号项至少由“编号标题段+论证段”组成。
- 资料不足时先在内部审计层记录具体缺口。影响投资结论的缺口阻断终稿；不影响结论的缺口不进入正文。调整业务表头、合并无数据的行项或改用对应正文槽位，不用`不纳入本次测算`、`未取得`或空白填满表格。进行稿方可显示缺失状态。
- 字符量、段落数、行数及与参考样例的比例仅作极端收缩预警，不能用空话堆字通过，也不得因为密度门禁而压缩字号。是否合格以字段完整、事实可溯源、信息归位和决策相关性为准。
- 页数只用于识别异常收缩或渲染失败；`20—50页`不是内容充分性的主要判据。

## 二、严格样例视觉模式的逐表必须回答维度

| 表号 | 表格角色 | 必须回答的维度 |
|---|---|---|
| 1 | 公司情况 | 公司名称、成立时间、注册地址、实际经营地址、法定代表人/实控人、主营业务、发展阶段及核心判断；地址只写地址，发展阶段和核心判断各保持一项中心结论 |
| 2 | 投资概要 | 投资主体、交易方式、金额、估值、股比、资金用途、同轮安排及已经形成的保护条件；终稿不得存在未确定交易项 |
| 3 | 行业概况 | 三个固定主题各至少2—3个自然段，每个主题形成“阶段/环境结论—关键驱动与约束—对目标公司的影响”；右栏每项不少于180个非空白字符，不显示推理标签，不堆政策口号 |
| 4 | 商业路径 | 当前产品与收费方式、获客/交付/验收/回款、复购或产品化路径；不将估值方法或证据状态写入该表 |
| 5 | 投资价值与风险 | 投资价值选择3—5个项目特定论点；每项至少用3个自然段完成事实基础、能力/壁垒、商业或竞争含义与本轮投资意义，投资价值单元格不少于650个非空白字符且无防御性尾句。风险只写重大事实、投资影响及已形成控制安排 |
| 6 | 公司基本信息 | 工商登记、当前注册资本、住所、经营范围、法定代表人、治理状态和经营资质；实缴、历史变化、投后资本和估值分别归位 |
| 7 | 历史沿革 | 时间、事项、资本/融资变化、工商或协议证据及未完成登记事项 |
| 8 | 报告日股东结构 | 股东、认缴注册资本、持股比例及合计勾稽；交代基准日和已签署生效但尚未登记的历史融资状态，不混入本轮投后结构 |
| 9 | 股权穿透 | 上层持有人/合伙人、控制链、最终受益人、代持或特殊权利及核验范围 |
| 10 | 组织架构 | 可读组织架构图、经营管理层级、核心部门和汇报关系；图下说明部门职责与当前组织阶段 |
| 11 | 关联公司及关联交易 | 按重大性披露关联主体、关系、控制/持股/任职、重大往来和已形成安排；不保留零星已结清报销，不追加“避免/防范冲突”或“不利后果”等风险解释 |
| 12 | 资质、认证及荣誉 | 使用`类别｜资质、认证或荣誉情况`，只列业务资质、认证、政府/行业认定和荣誉，不列负面法律事项或一般经营合规事项 |
| 13 | 核心产品 | 每行写清产品定义/核心功能、应用场景/目标客户和商业化进展；认证与专利清单不得代替产品 |
| 14 | 核心技术 | 每行写清技术描述/原理、技术来源/权属、技术门槛及对产品的作用；不得与产品表重复 |
| 15 | 应用场景 | 客户或场景、客户痛点、产品解决方式、成熟度以及合同/测试/验收等验证证据 |
| 16 | 技术沿革 | 年份、论文/算法/产品/测试/工程成果及其如何沉淀为当前技术路线 |
| 17 | 技术与知识产权现状 | 专利/软著/代码/数据/合作研发的截至报告日状态、权属主体、发明人/贡献方及已形成的权属安排；不在本表重复估值排除语言 |
| 18 | 商业模式与销售策略 | 按业务形态展示业务/产品、收费或收入方式、获客/销售方式和交付方式；不使用“商业验证”固定列，合同/验收/开票/回款/复购归入4.2 |
| 19 | 成本结构 | 成本项目、金额或合同、期间、固定/变动属性、供应商依赖和毛利影响 |
| 20 | 市场空间 | 近期机会、中期空间、测算口径、关键假设、可服务市场及公司切入路径 |
| 21 | 业务拓展规划 | 各阶段研发、商业和组织目标，里程碑、责任/资源、前置条件；规划与历史实际隔离 |
| 22 | 人员预测 | 当前基数与资料已给出的年度岗位/人数、扩编依据及人工成本；只展示有可采用输入的年度，不用“不纳入本次测算”填满后续列 |
| 23 | 历史财务 | 纵向分为利润表、资产负债表、现金流量表；资产负债必须含流动/非流动资产、资产合计、流动/非流动负债、负债合计、所有者权益合计；期间按资料动态扩列，不保留空期间 |
| 24 | 收入预测 | 产品/客户/项目构成、资料已给出的预测年度收入及假设，不把预测写成实际，不生成无输入的预测列 |
| 25 | 投资亮点 | 每项形成`投资亮点—业务基础—投资价值`一一对应，不以口号或产品清单替代业务事实 |
| 26 | 退出路径 | 路径、实现条件、时间/规模/治理/资本市场前提；使用方案式陈述，不把内部不确定性清单填入表格 |
| 27 | 风险 | 已确认风险事实、投资影响和具体风险控制安排；不用“状态：已接受/交割条件/投后事项”代替安排内容 |

## 三、机器门禁重点

严格模式至少自动拦截以下退化：

- 表3任一主题只有口号、空泛宏观判断或缺少对目标公司的影响；
- 表5投资价值少于3个或多于5个项目特定论点，或没有成组的标题/论证段落；
- 表3任一主题不足2个自然段或内容低于最低颗粒度，表5投资价值低于最低字符/段落门槛；
- 表12混入诉讼、处罚、失信、债务、租赁、劳动社保、数据测绘或环保消防事项；
- 表13/14未明确区分核心产品与核心技术，或用认证/专利名称替代产品技术描述；
- 表22/24存在整列空白、横杠或占位符的预测年份；
- 表23缺少资产/负债分组、合计行或现金流量表分组；
- 表15、20、25、27存在字段空缺或仅有标签没有分析；
- 表23/24为了复制样例行数而保留空行、无输入年度或大量“不纳入本次测算/未取得”；
- 参考密度显著收缩的表格没有足够项目事实与分析；不得靠添加开放式资料限制通过密度门禁；
- 用统一字体/字号压缩页面，或把多个论点改造成单段、单run软换行。
- 表3或表5叙述正文使用单倍行距，或同一视觉角色在不同表格中出现不一致的行距、段前和段后。
- 1.5、2.6、5.2.3或投资结论重复列示原始亏损、负现金流金额，或2.6出现无投资意义的零星个人款项。
- 正文或表格出现写作推理标签，结论出现“核心逻辑由…项事实构成”等提纲式语言。
- 第11表在关联事实后追加风险动机/后果评价，或第18表使用“商业验证”固定列并与4.2重复。

自动校验结果必须与证据台账和逐页人工检查合并判断，不得只看字符阈值放行。
