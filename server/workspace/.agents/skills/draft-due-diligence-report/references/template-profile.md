## 参考报告结构证据

- 使用Codex捆绑版LibreOffice并配置其`Resources/fontconfig/fonts.conf`后，参考报告有效渲染为44页。未配置`FONTCONFIG_FILE`时曾异常压缩为28页并丢失中文正文，该结果无效，不得作为页面基准。
- 最终页数仍以冻结DOCX在交付环境更新字段后的结果为准；任何无内容解释的显著页数收缩、正文字符骤减或页眉缺失均视为渲染失败。
- 4个A4分节：纵向、横向、横向、纵向。
- 一级标题9个、二级标题29个、三级标题21个；正文按项目证据自然调整，不机械复制数量。
- 27张原生表格，主要使用`Table Grid`；灰色表头、黑色全框线。
- 目录包含57个`PAGEREF`字段；3个页脚`PAGE`字段。
- 页眉固定声明：`申明：本报告为赛智伯乐内部项目文件，禁止外传，报告内容仅代表机构观点`。报告标题只用于封面，不要求作为逐页页眉。

表格段落按视觉角色统一而不是按单张表临时压缩：标签和表头为1.15倍行距，普通表体为1.5倍行距，段前段后均为0；密集财务表只有在`table-layout-profile.json`明确列出时使用1.15倍。表3和表5的叙述内容不得改为单倍行距。

中文字体需同时写入East Asia字体属性。渲染环境可配置字体替换用于视觉检查，但DOCX交付门禁检查写入的字体名，正文和表格必须为`仿宋_GB2312`，标题必须为`黑体`。

`style-profile.json`是上述角色的机器门禁。`font_aliases`只保存交付DOCX允许写入的精确字体名；渲染替代字体另存于`render_font_aliases`，不得作为DOCX验收别名。

## 标题与编号

- 使用真实`Heading 1/2/3`样式，显示`1、`、`1.1`、`1.1.1`层级。
- 目录由标题样式生成；不得手工键入页码。
- 封面公司全称与报告名为两个独立居中段落；封面禁止横线、段落边框、装饰表格、文本框和形状。
- 目录必须是TOC/PAGEREF域配合点引导符，不得以表格模拟；更新后页码不得全部为0。
- 封面后是目录，目录后直接进入`1、投资概要`及`1.1 公司情况`；不得新增“报告基础与范围”“编制说明”“证据口径”或其他样例外前置说明。
- 模板中未设置表后正文槽位的位置不得插入表后说明、来源串或“行业判断/项目判断”。交付文档不得显示`SRC-*`、`CLAIM-*`或内部路径。
- 一级标题默认另起页；若前一章尾部残留无结构作用的连续空段落，会与`pageBreakBefore`叠加生成仅有页眉页脚的伪空白页。先清理空段落并保留分节段落，再复测；不得靠删除标题层级掩盖问题。

## 表格

- 灰色表头、黑色0.5pt左右全框线、正文垂直居中。
- 严格样例模式保留参考表格的视觉角色；2.5的旧人员表默认替换为组织架构图，业务表逐张遵守`table-semantic-contract.md`。表头不写来源、核验过程、证据状态、估值排除或模拟口径，表体不得填入与表头不相干的内容。
- 2.6使用`关联主体或事项｜关联关系及投资相关情况`，数据行按重大关联主体/事项动态生成，不保留无事实意义的固定行。
- 4.1表采用`业务板块｜主要产品/服务｜收入来源｜销售与交付方式`或目标公司业务同义字段，不设置独立`商业验证`列；客户合同、验收、开票和回款集中在4.2。
- 2.3.1使用`股东｜认缴注册资本（万元）｜持股比例`呈现报告日有效结构，本轮投后股权归入7.2；2.7使用`类别｜资质、认证或荣誉情况`灰色表头；表13/14分别承载核心产品和核心技术；表23使用纵向三分组财务表。
- 第27张表在保持原视觉角色和列宽的前提下使用`风险类别｜具体风险描述｜风险控制安排`，体现投资经理已经形成的处置；不得使用`风险控制建议`。
- 数字、金额、比例右对齐；短状态和日期居中；叙述列左对齐。
- 列宽按内容分配，禁止机械等宽；叙述列获得主要宽度。
- 长表重复表头，不设固定行高；关键财务表可横向跨页。内容容纳不足时拆表、续表或横向排版，禁止缩小表格字号。
- 表格上下留出自然间距，不用空白段落制造大间隔。
- 模板中的占位文本已位于显式格式化的原型run中；生成器只替换文字，或从同角色原型复制`w:rPr`。不得用`paragraph.clear()`、`cell.text=""`或统一字体函数抹除这些格式。

## 模板使用

1. 从`primary-dd-report-template.docx`复制工作副本。该资产是保留封面、目录域、标题、4个分节和27张表角色的脱敏结构底稿，不是空白文档。
2. 替换所有占位符并删除不适用的占位说明；不得从`reference-dd-report.docx`复制任何事实段落。
3. 复用样式、主题、页眉页脚和表格组件；按需要新增横向节。
4. 生成后运行占位符、样例词和旧项目信息泄漏检查，并与只读参考逐页比较视觉角色而非像素内容。
5. 默认模板尾章标题为`投资结论及建议`，用于已完成尽调、拟提交投资决策的建议稿；只有用户明确要求投委会批准后的决策终稿时才改为`投资结论`。

## 字体安全渲染

- 通过`scripts/render_docx_fontsafe.py`调用文档技能的`render_docx.py`，不要直接运行未配置字体环境的`soffice`。
- 记录渲染器路径、`FONTCONFIG_FILE`、页数和正文可提取字符数。命令退出码为0不代表渲染正确。
- 首轮渲染必须核对目标公司名称、内部声明、结论和核心数字是否可提取；若缺失，先修复字体环境，不调整正文或缩小字号迎合错误分页。
- 同一冻结DOCX在同一渲染器与字体配置下独立重渲染时，页数、方向和页面像素应保持一致；PDF字节哈希可能因元数据时间不同而不同。
