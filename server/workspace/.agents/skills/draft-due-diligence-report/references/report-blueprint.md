# 上会尽职调查报告结构

## 前置部分

1. 封面：目标公司全称、`上会尽职调查报告`、出具团队、日期；
2. 内部声明：页眉写明内部文件、禁止外传及观点属性；
3. 目录：显示三级标题与页码，正文更新后刷新；

严格样例模式下，封面后进入真实目录，目录后直接进入`1、投资概要`。不得在封面、目录与`1.1 公司情况`之间新增“报告基础与范围”“编制说明”“证据口径”或其他说明性模块。资料截止日、重要限制和口径差异仅放入样例已有字段：相关表格右栏、财务期间/单位带、风险表或结论中的必要限定，不单独扩展结构。

本蓝图列出的标题、表格与正文槽位构成交付结构。内部证据台账可以比报告更细，但不得以表后来源段、脚注、尾注、`SRC-*`编号或证据索引附录进入默认交付物。

## 1、投资概要

用表格和短段落让投委会快速掌握：

- 公司基本事实与核心判断；
- 本次交易金额、方式、估值、股比和主体；
- 行业阶段与竞争位置；
- 商业模式、经营现状和财务摘要；
- 投资价值、关键风险和已经形成的控制安排。

投资概要不引入正文没有展开的新事实。

严格样例模式下，1.1—1.5分别使用公司情况、交易要点、行业概况、商业模式和经营管理、投资价值与风险五张键值表。特别要求：

- 1.1明确区分注册地址和实际经营地址，两个地址字段只写地址本身；租赁面积、租期、租金和园区说明归入经营场所或法律章节。发展阶段用一句自然陈述概括技术、产品、客户/收入和组织状态，核心判断保持简洁；不显示“中心判断：”等内部写作标签；
- 1.2只消费交易登记表中`current_round_id`的最新有效版本。上一轮金额、估值、投资人和保护条款不得作为本轮要点；最后一行优先使用`主要权利与交割安排`，直接写保护性权利、付款对象与步骤、交割及工商变更安排；不得使用“按……口径执行/办理”概括交易义务；
- 1.3三个固定主题分别至少写2—3个自然段，每个主题形成“阶段/环境结论—关键驱动与约束—对公司与投资的含义”，避免政策口号、泛泛增长和无事实空话；
- 1.5投资价值选择3—5个项目特定论点，每项由事实基础、可持续能力、商业/竞争含义和本轮投资意义构成完整分析链，不用一句优势概括替代分析；
- 1.3按`行业所处发展阶段｜市场环境｜关键影响因素`组织与目标公司相关的行业事实与商业意义，不追加估值排除、来源口径或防御性尾句；
- 1.5按3—5个项目特定价值点展开，每点由小标题和一段事实依据构成；不为满足固定数量堆叠重复论点。
- 1.3和1.5采用投资经理决策层视角：结论直接落到目标公司的需求、竞争位置、商业验证和投资意义；不得在价值判断后追加“但、仍需、取决于、不能直接证明估值”等防御性尾句。主要风险写明已核实事实、投资影响和已形成处置。

## 2、公司概况与法律合规

按材料选择：

- 公司基本信息、历史沿革、注册资本和实缴；
- 股东、完全稀释股权、穿透结构和实际控制人；
- 历史融资、优先权利、股权限制和期权池；
- 核心团队、劳动/聘任状态、组织架构和关键人风险；
- 子公司、关联方、关联交易；
- 资质许可、知识产权权属、重大合同、诉讼处罚、税务与劳动合规；
- 内控制度及实际执行情况。

第三方法律尽调的基准日、依赖范围和取证属性留在内部台账。可见正文直接陈述已经形成的法律事实和结论；只有专业报告性质本身直接影响结论时，在对应槽位说明一次。

2.4核心团队按人员设置三级标题，每名核心成员至少覆盖现任职责、教育背景、关键任职经历、代表项目/成果和与目标公司业务的匹配性。2.5默认使用组织架构图；优先复用资料中的清晰原图，否则根据已核实的部门、人员和汇报关系重绘，并在图下说明主要职责和组织阶段。只有无法形成可靠层级图且用户允许时才使用`部门｜人员配置｜主要职责`作为降级方案。

`2.3.1 公司股东`使用报告基准日有效股东结构，表头为`股东｜认缴注册资本（万元）｜持股比例`；已签署生效但尚未登记的历史融资可在表前说明法律状态。本轮交易完成后的投后结构归入`7.2 公司估值与投资方式`。2.6使用`关联主体或事项｜关联关系及投资相关情况`，只列与控制权、治理、资金占用、知识产权、竞业、税务或交易判断有关的重大关联事项；右栏只写关联事实及已经形成的离任、退出、权属或交易安排，不追加“避免/防范冲突”、“相关不利后果”等风险解释。实质性风险只在第8章分析一次。小额已结清报销及无投资影响的临时垫付留在内部台账。经营亏损、现金流和估值调整不属于本节。2.7使用`类别｜资质、认证或荣誉情况`，只列业务资质、认证、政府/行业认定和荣誉；诉讼处罚、失信、债务、租赁、劳动社保、数据与测绘、环保消防等移至法律分析或风险章节。

## 3、产品与技术

- 产品/服务定义和目标用户；
- 核心技术路线、关键模块、成熟度和可替代性；
- 产品矩阵、交付形态、定价或收费方式；
- 研发里程碑、测试/认证、技术债与已确认的量产/部署边界；
- 知识产权、开源软件、数据来源与数据权属；
- 已形成的技术成熟度结论，以产品阶段、实际交付、测试或应用结果陈述，不展开未采用的技术主张和估值排除过程。

把论文、Demo、PoC、工程化产品和商业交付分开陈述。

产品概念总览必须分开呈现核心产品和核心技术。核心产品使用`核心产品｜产品定义/核心功能｜应用场景/目标客户｜商业化进展`；核心技术使用`核心技术｜技术描述/原理｜技术来源/权属｜技术门槛/产品作用`。认证、资质或专利清单不能替代产品/技术描述。技术沿革另可使用`年份｜代表成果｜对现有产品/技术的作用`，代表成果必须可溯源，第三列说明它已经形成的产品或技术作用。

## 4、业务情况

- 商业模式、销售路径和收入来源；
- 客户结构、项目状态、合同、验收、开票和回款；
- 供应商、采购、成本、交付依赖和集中度；
- 产能/服务能力、项目管理、售后和质量控制；
- 关键业务指标和单位经济性（材料支持时）。

客户验证按“已回款—已验收—已签合同—框架/试用—PoC—意向/Pipeline”分层。

4.1商业模式与销售策略只固定“产品/服务、收费/收入、销售和交付”的表意角色，不固定使用`商业验证`列。项目制技术/数据服务优先使用`业务板块｜主要产品/服务｜收入来源｜销售与交付方式`；软件平台可使用`产品/服务｜收费模式｜获客方式｜交付与续费`；硬件可使用`产品线｜销售模式｜交付方式｜收入构成`。合同、验收、开票、回款和复购证据集中写入`4.2 客户验证情况`，不在4.1重复。

## 5、行业和市场

- 行业定义、价值链和发展阶段；
- 政策与监管；
- 目标市场和可服务市场，明确来源、日期和测算方法；
- 竞争格局、可比主体和差异化；
- 需求驱动、采购周期、进入壁垒和替代风险。

行业章节必须服务于公司判断，不堆砌宏观资料。

行业分析只出现在`1.3 行业概况`和本章既有标题/正文槽位内。不得在其他章节或每张表后重复新增名为“行业判断”“项目判断”“本节判断”的固定模块。

## 6、经营与财务

- 报告范围、会计期间、币种、单位和是否审计；
- 收入、成本、毛利、费用、利润和现金流；
- 资产负债、现金、应收、存货、固定资产、负债和或有事项；
- 客户/项目收入质量、回款与收入确认；
- 财务尽调调整、异常项目和税务影响；
- 预算、预测、核心假设和敏感性；
- 历史实际与预测之间的桥接。

6.1业务拓展规划可使用`阶段｜研发目标｜商业目标｜组织目标`。人员预测表首列使用`人员类别`，收入预测表首列使用`营业收入构成`。只展示资料具有可采用输入的年度，不用空列、“不纳入本次测算”或机械外推填满五个连续年度。

宽财务表可使用A4横向分节。不得通过缩小到难以阅读的字号强塞进纵向页。

6.2历史财务优先使用纵向分组、多期横向比较表：第一列为科目，后续列为资料实际覆盖期间；行分`利润表`、`资产负债表`、`现金流量表`。资产负债表至少清晰列出流动资产、非流动资产、资产合计、流动负债、非流动负债、负债合计和所有者权益合计。不得保留没有任何数值的期间列，也不得以净资产替代完整资产负债分类。

## 7、投资方案

- 投资主体和载体；
- 增资、老股、可转工具或SPV结构；
- 投资金额、每股价格、投前/投后估值和投后权益；
- 同轮融资、交割后完全稀释股权和资金用途；
- 已谈保护条款、公司治理和交割条件；
- 估值依据、回报或退出路径（有可靠输入时）；
- 独立合规性分析的结论摘要（如已制作）。

## 8、风险识别与控制

使用表头：`风险类别｜具体风险描述｜风险控制安排`。

只保留影响投资判断的项目特定风险。第二列直接写已确认的风险事实及投资影响，第三列写具体交易条款、交割安排或投后责任。不在单元格末尾追加“状态：已接受/交割条件/投后事项”。重大风险在投资概要和结论中只回扣决策影响和已有安排，不复制整张风险表。

原始亏损、负现金流及财务调整金额只在第6章或本章最相关风险记录中披露一次。`1.5`、`5.2.3 综合评估`和投资结论不重复列示原始负数；如需回扣，只说明公司处于投入期及其对交易安排的影响。

## 投资结论及建议

`investment-recommendation`按三个自然段收束：

1. 公司定位、核心产品/服务和当前发展阶段；
2. 行业机会、已形成的商业基础、团队及产业资源；
3. 具体投资建议，写明投资主体/载体、金额或区间、当前资料支持的估值类型/区间、交易方式和投后权益或计算机制。

结论不使用“核心逻辑由三项事实构成”等提纲式表述，不复制风险表或交割/投后控制清单，不使用`本项目投资结论为同意……`、`原则上同意`或`有条件推进`等审批口径。具体投资建议只在末段出现一次；其他章节仍禁止“建议核验/补充/整改”等顾问式语言。

`final-investment-decision`在用户明确说明已决定投资、确定投资或要求以已决定投资的投资经理视角写作时使用`投资结论`，直接记录当前轮次交易方案和决策基础，不使用“建议”。没有明确交易方案、重大证据仍缺失或存在未处置的否决性风险时，停止生成两种终稿，返回资料补充或冲突裁决流程。

## 附录（仅在用户明确要求时）

- 资料范围与重大缺口；
- 股权结构或穿透图；
- 关键合同、知识产权或财务明细；
- 用户可读的资料清单；不得使用内部`SRC-*`、`CLAIM-*`编号或工作路径。

附录不用于隐藏正文应披露的重大风险。
