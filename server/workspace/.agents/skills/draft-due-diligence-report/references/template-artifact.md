## 投资概要写法

投资概要保持五个二级小节，不增加三级标题或报告自述；用表格呈现键值信息，用正文呈现行业判断和投资价值。

1. `1.1 公司情况`：6行，依次为公司名称、成立时间、注册地址、实际经营地址、法定代表人/实际控制人、主营业务。
2. `1.2 交易要点`：6行，依次为投资主体、投资方式、投资金额、投资估值、项目类型、收益与责任安排。
3. `1.3 行业概况`：2至3段正文，说明行业阶段、下游采购标准和竞争重心。
4. `1.4 商业模式和经营管理`：5行，依次为商业路径、客户与生态、组织与人员、经营现状、管理基础。
5. `1.5 投资价值与风险`：按“行业定位与付费基础、差异化技术路线、数据/反馈闭环壁垒、客户或生态商业验证、团队产业化能力”列示5条完整价值正文，再以一个主风险及其传导段收束；交易安全边际放在7.2。

写法遵循德塔V5：先陈述事实，再给投资判断；长单元格用自然分段，不使用口号式页首结论。风险必须指出最强反向事实，不以资料清单代替判断。
