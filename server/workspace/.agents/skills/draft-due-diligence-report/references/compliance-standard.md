# 投资合规性说明标准

仅在用户要求独立合规说明时使用。它是对基金/投资主体能否实施本次交易的专项说明，不是公司全景尽调报告。

## 参考资产

`assets/reference-compliance-statement.docx`为只读结构和语气参考。样例项目事实不得复用。

## 默认结构

1. 标题：`关于[项目名称]投资合规性的说明`；
2. 公司情况介绍：公司简介、核心团队、产品及技术；
3. 投资理由：行业方向、团队、技术、商业化和产业协同；
4. 投资计划：主体、方式、金额、估值、股比、SPV和同轮安排；
5. 投资情形分析；
6. 综合结论、出具主体和日期。

## 投资情形分析

按基金合伙协议和适用规则逐项核对，至少考虑：

- 是否触及投资限制或禁止事项；
- 是否影响地域返投或其他政策性要求；
- 是否构成关联交易及审批是否充分；
- 是否符合基金投资方向和产业范围；
- 是否符合投资配置、投资阶段和载体要求；
- 是否符合集中度、单项目比例和权限要求；
- 是否存在其他违反法律法规、监管规定或合伙协议的情形。

没有基金合伙协议、返投口径、实缴规模、已投金额、关联关系核查或集中度上限时，不得写“符合”。应写明资料未取得、暂无法判断及所需补充依据。

## 计算与证据

- 集中度使用合伙协议定义的分母，不自动使用认缴或实缴规模；
- 返投使用协议定义的项目、金额和穿透规则；
- SPV同时披露基金出资、SPV总出资、费用/收益安排及穿透权益；
- 投资金额、估值和股比与尽调报告及交易文件一致；
- 每项结论能定位到合伙协议条款、基金台账、关联核查或交易文件。

## 语气

结论使用“根据现有材料”“在完成投资决策程序及交易文件约定的前提下”等限定。只有证据完整时使用确定性“符合”；不得用合规说明替代法律意见或基金管理人的正式审批。

## 版式

默认A4纵向、宋体/仿宋类正文、黑体标题、数字编号、简洁公文式、右对齐落款和日期。除非用户要求，不复制尽调报告的目录、宽表或长篇章节。
