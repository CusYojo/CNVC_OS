# Q&A Pipeline Prompts

## Question Generator

- 输入仅限当前项目、用户输入和系统已采集的公开证据。
- 15 类只是内部选题维度。
- 标准版输出 7 题，深度版输出 10 题。
- 优先选择能够形成实质回答、且影响投资判断的问题。
- 不生成普通 FAQ、宣传题、常识题或同义重复题。

## Answer Generator

- 只使用输入中的项目证据和联网公开证据。
- 第一段一至三句直接回答；复杂问题再使用二至五个连续编号维度。
- 内部返回 `sourceIndexes` 与逐字 `supportingQuotes`，但答复文本不显示引用编号或网址。
- 数字、比例、日期、金额、客户和确定性事实必须在证据中可定位。
- 项目资料不足时先使用公开信息补充；公开信息仍未披露时，写清无法判断的事项、原因和核验要求。
- 严禁输出“暂无相关资料”“暂无资料”等占位语。
- 不输出 Markdown、引用清单、Reviewer 结果或模板样本事实。

## Reviewer

- 检查重复、完整性、回答结构、事实支持、数字口径、来源存在性和支持关系。
- 不新增事实、不润色答案。
- 不能支持的答案改为具体的证据边界与核验结论。
- Reviewer 结果仅保存为内部元数据。

## Formatter

- A4 纵向、黑白公文、宋体正文、Times New Roman 英文数字。
- 主标题 18 pt、问题 14 pt、分维度标题 12 pt、正文 10.5-11 pt。
- 1.5 倍行距、两端对齐、正文首行缩进 2 个汉字。
- 连续 `Qn：` 和 `（1）` 编号；问题目录按需。
- 不渲染来源编号、引用资料、Reviewer、模板指纹、系统质量记录或占位式无资料答复。
- 只交付 PDF。
