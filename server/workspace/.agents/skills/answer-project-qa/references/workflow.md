# Q&A 端到端 Workflow

## 阶段 1：Template Parser

读取 `docs/Q&A/` 五份 PDF，提取页面尺寸、标题、编号、回答标签、段落层级、表格和图片使用方式。输出不含样本事实的模板画像。

## 阶段 2：Current Project RAG

校验用户、项目、权限和资料截止日；只检索当前项目授权资料，清理乱码、占位语和重复分片。

## 阶段 3：Public Web Research

围绕公司主体、产品技术、团队、市场、竞争、客户、商业模式、融资、合规和动态执行 SearXNG 检索。保留网页标题、摘要、网址、公开日期、访问日期和检索记录。全部检索失败时停止正式任务。

## 阶段 4：Question Generator / Duplicate Checker

15 类仅作内部选题池。标准版生成 7 个、深度版生成 10 个最具投资决策价值且证据覆盖较好的问题；去除同义重复并重新连续编号。

## 阶段 5：Answer Generator

先使用项目证据，再使用联网公开信息。每题先直接回答，复杂问题再给二至五项分维度论证。不得输出占位式无资料答复；未公开事项形成具体的核验结论。

## 阶段 6：Reviewer

在内部检查重复、完整性、事实支持、数字、来源存在性和支持关系。Reviewer 不新增事实。失败答案改为具体证据边界；审阅结果不进入可见正文。

## 阶段 7：Formatter

按核心规范生成 A4 黑白公文版式。可在服务器内部生成临时 DOCX 作为排版中间件，但正文不得包含来源编号、引用资料、Reviewer、模板指纹或系统质量记录。

## 阶段 8：PDF Export / Visual QA

将最终排版转换为 PDF，只登记 PDF artifact。检查 PDF 头、CJK 字体、页数和文本，再逐页渲染检查截断、重叠、孤立标题、表格断裂和异常空白。不得登记 DOCX、PPT 或 PPTX。
