# Q&A 端到端 Workflow

## 阶段 1：Template Parser

读取 `docs/Q&A/` 五份 PDF，提取页面尺寸、标题、编号、回答段落层级、表格和图片使用方式。模板中的旧式回答标签只用于识别内容边界，不进入新文档；输出不含样本事实的模板画像。

## 阶段 2：Current Project RAG / Direct Public Search / Page Verification / Model Summarization

校验用户、当前会话绑定的项目、权限和资料截止日；以当前项目资料库中的上传原件、知识片段和访谈材料为主要证据，项目档案和用户本次明确输入为补充；清理乱码、占位语和重复分片。线索池摘要、标签、评分和融资线索只按待核验线索进入证据。对会改变阶段判断或下一步建议的缺口，由系统仅使用公开项目名称和检索主题直接发现候选原始页面，项目资料库正文与内部字段不进入外部搜索词；系统先删除导航、榜单入口、相关推荐、联系方式、登录入口、备案和版权页脚，再执行公网地址安全、项目名称匹配、页面正文、可信域名和资料截止日检查。只匹配简称或近名的页面不得确认项目工商、股权、财务或融资事实。通过后缓存到当前项目资料库，并交由项目大模型与本地资料一并总结。不得调用或依赖 SearXNG，不得把搜索摘要、模型记忆、虚构链接或无法访问页面作为证据。

## 阶段 3：Question Generator / Duplicate Checker

15 类仅作内部选题池。优先响应用户本次关注点，再根据当前项目证据丰富度选择主体、股权与治理、团队、产品与技术、市场与客户、商业模式、财务、融资与估值、交易方案和风险问题。每题必须检验一个会改变投资决策的假设，并以因果、比较、阈值、反事实、压力测试或失效条件形成递进追问；浅层信息盘点题直接淘汰并由高价值问题补位。默认排除“阶段与推进建议”；只有用户明确要求是否继续投资、是否启动尽调或下一步如何推进时，才用自然的投资判断设置一题，且不得展示内部项目状态词。标准版目标 7 个、深度版目标 10 个；不得生成泛行业研究问题。

## 阶段 4：Answer Generator

只使用当前项目资料库、项目档案、用户输入和经系统页面核验的当前项目公开资料。先确认主体和时间线，选出一个中心判断及真正改变判断的项目特有事实，再按因果、比较、阶段或约束关系直接写成 answer。一个自然段能够讲清时不强制拆分，多项事实存在不同逻辑时再分段，最多六段；不显示“答复：”“回答：”、编号、小标题或字段标签。会议纪要可以作为内部证据，但先删除纪要名称、会议时间、地点、参会人员、议程和原始章节，再将收费方式、实施流程、客户进展、资源投入和管理层陈述改写成完整事实。有多条证据时综合时间线、量化指标、信号强弱、交叉印证或冲突、投资影响和下一步动作，不只摘抄材料。行业内容只能服务于当前项目判断；人员、研发合作、知识产权许可或转让关系必须写清关系类型。不使用固定句架；核验动作只保留最可能改变投资判断的一至三项。不得输出占位式无资料答复；内部证据未覆盖的事项改写为自然的有限判断和具体核实动作。正文不得出现“项目资料”“项目材料”“资料库”“资料截止日”“经系统核验”“公开页面”“会议纪要”“交流纪要”“访谈纪要”“回填资料库”、内部项目状态词、OA 或系统按钮等生成、资料加工或内部流程词。

## 阶段 5：Reviewer

在内部检查重复、完整性、当前项目聚焦、事实支持、数字、来源存在性和支持关系，并逐题检查是否重复工商或融资事实、是否夹带材料标题或孤立短语、是否残留内部项目状态词、编号、小标题或字段标签。用户明确要求阶段判断时，再检查建议是否自然、明确并有依据。Reviewer 不新增事实。失败答案改为具体判断边界；审阅结果不进入可见正文。

## 阶段 6：Formatter

按核心规范生成 A4 黑白公文版式 DOCX；使用目录时完整列完全部目录项，再另起页进入正文 Q1，不在固定题号处拆页或重复标题；模型若返回“答复：”“回答：”、编号或结构标题，先按内部语义归位，再删除标签、编号和标题，只保留段落正文；根据内容密度合并或拆分为一至六个自然段，并避免相邻问题使用相同段数、首句和收束句；删除来源材料自带的“（四）”“（1）”“2、”等章节编号；长段落允许自然跨页，避免孤立短行和异常留白；正文不得包含 Markdown、网页框架、来源编号、引用资料、Reviewer、模板指纹、系统质量记录或资料加工话术。

## 阶段 7：DOCX Review / Visual QA

检查 OpenXML、中文编码、字体、页数和文本，并逐题验证正文为一至六个自然段且不含“答复：”“回答：”、分维度编号、小标题、字段标签或资料加工话术；检查相邻问题是否机械复用相同句式；在可用环境中使用 Word/WPS 打开，逐页检查截断、重叠、孤立问题、表格断裂和异常空白。只登记 DOCX，不生成或登记 PDF、PPT 或 PPTX。
