# 参考模板驱动可编辑 PPT 输出契约

## 最终产物

最终成品必须同时保留图片型 PPTX、桥接 PDF、元素级可编辑 PPTX、逐页图片、图片生成证据、语义覆盖清单和交接报告。只有 `pipeline-handoff-report.json` 与 `conversion-handoff.json` 均通过时，元素级可编辑 PPTX 才能标记为可下载成品；Gorden 四层中间稿只用于视觉与分层验收，不替代最终桥接转换产物。

## 内容与证据

正文仅使用用户资料、项目资料库和已核验公开来源。输入资料先按主体、日期、关系、数字口径和来源去重；同一事实、文件、数字或来源只在语义最匹配的页面完整表达一次，其他页面不得重复复述。融资、估值、收入、客户、订单和交易条款无法核验时必须进入尽调缺口，不得用模板样本或模型常识补齐。

每条重要结论都绑定 `source-registry.json` 中的实际来源。技术结论优先绑定论文、专利、官方技术材料或其他一手来源。模板只授权复用结构、排版和视觉语言，模板样本中的公司、人物、Logo、日期、页码、数字和结论不得进入当前项目成品。

## 页面与来源披露

演示稿面向投资委员会或用户指定受众，页面不得显示内部 Skill 名称、模型过程、搜索摘要、内部索引或文件系统路径。页面正文可以使用简洁来源脚注；最后一页或末尾来源附录仅列实际使用来源，并使用人类可读的标题、机构、日期与网址。未被任何页面采用的资料不得混入引用资料。

最后一页同时包含投资结论、后续事项和责任声明。无法验证的公开说法必须明确限定为公开信息或待核验事项，不得写成已尽调确认事实。

## 三技能边界

`create-reference-driven-editable-ppt` 是唯一总编排器；`GordenSuperPPTSkills` 负责模板摄取、页面策划、网关出图和四层资产；`pdf-to-editable-ppt` 负责桥接 PDF 的元素级可编辑化、渲染、水印、语义构建与前景对象验收。除这三个技能外，不得调用其他 PPT 构建、内容替换或套版技能。

最终可编辑文件至少满足：Open XML 包有效、每页有原生可编辑文字、背景和框架为独立对象、模板样本无残留、文字与视觉无明显重影或裁切、所有报告哈希与当前产物一致。任一门禁失败时必须保留任务参数并报告具体停止阶段，不得交付半成品。
