# 发布验收清单

## 事实、数字与断言

- [ ] 每项重大事实有来源 ID、适用日期、对象、期间、单位和状态。
- [ ] 所有冲突值已裁决；被否决值未进入正文。
- [ ] 回答中的非年份数字可在事实库或问题中找到。
- [ ] 管理层预测、需求意向、PoC、测试、采购和联合研发没有越级表达。
- [ ] 联合研发、IP、控制权、激励、竞业和不可替代性的每项正向断言都有 `claim_support`；对外模式没有证据的制度断言已删除。
- [ ] 产业赋能仅在已核实投资关系及已发生协同行为时确定表达；客户、样品测试方和合作方没有被误称为产业股东。

## 定位与问题设计

- [ ] 已锁定 `audience_mode`；对外Q&A与内部交易方案没有混写。
- [ ] 对外Q&A的问题本身没有IP缺口、赔偿、分期付款、预留、补偿或底座依赖等内部风控议题。
- [ ] 叙事模式与用户用途或参考模板一致。
- [ ] `dual_use` 完整输出赛道三分法和项目差异化站位，且站位事实可溯源。
- [ ] 共 6—9 题，编号连续，互不重复；问题来自投资判断，不是逐题拼接两组材料数字。
- [ ] 至少一半对外问题不依赖数字仍能成立；六至七题至少采用三种问题原型，八至九题至少采用五种。
- [ ] 对外模式覆盖估值对标、客户验证、收入质量、产品/技术价值、商业化与组织能力；内部模式另行覆盖治理/IP和交易安排。

## 回答质量

- [ ] 对外正文没有“经项目组核查、项目组支持、未计入定价、分期支付、专项预留、原股东补偿”。
- [ ] 对外每题 1—4 个自然段、无最低字数；内部模式每题 2—4 段、450—1000 字。长度由问题决定，没有机械堆数字。
- [ ] 差异化机制传导到客户采购、提价、复购、交付效率或投资回收期。
- [ ] 商业模式明确区分短期现金流、中期产品化和长期平台化。
- [ ] 估值对标先解释行业估值逻辑，再做自身倍数和基准/成长/期权分层。
- [ ] 海外基础模型和成熟平台只作赛道上限，对标段写明轮次、规模、产品与收入阶段差异，未直接套用倍数。
- [ ] 对外正文没有风险清单、待确认事项或交易安排；这些内容已留在内部底稿或《交易方案》。
- [ ] 全文没有“阶段约束”“价值释放条件”“治理资产”“资本上限”“成长锚”“平台飞轮”等造词。
- [ ] 正文段首没有“小标题+冒号”，相邻问题没有机械复制相同骨架。
- [ ] 对外每题在前一两句内回答问题，不出现“项目组”；具体商业结果已经完整回答时没有强制补写投资结论。
- [ ] 第一口是完整判断句，没有“合理。能。具备。清晰。较好。”等单字模板开场；没有客户入口、高维数据积累、价值释放、平台飞轮、生态闭环等包装词。
- [ ] 分点题不超过全文一半；其余问题按比较、机制、案例、产品角色或团队执行自然展开，没有每题机械套三点。
- [ ] 相邻问题没有连续复用相同首句和相同收束句；数字只在真正改变判断时出现。
- [ ] 没有为了凑段落或字数保留重复总结，同一客户组合没有在过半回答中机械复现。
- [ ] 句长由内容自然决定，没有连续碎句、刻意反问、制造出来的金句或节奏配额。
- [ ] 没有“这个顺序更能解释……”“最有分量的支撑是……”等替听众概括证据权重的工整元话语，重点落在订单、验收、扩品、复购和回款本身。
- [ ] 需要因果解释的问题已讲清客户动机或经营机制；事实型问题没有为填 `why_layer` 发明原因。
- [ ] 结尾没有集中使用“已经形成、已经验证、具备……能力/基础/质量”；具体结果已经回答问题时没有多余总结句。
- [ ] 已核实事实优先正向陈述，没有“不是以远期设想定价”“不包含意向金额”等防御性对照；“证明了”“已降低”等措辞与证据强度一致。
- [ ] 技术题先写技术如何转化为客户成果、付费和复购，没有以“数据处理/仿真/交付能力”分类清单替代商业论证。
- [ ] 没有“建议公司、公司需要、后续需要、只有完成后才能证明”等继续尽调式表达。
- [ ] 未成熟事项没有进入对外 Q&A，也没有“尚未完成、纳入投后、提交审议”等过程表述。
- [ ] 没有“这说明、共同证明、这体现、这表明、由此可见、据此”等讲解式推导词。
- [ ] 事实等级与来源保留在底稿；对外正文没有“据公司披露、据管理层、管理层表示”等资料转述口吻，也没有把内部口径误写为第三方核验、双方谈妥或协议已签署。
- [ ] 没有“反向解释”“另一种解释”等内部投研标签，也没有为语气而粉饰负面财务事实。
- [ ] 现有商业化/组织题已被升级而非重复新增；全文不超过 9 问。
- [ ] `reference_faithful` 标题后直接进入 Q1，没有前置总览，但私有赛道地图及必要模块仍完整。

## 红队、评分和视觉

- [ ] 红队同时检查防御性叙事和无证据融资包装；所有 P0/P1 已关闭。
- [ ] 总分≥85、各维度≥60%、hard failures 为空。
- [ ] `audit` 与 `verify` 均通过。
- [ ] DOCX 为单节 A4，无目录、表格、页眉页脚和页码；如有格式参考，已按参考实测参数渲染。
- [ ] 已逐页检查，无截断、重叠、乱码、孤立问题、异常留白或错误字体。
- [ ] 已逐题朗读；句子有呼吸感，停顿位置自然，正式但不像说明书。
- [ ] 已建立事实主归属；同一客户故事没有反复承担定位、产品、收入、估值和团队等多种论证。
