# 德塔式项目 Q&A 模板

## 适用模式

用户提供德塔智能项目 Q&A 或要求保持同版式时，使用 `reference_faithful`。参考文档控制可见结构与排版；本 Skill 控制事实准确、语言自然和投资逻辑。

## 可见结构

1. 居中标题：`<项目名称>项目 Q&A`。
2. 标题后直接进入 Q1，不设置执行总览、摘要、目录、引言、来源说明或页码。
3. 6—9 个连续编号问答；问题加粗，答案首段以“回答：”起始。
4. 每题 1—4 个自然段，在前一两句内回答问题；后续根据问题采用比较、机制、单一客户决策、跨行业复用或估值论证，不强制复制同一种总分结构，不为凑段数添加总结段。句子长短随内容变化，不人为安排“短句重音”。
5. 正文不显示分析标签，不以“小标题+冒号”组织段落，不新增重复的商业化/组织问题。
6. 对外模式第一句直接回答问题，随后把客户为什么采购、复购或扩品讲清楚；具体商业结果已经答完问题时直接结束，不另起“已经形成、具备能力”式总结段，不出现项目组内部口吻，也不向公司提出新的尽调任务。

## 排版令牌

- A4 纵向，单一连续节。
- 上下页边距 2.54cm，左右页边距 3.175cm。
- 中文使用楷体 11pt（DOCX 中写入 `STKaiti`，macOS Word 解析为 Kaiti SC）；西文与数字使用 Times New Roman 11pt。
- 标题 16pt、加粗、居中；标题下间距约 16pt。
- 问题 11pt、加粗；问题前约 20.4pt（Q1 除外），问题后约 7.8pt。
- 答案 11pt、不加粗、不首行缩进；固定行距约 14.4pt，段后约 7.8pt。
- 无表格、色块、图片、装饰线、页眉、页脚和页码。

## 内容映射

- Q1 自然说明行业参照的局限和公司自身定价依据，不使用“资本上限”等造词。
- 客户题按证据区分采购、共同验证和联合研发。
- 硬件题说明第三方供应的价值及量产指标，不声称“不可替代”。
- 对外模式只在已有完整落地事实时设置治理题；未决治理和交割事项转入内部材料。
- 商业化与组织题集中覆盖有证据的职责、产业协同和已落地人才机制。
- 搬迁赔偿、良率缺口、底座依赖和人力缺口等内部风控议题不进入对外 Q&A；内部模式另行说明。
- 技术题使用自然的商业化叙述：从通用工具如何转化为客户任务成果写起，再落到付费、回款和复购，不先罗列能力分类。
- 参考德塔的问题深度而非逐题复制其“第一、第二、第三”形式。问题可以从产业定位、商业机制或客户结果提出，不强制先引用材料数字。
- 参考德塔的答问感，不把每句话修成同样完整的说明句。避免“这个顺序更能解释”“最有分量的支撑是”一类整理痕迹，直接停在客户行为或经营结果上。
