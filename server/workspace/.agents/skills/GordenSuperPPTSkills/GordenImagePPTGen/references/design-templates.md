# 视觉设计模版库 — 页面类型布局规范

每个模版 = 可直接写入 image-prompt-guide.md §2 提示词模板的【版式结构】段落。
每页只需选一个模版填入，再补【页面文字】即可出图。

---

## 通用页面栅格系统

所有页面默认使用此网格基线：

```
画布: 16:9（2560×1440 或等比）
安全区: 上下各 80px，左右各 120px 留白
网格: 12 列等宽，列间距 24px
卡片圆角: 16px
卡片投影: 0 4px 16px rgba(0,0,0,0.08)
分割线: 1px solid，颜色跟随配色方案
```

## M1 封面页 cover

```
【版式结构】
- 全幅底色（跟随配色方案的底色或主色深底）
- 左上角：公司/品牌 logo 小字（可选）
- 中心大字区（垂直居中偏上）：
  - 主标题 特大号加粗，占画面宽度 60-70%，2-3 行以内
  - 主标题下方 40px 处：副标题/一句话价值主张，字号为主标题 30%
- 底部区域（距底边 120px）：
  - 一行 4-5 枚 KPI 芯片带：每枚为白底细边圆角小卡(160×64px)，内含特大号强调色数字(左) + 灰色小字说明(右)
  - 芯片带下方：日期/场合/演讲者姓名，小号灰色字
- 装饰：主标题背后有极淡的几何纹理（网格/光晕/与主题相关的抽象线稿），不抢文字
```

### M1 封面变体

| 变体 | 调整 |
|------|------|
| M1a 极简封面 | 无 KPI 芯片带，仅标题+副标题，大量留白，适合发布会 |
| M1b 数据封面 | 标题偏左上，右侧放一个特大号核心数字（如"ARR $12M"），适合路演 |
| M1c 宏大叙事封面 | 全幅暗底+中心一点光，标题在光区，适合愿景型 |
| M1d 问题封面 | 标题是反常识数据或问题句，不出现公司名，适合悬念开场 |

## M2 目录/议程页 toc

```
【版式结构】
- 顶部：左侧竖条色块(8px宽×标题高) + "目录"或"CONTENTS" 中等字号
- 主体区（6 列等宽网格）：
  - 每列一个章节卡片（竖长方形，120×180px比例）
  - 卡片顶部：章节编号大号数字（01/02/03…），与配色方案主色同色
  - 卡片中部：章节标题，中等字号加粗
  - 卡片底部：一行极简描述，小号浅色字
  - 卡片之间有细连接线（当前页指向下一页）
- 总页数 4-6 章，当前章高亮（底色加深/边框加粗），待讲章灰色半透明
```

## M3 市场/行业全景页 market

```
【版式结构】
- 顶部：小节标题区（编号竖条 + 标题 + 标题下短分割线 + 一行导语）
- 主体区（左右分栏或上中下三栏）：
  - 左/上：TAM/SAM/SOM 三层嵌套圆环图，每层标注市场规模数字
  - 右/下：3 个驱动因素卡片，每个含图标 + 因素标题 + 一句话说明 + 增长率箭头
- 底部：通栏强调色细横幅，一句核心判断（如"2030 年市场规模突破 4500 亿"）
- 装饰：背景有极淡的世界地图/行业相关纹理
```

### M3 变体

| 变体 | 适用 |
|------|------|
| M3a 时代叙事 | 中轴时间线：PC→移动互联网→AI→具身智能，每个时代一个节点+图标，当前时代高亮 |
| M3b 产业链地图 | 分层架构图：上游→中游→下游，每层横向排列 4-5 个玩家卡片 |

## M4 问题/痛点页 problem

```
【版式结构】
- 顶部：小节标题区（编号 + "为什么需要改变" 类标题）
- 主体区（左 60% + 右 40%）：
  - 左侧：3-4 个痛点卡片纵向排列
    每个卡片 = 左侧图标(圆形，主色底+白色图标，56px) + 右侧文字（痛点标题加粗 + 2 行说明 + 底部小字数据佐证）
  - 右侧：一张"现状示意"大图或一个反常识数据（特大号红字 + 感叹号）
- 视觉线索：三个痛点卡片之间有向下连接箭头，最终汇聚到右下角的红色问号
```

---

## M5 解决方案页 solution

```
【版式结构】
- 顶部：小节标题区（"我们的方案" 类标题）
- 主体区：
  - 左侧（30%）：现状混乱状态（灰色/暗色、碎片化图标堆叠）
  - 中间（10%）：一个大漏斗图或箭头（从混乱指向有序）
  - 右侧（60%）：3-4 列模块化卡片，每列 = 编号(01/02) + 图标 + 方案标题 + 2-3 个要点（带小图标项目符号）+ 底部一个量化效果（"效率↑40%"）
- 色彩过渡：左边灰暗→右边明亮（配色方案主色），暗示"解决问题"的情绪弧线
```

## M6 产品架构页 product-arch

```
【版式结构】
- 顶部：小节标题区 + 产品名
- 主体区：3-4 层水平分层架构
  每层 = 层名标签（左侧竖条，含层名中英文 + 小图标） + 该层内 4-6 个等宽模块卡（图标 + 模块名）
  层与层之间用向上箭头连接（下层支撑上层）
- 或：中心 Hub-Spoke 放射图
  中心圆 = 核心产品名 + logo
  四周 6-8 个放射节点 = 功能模块，放射线连接，每个节点含图标+功能名+一行描述
- 右下角：一个核心性能指标 callout（如"生成速度 <5 秒"）
```

## M7 产品功能详情页 product-feature

```
【版式结构】
- 顶部：小节标题区
- 主体区：Bento Box 便当盒看板
  - 左上 50%：大卡 — 主打功能标题 + 功能示意图/产品截图占据卡内 60% + 底部 3 要点
  - 右上 50%（拆成 2×2 四小格）：4 个辅助功能小卡，每卡图标 + 功能名 + 一行说明
  - 下方横幅：一句总结 + 一个关键数字
- 卡片风格：白色底卡（带微投影），彩色标题条（配色方案主色，8px 高）
```

## M8 竞争壁垒/护城河页 moat

```
【版式结构】
- 顶部：小节标题区（"为什么别人做不了"）
- 主体区：中心"护城河"同心圆图（3-4 层环）
  最内层：公司名/logo
  第二层：技术壁垒（1-2 项，如"自研 U-ViT 架构"）
  第三层：数据/生态壁垒（1-2 项，如"2500 万用户数据飞轮"）
  最外层：商业壁垒（1-2 项，如"8 大行业 30+ 场景合约"）
  每层环上有节点标注，环之间用放射线连接
- 或：2×2 四象限卡片矩阵，每个卡片 = 壁垒名 + 一句话说明 + 证据（"被 OpenAI 采用"）
```

## M9 竞对对比页 competition

```
【版式结构】
- 顶部：小节标题区
- 主体区：对比表格形式（用卡片模拟表格，不是死板的表格线）
  - 最左列：对比维度（性能/速度/成本/易用性/生态）— 5-6 行，用图标+文字表示
  - 中间列：我们 — 每格绿色/主色打底，数据高亮
  - 右列 1/2/3：竞对 A/B/C — 每格浅灰底，数据常规
  - 底部一行：我们的定位总结（如"vs Sora 做到 1/10 成本"）
- 或：2×2 象限图（横轴=技术能力，纵轴=市场覆盖），我们固定在右上角高亮区
```

## M10 数据/KPI 总览页 dashboard

```
【版式结构】
- 顶部：小节标题区
- 主体区：Dashboard 全景
  - 顶部一行：4-5 枚 KPI 芯片（特大号数字 + 小字说明 + 迷你趋势箭头↑↓）
  - 左 60%：一个主图表区域（折线图或柱状图，带坐标轴标注和时间轴）
  - 右 40%（上下两格）：
    - 上格：环形进度图（如"完成率 78%"）
    - 下格：迷你柱状对比（如"Q1 vs Q2"）
  - 最底部：一行 3-4 个标签药丸（关键指标名 + 状态色）
- 所有图表风格：扁平化，配色方案主色系渐变
```

## M11 团队页 team

```
【版式结构】
- 顶部：小节标题区（"为什么是我们"）
- 主体区：核心成员卡片（3-4 张大卡横向排列，或 2×2）
  每张卡片：
  - 卡片上半：人物头像区(圆形裁剪，120px)——若无真人照片，用彩色圆形+首字母替代
  - 卡片下半：姓名（加粗）+ 头衔 + **一行最关键履历**（如"前百度智能云消防物联网中心主任"）
  - 卡片下方：能力标签药丸 2-3 枚（如"应急数字化""AI 系统""10年+"）
- 或：左侧 35% 放一张"团队能力雷达图"（技术/管理/产业/学术 4 维），右侧 65% 放 3-4 人卡片
```

## M12 商业模式页 business-model

```
【版式结构】
- 顶部：小节标题区
- 主体区：三栏 + 飞轮
  - 左栏：收入来源 1（如"硬件销售"）— 图标 + 说明 + 占比%
  - 中栏：收入来源 2（如"SaaS 订阅"）— 图标 + 说明 + 占比%
  - 右栏：收入来源 3（如"增值服务"）— 图标 + 说明 + 占比%
  - 三栏下方：飞轮图（环形箭头循环）：
    客户获取 → 数据积累 → AI 优化 → 成本下降 → 更多客户
- 底部：毛利率/客户留存率等关键商业指标一行
```

## M13 发展路线图页 roadmap

```
【版式结构】
- 顶部：小节标题区
- 主体区：横向时间轴（带节点圆点 + 竖分隔线 + 卡片）
  - 时间轴主轴贯穿页面中部偏下位置
  - 3-4 个阶段节点（时间标签 + 彩色圆点），每个节点上方挂一张阶段卡：
    - 阶段卡顶部：阶段编号/版本号 + 阶段名（如 "V1.0 核心验证"）
    - 阶段卡中部：3-4 条里程碑要点（带小图标项目符号）
    - 阶段卡底部：关键指标数字（如"出货 2 万片/月"）
  - 已完成阶段：实心圆点 + 绿色/主色卡
  - 进行中阶段：发光圆点 + 白色卡 + 主色边框
  - 未来阶段：灰色圆点 + 灰底卡
```

## M14 客户案例/标杆页 case-study

```
【版式结构】
- 顶部：小节标题区
- 主体区：2-3 个案例卡片横向排列
  每个案例：
  - 卡片顶：客户 logo + 客户名
  - 卡片中：场景描述一句话（如"空箱查验机器人替代人工作业"）
  - 卡片底：量化效果（特大号数字 + 单位，如 "99.8% 准确率"）
- 卡片底部再一行小字"← 人工 92%"
- 装饰：卡片背景有极淡的行业相关底纹（如港口案例的背景有淡色集装箱轮廓）
```

## M15 财务数据页 financials

```
【版式结构】
- 顶部：小节标题区
- 主体区（上 60% + 下 40%布局或左右分栏）：
  - 上：折线图（或柱状图）— X 轴 2024-2028，Y 轴营收，一条明显的上升曲线
    每个数据点标注具体数字（如 2026: 2000 万）
  - 下左：毛利率/净利率等关键指标一行 3-4 枚芯片
  - 下右：费用结构饼图（研发/销售/管理 占比）
- 整体基调：数字清晰、趋势明显，不过度装饰
```

## M16 融资需求页 fundraising

```
【版式结构】
- 顶部：小节标题区
- 主体区（左 50% + 右 50%）：
  - 左侧：三个关键数字大号展示
    "融资额：5000 万" / "出让股权：10%" / "估值：5 亿"
  - 右侧：资金用途分配
    饼图（3-4 块，如 研发 40% / 市场 30% / 运营 20% / 储备 10%）+
    图例说明
- 底部：一句话资金使用目标（如"本轮资金将驱动 V2.0 产品落地和首批 30 家客户签约"）
```

## M17 结尾/愿景页 closing

```
【版式结构】
- 全幅暗底或主色满屏
- 中心大字区：
  - 一句话愿景或品牌标语（特大号，占宽度 50-60%）
  - 下方一行小字：联系方式/网站
- 极简：不要多余元素
- 可选：远景背景图为与愿景相关的抽象光影/线条（如"机器人服务人类美好生活"配暖色光晕中的人与机器人剪影）
```

### M17 变体

| 变体 | 适用 |
|------|------|
| M17a 感谢页 | 纯白/纯暗底，中间"谢谢"或"Thank You"，下方联系方式 |
| M17b 愿景号召 | 愿景句+行动号召（如"Join us on the journey"），适合路演最后 |
| M17c 回到封面 | 与封面构图一致但显示不同文字（从"我们的故事"到"你的机会"） |

## 模版使用指引

1. **从 content-frameworks.md 选定场景** → 得到逐页内容框架
2. **对内容框架的每一页，匹配本文件的页面模版**：
   - 封面 → M1
   - 市场 → M3
   - 问题/方案 → M4+M5
   - 产品 → M6/M7
   - 壁垒 → M8
   - 竞对 → M9
   - 数据 → M10
   - 团队 → M11
   - 商业 → M12
   - 路线 → M13
   - 案例 → M14
   - 财务 → M15
   - 融资 → M16
   - 结尾 → M17
3. **把 Mx 的【版式结构】段落照搬到 image-prompt-guide.md §2 提示词模板中**
4. **套用 color-palettes.md 的配色 hex**，填进提示词的【整体风格】
5. **填入 content-frameworks.md 的具体内容**到【页面文字】

## 每页差异化原则

同一套 PPT 内，即使是同一功能页（如两页都是 KPI 展示），也必须采用不同布局：
- 第一页数据用 M10 Dashboard 全景
- 第二页数据用 Bento 看板（M7）+ 侧栏 KPI rail
- 绝不出现两页使用完全相同的【版式结构】
