# Gorden 投资建议书输出契约

## 输入与事实边界

运行时必须接收当前项目字段、按顺序排列的证据来源、资料截止日、上传模板分析以及投资建议书正文结构。正文至少覆盖公司简介、核心团队、产品与技术、市场与竞争、商业模式、财务、融资、估值、交易方案、投资结论和风险；有详细项目字段或证据时必须写入语义最匹配的页面，不得只在摘要中笼统带过。

同一事实、数字、人物、客户、融资事件、估值口径或交易条款只能在最相关页面完整表达一次。输入证据按主体、日期、关系和数字口径去重；不得把模板样本、搜索摘要、无法核验的网页片段或模型常识当成当前项目事实。证据不足时明确待核验边界，不得编造补齐。

## 结构化内容

内容生成阶段返回 `title`、`executiveSummary`、`sections`、`highlights`、`risks` 和 `missing`。每个 `section` 包含当前项目语义标题、摘要、发现项、可选原生表格以及内部 `sourceIndexes`。财务信息保留期间、单位和历史或预测口径；融资信息保留轮次、金额、投资方、时间和资金用途；估值信息区分投前、投后及依据；交易方案保留投资金额、方式、持股、交割条件和保护性条款。四类内容不得互相替代。

`sourceIndexes` 只绑定真正支持该内容的来源。页面计划和生成审计记录实际使用的证据编号；只列实际使用来源，未使用资料不得混入引用清单。客户可见正文不得显示内部索引、检索过程、模板文件名、Skill 版本或模型错误。

## 严格技能顺序

投资建议书由 `create-reference-driven-editable-ppt` 统一编排：用户上传 PDF 时，先由 `pdf-to-editable-ppt` 完成模板预处理并通过交接检查；随后 `GordenSuperPPTSkill` 摄取参考模板、逐页生成图片稿并完成四层分层；编排器再把图片稿无损封装为桥接 PDF，最后由 `pdf-to-editable-ppt` 根据 Gorden 分层语义清单生成最终元素级可编辑 PPTX。用户上传原生 PPTX 时只跳过“模板预处理”，不得跳过最终桥接 PDF 的可编辑化和交接验收。除这三个技能外，不得调用其他 PPT 构建、替换或套版技能。

Gorden 阶段一必须逐页调用图片网关生成成品幻灯片，并保存图片型 PPTX、逐页 PNG、提示词和 `imagegen-manifest.json`。阶段二必须严格执行 `GordenImage2PPTX`，把每页拆成背景图、框架图、图标和普通文字四层；普通文字必须成为 PowerPoint 原生可编辑文本框，图标和框架必须保持为可移动图片对象。

## 产物与验收

最终交付可编辑 `.pptx`，同时在任务目录保留项目事实库、页面计划、模板映射、阶段一图片、图片生成证据、逐页分层资产、布局 JSON、图片型 PPTX、最终预览和工作流审计。末尾页面必须包含投资结论、后续事项和责任声明；实际使用来源保存在任务审计和引用记录中。

交付前必须通过以下门槛：PPTX Open XML 包有效；每页至少有原生可编辑文字；每页存在背景和框架分层；项目名称与责任声明可检索；模板样本公司、人物、数字、Logo、水印和无关网页内容全部移除；文字、图标和框架没有明显重影、错位、裁切或不可读。任何页面缺少图片生成证据、文字索引、图标映射、布局检查或视觉比较结果，都必须停止交付并重新生成受影响页面。
