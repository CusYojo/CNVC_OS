## 模板资产

### T1 `deta-ic`：德塔智能 IC 技术论证型

- 原稿：`../assets/reference-templates/deta-ic/source.pdf`，38 页，16:9。
- 总览：`../assets/reference-templates/deta-ic/contact-sheet.png`。
- 单页参考：`../assets/reference-templates/deta-ic/pages/page-NN.png`。
- 视觉特征：深灰极简封面、白底正文、亮蓝强调、窄页眉、研究报告式图表与证据排布。
- 叙事特征：赛道共识 → 技术问题 → 产品架构 → 科学家/团队 → 核心技术证据 → 产业验证 → 竞争与定价 → 财务、投资、退出、风险。
- 适用：底层技术、AI 模型、机器人、芯片、硬科技、研发驱动型公司；受众为投资决策委员会、产业资本或技术专家。
- 优点：技术推演深、证据链完整、最终投资决策闭环强。
- 风险：若项目公开技术材料不足，容易形成“概念很深、证据很薄”的页面；此时减少技术页，不得编造指标或论文。

### T2 `lancheng-investment`：蓝成应急场景商业化型

- 原稿：`../assets/reference-templates/lancheng-investment/source.pdf`，34 页，16:9。
- 总览：`../assets/reference-templates/lancheng-investment/contact-sheet.png`。
- 单页参考：`../assets/reference-templates/lancheng-investment/pages/page-NN.png`。
- 视觉特征：大面积白底、浅蓝分区、蓝黄双强调色、章节过渡页、照片与流程图并用，呈现稳健的机构投资报告气质。
- 叙事特征：投资亮点 → 行业窗口与政策 → 供需痛点 → 公司演进 → 产品/技术/壁垒 → 生态绑定 → 场景案例 → 客户访谈 → 竞品 → 商业模式 → 财务、投资、风险、退出。
- 适用：行业解决方案、机器人二次开发、政府/国资场景、产业平台、渠道和交付驱动型公司。
- 优点：落地证据、客户价值、商业闭环、渠道壁垒表达直接。
- 风险：不能把战略合作、意向订单或政策空间自动等同于可确认收入；所有关系和数字必须做实体、期间和口径核验。

## 选择规则

1. 用户点名“德塔风格 / 技术 IC / 技术尽调”时，选 `deta-ic`。
2. 用户点名“蓝成风格 / 场景落地 / 产业商业化”时，选 `lancheng-investment`。
3. 同时给出两份模板、要求综合参考或未指定时，默认选 `hybrid-investment-ic`。
4. 混合模式只混合故事模块和页面结构，不在同一份演示稿里交替使用两套视觉主题。先确定一套全局视觉系统，再把另一模板当作信息架构参考。
5. 技术证据充分、评审偏技术时，以 `deta-ic` 为视觉主模板；客户案例、渠道和经营数据更充分时，以 `lancheng-investment` 为视觉主模板。

## 默认混合策略

`hybrid-investment-ic` 推荐采用 14-18 页，并按项目事实多少增减：

1. 封面：德塔深色极简或蓝成白底机构风，二选一。
2. 项目摘要：使用德塔第 2 页的信息组织。
3. 投资亮点：使用蓝成第 2 页的四列证据卡。
4. 行业窗口：蓝成第 4 页负责“为什么是现在”，德塔第 4/7 页负责规模和资本锚点。
5. 核心痛点：使用蓝成第 6 页的供需错配结构。
6. 产品全景：使用蓝成第 9 页的产业链/场景地图。
7. 技术架构：使用德塔第 11/19/21 页的分层与全链路结构。
8. 技术证据：使用德塔第 23 页，但只呈现可验证的论文、测试或基准。
9. 团队：技术型项目用德塔第 15 页；产业型项目用蓝成第 14 页。
10. 商业壁垒与生态：使用蓝成第 11-13 页的飞轮、股权绑定和资源协同结构。
11. 场景验证：使用蓝成第 17 页的流程 + 效率指标；多合作方时补德塔第 26 页的证据墙。
12. 客户/专家验证：使用德塔第 30 页或蓝成第 21 页。
13. 竞争与估值：对比维度用蓝成第 24 页，资本定价用德塔第 31 页。
14. 商业模式与财务：使用蓝成第 27/29/30 页，所有预测明确假设。
15. 投资方案、退出、风险：组合德塔第 35-37 页与蓝成第 31-33 页。

## 阶段 1 使用方法

以下资产路径均相对于 `GordenSuperPPTSkill/`。实际执行时先解析为绝对路径，避免任务运行目录不同导致找不到参考图。

1. 在 `outline.json` 中给每页增加：

```json
{
  "template_mode": "hybrid-investment-ic",
  "visual_master": "lancheng-investment",
  "reference_template": "deta-ic/pages/page-21.png",
  "reference_role": "仅参考分层架构与信息层级，不复用文字、Logo、人物或数据"
}
```

2. 把选择结果另存为 `template-selection.json`，至少包含 `mode`、`visual_master`、`source_templates`、`slide_reference_map`。
3. 每页选择一个主参考页；如需第二页，只借用其信息组织，不要同时混合两套构图。
4. 调用阶段 1 网关时，把主参考页作为图像输入：

```bash
python3 ../GordenImagePPTGen/scripts/generate_gateway_slide_image.py \
  --prompt @prompts/NN-page.md \
  --image assets/reference-templates/<template>/pages/page-NN.png \
  --out-dir <run>/metadata/NN \
  --size 2560x1440 --quality high
```

5. 在提示词中明确：只学习布局骨架、留白、配色比例、图表组织和信息密度；完整替换全部可见文字、Logo、人物、产品图和数据。
6. 若参考页与当前内容容量不匹配，优先保持当前内容完整和可读，允许调整模块数量，不要求像素级照抄。

## 样本残留门禁

交付前逐页检查，不得出现：

- 德塔智能、蓝成应急、宇树、通研院等模板样本实体，除非它们确为当前项目相关方且有来源支持。
- 模板中的报告人、日期、页码、Logo、水印、二维码、客户照片或人物头像。
- 模板的收入、估值、融资额、客户数、订单量、市场规模或预测数字。
- 模板中的绝对化结论，例如“唯一”“独家”“全球领先”，除非当前项目证据充分且表述经过限定。

视觉相似不是事实授权。模板只提供故事结构和设计语言，当前项目必须建立独立事实库。
