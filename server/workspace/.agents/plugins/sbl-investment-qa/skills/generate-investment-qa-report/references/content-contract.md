# Q&A 内容与版式契约

## 叙事模式

- 默认使用 `dual_use`：执行总览 + 6—9 个问答，同时服务对外融资与内部投决。
- 用户明确要求纯内部质询时用 `internal_ic`。
- 用户给定参考文档并要求格式一致，且参考文档无总览时用 `reference_faithful`。

## 汇报主体与时点

- 默认 `audience_mode=external_decision_qa`：正文是面向投决会或出资人的成熟答疑，只呈现结论与已落地支撑。只有用户明确要求内部风控、尽调缺口或交易条款时，才使用 `internal_decision_qa`。
- 对外模式下，IP待闭环、搬迁赔偿、分期付款、专项预留、对赌补偿、底座依赖等不作为Q&A问题，转入《交易方案》或尽调附件。
- 对外模式禁用“经项目组核查”“项目组判断”“项目组支持”等内部叙述者口吻，也禁用估值剔除、分期付款、专项预留、补偿和不释放款项等交易操作语言。
- 正式 Q&A 代表已完成尽调并形成投资结论的投资团队，但对外正文不出现“项目组”这一内部叙述者。
- 默认 `report_stage=final_recommendation`、`investment_stance=support`：正文不展开审批过程、未来尽调或投后任务。
- 对外模式先直接回答，再解释决定事实背后的客户动机或经营原因。具体商业结果已经答完问题时直接结束，不另起“已经形成、具备能力”式总结段，也不展示分析过程。
- 未成熟事项不进入对外 Q&A；在内部模式中另行写入尽调底稿或《交易方案》。

## 可见正文

### `dual_use`

1. 一行居中总标题：`<公司简称或全称>项目 Q&A`；
2. 一组执行总览段落，覆盖市场争议、赛道三分法和项目定位；
3. 6—9 个按序编号的问题；
4. 每题 1—4 个自然段回答；多项独立依据可以各占一段。

### `internal_ic`

只包含总标题和 6—9 个 Q&A，每题 2—4 段。

### `reference_faithful`

只包含总标题和 6—9 个 Q&A；标题后直接进入 Q1，每题 1—4 段。赛道三分法和项目定位保留在私有规划文件中，不显示为前置总览。

所有模式均不得出现封面、目录、表格、页眉、页脚、页码、事实 ID、评分、审计过程或来源标签。

## 问题契约

- 使用 `Q1：` 至 `Q9：` 连续编号；每题登记 3—10 条必用事实，估值题可容纳海内外对标与自身估值事实。
- 以投资人核心争议书写，一至两句并以问号收束。
- 对外问题不强制包含数字。至少一半问题应当在删除数字后仍然成立，避免从两组材料数据机械反推问题。
- 一题只解决一个主争议，不与其他题重复。
- 每题选择 `positioning`、`market_need`、`mechanism`、`customer_case`、`transferability`、`product_role`、`revenue_quality`、`valuation` 或 `organization` 原型；六至七题至少覆盖三种，八至九题至少覆盖五种。
- 对外模式整体覆盖估值对标、客户验证、收入质量、产品/技术价值、商业化与组织能力；治理/IP、赔偿、底座依赖和交易安排仅在有完整已落地正向事实且外部明确提问时出现。内部模式可覆盖治理/IP和交易安排。

## 决策型回答契约（`dual_use` / `reference_faithful`）

- 对外模式不设最低字数，最多 800 个中文字符、1—4 段；内部模式 450—1000 个中文字符、2—4 段。题目不必等长。首段角色为 `opening_position`，其余段落按问题需要承载比较、客户决定、发生过程、商业结果或投资判断。最后一段如果只是重复前文结论，应直接删除。
- 使用足以证明结论的可追溯事实，不为满足固定数量机械堆数字。
- 在前一两句内回答问题；机制题再把“为什么会这样”讲清楚。数据要嵌入业务过程，不单独成段罗列。禁止“这说明、共同证明、这体现、这表明、由此可见、据此”等讲解式推导词。最后一句可以停在持续采购、按月付费、单独销售、采购和回款等具体结果；不要为了统一收口再补一句投资结论。
- 估值题的第二段先写正向同业逻辑，再写公司自身收入倍数及基准/成长/期权分层。
- 海外通用机器人基础模型、国内成熟全栈平台仅用于说明行业关注度与长期空间；必须同时披露轮次、规模、收入或产品阶段差异，并明确不能直接套用估值倍数。
- 对外模式不写交易处理；内部模式的估值、财务、治理和政策责任题可给出交易处理。

## 证据和表达层级

- 客户事实区分需求、试用、PoC、客户项目、联合研发、合同、交付、验收、开票、回款和复购。
- 股权控制、股权激励、全职性、竞业、IP 归属、联合研发和“不可替代”类断言必须登记 `claim_support`。
- `confirmed` 只能引用 `verified` 事实。事实状态、来源和采信过程保留在底稿，不在对外正文反复写“据公司披露”“据管理层”或“管理层表示”。`management_stated` 仅可用于已被项目组采纳的非敏感描述，不得证明合同、验收、回款、治理、权属或第三方验证效果；无法直接陈述的内容从对外正文删除。对外模式不使用 `pending` 或 `conditional` 事实支撑肯定结论。
- 不得把客户采购自动升级为联合研发，把意向写成合同，把测试写成验收，或把管理层陈述写成已落地制度。
- “付费客户及共同验证伙伴”可用于存在采购和任务反馈但没有联合研发协议的关系；“联合研发”必须有共同研发任务、成果分配或持续迭代的文件/访谈证据。
- “产业分工空间”可基于本体厂资源优先级和跨平台需求论证；“无法复制”“长期不会被替代”一律不得作为事实结论。
- 控制权稳定、四年激励、离职回购、全员竞业、高校成果商业权归公司、开源无侵权等制度，如未完成文件归档与执行验证，不进入对外 Q&A；内部模式可写成管理层陈述或交易条件。

## 文本过滤

- 禁用：“阶段约束”“价值释放条件”“治理资产”“资本上限”“成长锚”“对称资本处理”“平台飞轮”“反向解释”“另一种解释”“不存在被替代风险”“长期不会被替代”“无法复制的核心壁垒”“无控制权旁落风险”“不存在知识产权侵权隐患”。
- 禁止在正文段首使用“产业逻辑：”“商业模式：”“风险提示：”“投资建议：”等小标题加冒号。
- 禁用顾问式与继续尽调式表达：“建议公司”“公司需要”“后续需要”“接下来重点观察”“建议进一步”“投后需完成”“只有……才能证明”。
- 对外正文禁用机械来源前缀：“据公司披露”“据管理层”“管理层表示”“管理层称”“公司称”。证据来源只在内部事实库保留。
- 对外正文禁用讲解式推导：“这说明”“共同证明”“这体现”“这表明”“由此可见”“据此”。结尾要闭合投资含义，但不要重复第一句。
- 第一口必须是完整判断句，不单独使用“合理、能、具备、清晰、较好”作答。优先写收入、采购、交付、验收、回款、复购、成本和客户任务；不用“客户入口、高维数据积累、价值释放、成长锚、治理资产、平台飞轮、资本上限、生态闭环”等包装词。
- 同时有两项以上独立依据时可以用“第一、第二、第三”，但分点题不得超过全文一半。对比、机制、客户案例、产品角色和团队题优先使用自然段，不能把每题都写成同一种总分结构。
- 相邻问题不连续复用相同开头和相同结尾。估值和财务题保留必要数字；其他问题只使用真正改变判断的数字。
- 句长由信息自然决定。不得用连续碎句、感叹句、刻意反问或制造出来的“金句”模拟口语感。
- 禁止替听众讲解证据分量的工整元话语，如“这个顺序比单纯的采购金额更能解释复购”“对估值最有分量的支撑是”。直接写发生顺序或决定估值的经营事实。
- 同一组客户同时出现的回答不超过全文一半，避免把客户材料当成每题固定例证。不得为了满足版式变化而补写段落。
- 结尾出现“已经形成、已经验证、具备……能力/基础/质量”的题目不得超过两题；可以删掉的总结句直接删除。
- 对已核实事实优先使用正向陈述：“定价基于已落地收入和客户复购”“收入全部来自已履行项目”，不写“不是以远期设想定价”“不包含意向金额”等防御性对照。只有证据已经证明结果时才使用“证明了”“已降低”等笃定动词，禁止用语气替代证据。
- 技术题不以“数据处理能力、仿真能力、交付能力”等分类清单开场。先写公司如何把通用工具转化为客户任务成果，再串联工作流程、任务效果、付费与复购；分点只用于商业含义不同的依据。
- 在没有协议证据时不得写“双方已约定”“交易文件已明确”；对外最终结论稿不写内部定价处理。
- 禁止以“尚未”“尚不足”“只能”“无法”“不能”“不宜”开头。
- 不得虚构、改写或粉饰负面事实。若该事实无法形成成熟的对外回答，则不设置为对外 Q&A 问题，保留在内部尽调底稿。

## 评分契约

对外模式固定维度共 100 分：

- 核心争议选择与问题锋利度 10；
- 数据颗粒度与证据状态 20；
- 赛道定位、产业分工与对标 10；
- 公司专属机制与商业模式 15；
- 客户收入效率与现金流传导 20；
- 团队执行与商业化能力 10；
- 结论清晰与自然表达 15；其中包括句长变化、关键句重音和朗读自然度。

内部模式另行使用治理/IP、风险处理、估值付款和交易安排维度，不能用内部评分项倒逼对外正文披露风险。

总分低于 85、任何单项低于该项满分 60%、或存在 hard failure，均不得发布。

## DOCX 版式

- 没有参考文档时：A4 纵向，单一连续节；使用脚本默认的黑白答辩体。
- 有参考文档且用户要求一致时：参考文档为唯一版式权威，记录字体、字号、页边距、间距和元素范围，再使用 `reference_faithful` 渲染。
- 德塔 Q&A 纯问答模板使用 A4、上下 2.54cm、左右 3.175cm、中文楷体 11pt、西文 Times New Roman 11pt、标题 16pt；标题后直接进入 Q1，无执行总览、目录、页眉页脚或页码。
- 问题加粗，回答不加粗、不首行缩进；问题与首段保持同页。
- 黑白版式，不使用色块、图表、图片、装饰线或自动编号样式。
