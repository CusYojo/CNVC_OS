# 对外投决答疑与内部风控分层规则

## 1. 先锁定受众，再选版式叙事

- `external_decision_qa`：默认。面向投决会、出资人或外部机构，只呈现成熟结论与已落地证据。
- `internal_decision_qa`：仅在用户明确要求内部尽调、交易保护或下行情形时使用。
- `dual_use`：带执行总览的版式叙事。
- `reference_faithful`：参考文档标题后直接进入 Q1 时使用。
- `internal_ic`：纯内部质询稿。

“对外+内部双轨”指 Agent 支持两种独立产物，不是把两类内容写进同一份正文。

## 2. 对外正文

对外 Q&A 代表已经完成尽调并形成结论的投资团队，但不出现内部叙述者。每题 1—4 个自然段，不设最低字数：

- 在前一两句内给出答案。不得用“合理、能、具备、清晰、较好”单独成句，也不必把每题都写成同样的结论句开头。
- 论据仅使用已确认收入、已采购、已验收、已回款、已验证效果和已签署文件。
- 事实状态和来源留在内部底稿。对外正文直接陈述投资团队已经采纳的事实，不反复写“据公司披露”“据管理层”或“管理层表示”；仍需依靠归因才能成立的口径不进入正文。
- 关键事实展开充分后，优先停在具体商业结果，例如客户继续下单、另一行业客户按月付费或产品能够单独销售。没有必要时不再加总结句；“已经形成、具备能力、验证价值”不能成为统一收尾。
- 删除比补写更优先。前一段已经给出决定性客户行为时，不为追求完整结构再写总结段。
- 机制题和客户决策题要讲清直接原因，例如复购来自什么已完成结果、扩品解决了客户哪一段工作。事实型问题不要为追求深度补写材料没有支持的原因。
- 不使用“经项目组核查”“项目组判断”“项目组支持”。
- 不写估值剔除、分期付款、专项预留、原股东补偿、对赌、暂缓款项或投后动作。
- 不使用“这说明、共同证明、这体现、这表明、由此可见、据此”等推导词，不把分析过程讲给听众。
- 使用行业通行、含义明确的词。能写“采购、交付、回款、复购、成本”的，不写“客户入口、高维数据积累、价值释放、平台飞轮、生态闭环”。
- 估值、客户、财务、产品、团队和技术等多因素问题可分点，也可按比较、机制或案例自然展开。整份报告的分点题不超过一半，不用“第一：收入基础”式小标题。
- 问题从投资判断出发，不强制引用材料数字。至少一半问题不以数字或两组材料数据开场，全文至少采用三种问题原型。
- 一道客户题只讲清一个客户的决策时，不强行补入第二个客户。只有收入质量或横向比较题才并列客户；同一组客户不得成为过半题目的固定证据组合。
- 已核实的正向事实直接写结论，少用“不是……”“不包含……”等防御性对照；“证明了”“已降低”等笃定词必须有结果证据支撑。
- 技术题先回答“技术如何变成客户成果和收入”，再写具体流程与案例，不以能力分类清单代替商业论证。
- 不设置 IP 缺口、搬迁赔偿、供应商依赖、口径冲突等无法用成熟事实闭合的问题。

风险不能通过改名或粉饰变成优势。若没有已落地事实形成完整回答，该议题保留在内部底稿，不进入对外 Q&A。

## 3. 内部正文

内部模式仍按“结论—证据—未决事项—交易影响”分析，可覆盖治理/IP、财务口径、搬迁责任、供应商依赖、付款、预留、补偿、重定价和终止条件。内部结论不得伪装成双方已签署条款。

## 4. 语言风格

- 专业、清楚、自然，一句话尽量只表达一个判断。
- 让句子跟着内容走。主语已经明确时不必句句补全，但短句仍须是完整意思；不要把正式材料写成聊天记录，也不要刻意制造“短句压重音”。
- 少替听众总结“哪个证据更有分量”。直接写“先交付，再验收，然后扩品”或“追觅复购，行之途按月采购”，事实本身就是重音。
- 不在段首使用“产业逻辑：”“阶段约束：”“价值释放条件：”“投资建议：”等小标题。
- 不连续复制同样的段数、结尾或“若达标/若未达标”结构。
- 禁用造词：阶段约束、价值释放条件、治理资产、资本上限、成长锚、平台飞轮、对称资本处理。
- 采购、共同验证和联合研发必须按证据层级区分；意向不能写成合同，样品不能写成验收。

## 5. 对标与商业模式

海外基础模型公司和成熟平台只用于说明行业关注度与长期空间，必须说明其轮次、体量或商业阶段与项目不同，不能直接套用估值倍数。

商业模式可在内部检验“客户任务→技术沉淀→可重复销售产品→跨场景复用”，正文用自然语言说明，不命名为“飞轮”。

## 6. 证据层级

- `verified`：可直接支撑确定性事实。
- `management_stated`：正文必须明确归属公司或管理层。
- `calculated`：写清计算口径，基础数据必须可追溯。
- `pending`：不得进入对外肯定性结论。

`claim_support` 用于联合研发、IP 归属、控制权、激励、竞业、不可替代性和产业赋能等敏感断言。表达级别不能高于证据级别。
