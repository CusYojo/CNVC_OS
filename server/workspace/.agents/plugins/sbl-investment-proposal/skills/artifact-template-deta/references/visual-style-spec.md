# Deta正式投资提案视觉规范

以下参数是正式DOCX的硬性视觉门禁，除非用户在当前任务中另行明确指定：

- 页面：16.2cm×21.0cm；上、下页边距1.5cm；左、右页边距1.8cm。
- 主标题：黑体17pt、加粗、居中；标题块段前12pt、两行间距6pt、段后18pt。
- 一级标题：黑体14pt、加粗、左对齐；段前12pt、段后6pt。
- 二级标题：黑体12pt、加粗、左对齐；段前8pt、段后4pt。
- 正文：宋体10.5pt；首行缩进2字符；1.4倍行距；段后3.5pt。
- 表格正文：宋体9–9.5pt。
- 表格表头：黑体9.5pt、加粗、浅灰底。
- 利润表与“营业收入五年预测”表使用完全一致的字体字号：表头黑体9.5pt、加粗，正文宋体9pt；不得对预测表设置更小的局部字号，也不得通过缩小字体实现整表容纳。
- 表格宽度：以左右1.8cm页边距后的实际版心为上限，按原列宽比例缩放；不得依靠超出版心或低于9pt字号容纳内容。
- 表格单元格段落取消正文首行缩进，表头与数字列按列语义对齐；落款主体与日期必须成组排版，不得将日期单独留在空白页。

交付前使用Word原生导出并逐页检查标题、正文、表格和分页。任一页面出现字体替换、表格越界、裁切、重叠、孤立标题或异常空白页时，调整后重新渲染。
