# 投资提案原文润色约束

当用户提供投资提案原文并要求润色、扩充、优化、改写或完善时，严格执行以下要求：

1. 在现有事实基础上适当补充细节、逻辑衔接和专业表述，使公司简介、股权结构、技术路线、交易条件、业务预测、投资亮点、风险控制和结论等部分更充实、完整、专业；不得引入原文及用户补充信息中没有的新事实、新数据、新预测或新结论。
2. 财务部分，包括资产负债表、利润表及所有财务数据和表格，必须逐项保持原文不变，不得补充、删减、润色、改写、重排、重算或修改格式、标题、表头、科目、金额、期间、单位和顺序。
3. 公司简介、团队、股权、技术、运营、财务、交易条件、业务预测、投资亮点和风险控制只客观描述事实、业务情况、行业风险及公司已有应对措施，不加入主观评价、价值判断、成功关键、依赖条件分析或“能否形成持续价值”类表述。“六、结论”是唯一例外，可在用户或原文已有明确投资建议时形成一段有依据的投决判断。
4. 禁止出现“该路径能否形成持续价值，主要取决于……”或任何同义、近义的评价性语句。
5. 禁止出现“投资意向书要求”“本意向书要求”“投资方要求”“协议要求”“本文件要求”等引用投资意向书、协议或外部文件的话术。
6. 不得自行补充“要求公司建立……制度”“建议公司完善……机制”或“使……具备稳定边界”等评价性、要求性或结论性语句。
7. 语言正式、简洁、专业，符合投资提案文风；段落衔接清楚，避免空泛套话和重复表达。
8. 严格围绕原文及用户补充信息展开，不自行添加额外分析、推测、行业对比或未来展望。
9. 信息不足时保持精炼，删除无依据的扩写，不以常识、公开信息、模板内容或合理推断补齐。
10. 公司简介不呈现统一社会信用代码或任何18位信用代码；即使原文含有该字段，也从正式提案中删除，不影响其他工商事实的原文锁定。

## 执行步骤

1. 先建立投资主体与目标主体绑定。用户确认的投资主体全称和简称优先于原文、旧报告、文件名、协议签约方、管理机构或历史基金名称；标题、导语、交易条件、治理权利、投资亮点、结论（如出现主体）和落款必须一致。将错误旧主体及其简称列入禁用清单，完稿后全文扫描，命中即退回订正。
2. 将用户原文保存为只读基线，另行建立已确认事实清单与用户补充信息清单。
3. 按 [section-expansion-framework.md](section-expansion-framework.md) 建立章节事实覆盖矩阵，记录材料已经支持但原文尚未展开的事实维度。
4. 先复制财务章节并锁定，再润色其他章节；禁止先重写全文后回填财务数据。
5. 对每个新增句子建立原文或补充信息的内部对应关系；无法对应的句子删除，不进入正式提案。
6. 使用“总体定义—构成拆解—实现方式—量化信息—当前状态”展开材料已经支持的事实；不得用空泛衔接或重复表述增加篇幅。
7. 完稿后逐项比较原文与成稿的财务章节。只有标题、段落、表格、表头、科目、金额、期间、单位、顺序和格式全部一致时才可发布。
8. 扫描评价性语句、外部文件引用话术、自行新增制度要求、行业对比、未来展望、新数字、新预测和新结论；除结论段按授权使用的投决判断外，发现任一项即退回订正。结论段中的赛道窗口、技术壁垒、商业验证、团队、估值折让和保护条款必须逐项对应正文或用户补充信息。
9. 比较章节覆盖矩阵中的 `available_dimensions` 与 `used_dimensions`；已有事实未充分展开时退回扩写，材料不足时记录缺口并保持精炼。
