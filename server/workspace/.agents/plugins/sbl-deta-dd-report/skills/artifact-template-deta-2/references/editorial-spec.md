# 德塔式报告编辑与去重契约

## 信息锚点

- 技术链：第3章完整说明；1.1只写主营业务，1.5只写价值结论，7.1只写投资意义，结论原则上不再复述路径。
- 历史财务与收入确认：6.2.3完整说明；1.4写经营结论，1.1只写对投资判断的影响，结论最多保留一个决定性数字。
- 交易结构：7.2完整说明；1.2用字段化短值，结论直接写决定性金额、权益和付款边界，不用章节交叉引用代替内容。
- 风险与控制：第8章完整说明；1.5写摘要，结论只写交割事项与未完成后果。

## 章节写法

- `1.1 核心判断`：一至两句，先判断后控制，不展开技术链、财务差异或条件清单。
- `1.5 投资价值`：固定五条，依次为行业定位与付费基础、差异化技术路线、数据/反馈闭环壁垒、客户或生态商业验证、团队产业化能力；每条形成“事实基础 → 价值机制 → 投资意义”。老股折价、分期、治理及下行保护归入7.2，不占用公司价值。验证边界移至“主要风险”或第8章，不用“尚未、仍需、无法、不计入”等措辞连续打断正向逻辑。
- `1.5 主要风险`：先指出一个商业化、产品化、复购或估值兑现主风险，再说明财务、客户、IP/数据及量产因素对收入底盘、成长价值和现金流的传导；不得写成并列风险名录。
- `7.1 投资亮点`：只保留亮点、尽调证据、投资意义，不重复产品说明或风险台账。
- `投资结论及建议`：严格三段；第一段为建议和理由，第二段为交易执行摘要，第三段用一个并列句概括交割事项，并用一句话写明未完成后果。

## 重复与语言预算

- “真实采集、合成、仿真、触觉”完整技术链最多出现在2个章节，完整机制只在第3章出现。
- “收入、净利润、收入确认差异”完整财务数字组最多出现在2个章节，只在6.2.3完整展开。
- “增资/老股金额、完全稀释持股、分期”完整交易元组最多出现在2个章节，不在1.2、7.2和结论三处逐字复述。
- 同一解释性句子不得跨章节重复；同一重大数字原则上不超过2次，固定概要字段与执行所需数字除外。
- 1.1最多1个不确定性限定；1.5投资价值不使用防御性短语；7.1合计最多2个简短边界提示；结论前两段不展开核查措辞。

重大风险、交割条件和终止边界不得因去重或语气优化而删除，只能移动到其唯一信息锚点并压缩表达。

## 编号与章节自足

- 两项及以上的编号枚举必须使用独立Word段落，一项一行；表格值单元格也不得将`1. ……2. ……`挤在同一段，手动换行不视为合格。
- 正文不写`详见`、`参见`、`见第X章`、`见X.X`或“按X.X所列”。每一章节直接给出本节所需的最短事实或结论，完整分析仍留在唯一锚点。
- `1.5 主要风险`只列风险本身，删除“控制方案详见第8章”等导航句。

## 材料归因与缺口措辞

- 可确认事实直接陈述，不在公司概况、团队、业务和客户章节反复写“材料显示”“尽调材料显示”。
- `未提供`、`未显示`、`尚未完成勾稽`及一般性“需进一步核对/需核验”集中到第8章和结论第三段；正文仅保留对经营与投资价值的专业判断。
- `以……为准`只用于正式权利义务、完全稀释股本或正式交易协议；其他位置直接陈述，确需时点时使用明确年月日，不使用“截至报告日”。
- 6.2.3和第8章可各保留一次约450万元收入确认事项；管理口径与账面口径差异保留为核心发现，但不重复叙述核验过程。
- 固定表头`尽调材料人数/规划`属于模板控件，不纳入归因词预算。
