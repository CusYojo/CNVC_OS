# 德塔V5投资价值与风险写作契约

## 正式稿结构

`1.5 投资价值与风险`固定为五条投资价值和一段主要风险，一项一个真实Word段落。五条不是优势清单，而是由外部机会逐步收敛到公司兑现能力的投资论证：

1. **行业定位与付费商业基础**：先说明产业竞争或采购标准正在发生的变化，再用合同、交付、验收、回款或已形成的产品基础证明公司已经进入该价值链，最后落到可验证的收入底盘或市场位置。
2. **差异化技术路线**：说明相对纯采集、纯仿真、纯算法或其他常见路线的差异，写清核心模块如何协同，并落到成本、交付效率、训练效果、跨场景适配或产品边界。
3. **数据与反馈闭环壁垒**：从行业数据稀缺、质量、成本或复用痛点出发，说明数据、模型、仿真、真机/客户验证或硬件入口如何回流，最终落到可复用资产、客户黏性或长期壁垒。
4. **客户/生态商业验证**：使用真实客户阶段或合作内容，说明其如何降低验证成本、扩大数据获取或部署范围、形成跨产品销售和复购。不得把线索、意向或普通交易对手包装成生态验证。
5. **团队产业化能力**：逐人绑定技术、工程、项目、客户或组织能力，说明组合如何支持从研发到交付再到产品化。2.4存在4至5名有证据的核心成员时应完整吸收其互补能力，不得只使用前三人；不得用顾问、院士或合作方履历替代公司核心团队。

每条采用“判断性主题句＋行业/客户问题＋公司事实与机制＋投资意义”的完整结构。事实和判断可在同一段自然衔接，不打印“事实基础、价值机制、投资意义”等内部字段。五条中不得出现老股折价、分期支付、治理安排、入股成本、资金暴露或下行保护；这些内容完整归入`7.2 公司估值与投资方式`。

## 主要风险

先用一句话确定唯一统领性风险，通常是商业化、产品化、复购、规模收入或估值兑现；再说明财务口径、客户、IP/数据合规、供应链或量产等重大因素分别通过何种路径影响收入底盘、成长价值或现金流。详细监测指标、交割控制和未达标处理只在第8章展开。

合格形式示意：

> 主要风险在于，现有项目交付能否转化为可复用产品、持续复购及规模收入，是估值兑现的核心变量。财务口径影响基准价值，IP和数据合规影响资产完整性与交付合法性，量产及复购影响成长价值转化为现金流的节奏。

不得用“风险集中于A、B、C、D、E”结束，也不得附“详见第8章”。

## 与其他章节的边界

- 第3章完整展开技术链，1.5只写差异化及投资意义。
- 第4章完整展开合同、验收、回款和客户阶段，1.5只选能支持商业验证的最短证据。
- 2.4完整介绍人员履历，1.5只写团队组合的产业化能力。
- 7.1归纳亮点，可简要包含交易安全边际，但不得复制1.5五段。
- 7.2完整呈现估值、老股折价、分期、治理和下行保护。
- 第8章完整呈现风险描述、价值传导、监测、控制和后果。
