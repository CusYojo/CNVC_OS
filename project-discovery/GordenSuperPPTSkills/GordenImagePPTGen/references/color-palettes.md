## C1 企业红灰 — 路演/汇报首选

```
底色:       #F4F6F9（极浅冷灰）
主色:       #D92D20（企业红 — 标题条/重点数字/底部横幅）
辅色 1:     #0B1F3A（深藏青 — 主标题/模块标题）
辅色 2:     #FFFFFF（卡片底色）
强调色:     #667085（钢灰 — 正文/标签/导语）
中性:       #E0E4E8（边框/分隔线）
亮色点缀:   #FF6B35（可选 — 微件/标签药丸背景）

使用规则：
- 封面：深藏青 #0B1F3A 大底 + 白字标题 + 红字 slogan
- 正文页：浅灰 #F4F6F9 底 + 白色卡片（细投影）+ 红色标题条
- 底部横幅：满幅 #D92D20 红带 + 白色粗体字
- 微件/药丸：红色底 + 白字，或浅灰底 + 藏青字
- 图表/连接线：红色主调 + 钢灰辅助
- 重点数字：特大号 #D92D20 红字
```

## 配色方案使用指引

1. **默认用 C1**：企业红灰适合大多数商务场景
2. **用户给参考图**：提取参考图配色，替代内置方案
3. **用户有 brand guide**：严格按品牌色
4. **切换风格**：改方案后全套统一，不同页不能混用不同方案
5. **避免纯绿**：C5/C10 含绿 —— GordenImage2PPTX 阶段 B1 探色后会自动改非绿底色
6. **hex 写进 prompt**：把选定的 hex 写进 §2 模板的【整体风格】和每个 `outline.json` 的 `visual_generation_prompt` 里
