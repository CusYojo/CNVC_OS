# 真实 BP 案例蒸馏 — 融资路演内容模式

以下模式从 25 份真实投资机构过目的 BP 中蒸馏。
不是理论模板，是**实际被投资人看过的页面结构和写法**。

---

## 案例 1：硬科技/深科技型（生数科技、零次方机器人、美梦科技）

**特征**：核心技术驱动，学术背景强，全球对标。

### 页面结构（12-16 页）

| 页 | 生数科技（AI视频）| 美梦科技（世界模型）| 零次方机器人 |
|----|-----------------|-------------------|-------------|
| 01 | 封面："多模态生成领域全球领航者" | 封面："虚实之间的造梦师" | 封面：产品名+技术定义 |
| 02 | **技术演进时间轴**：2020-2025 四个阶段（积淀→产品→迭代）| **AI 跃迁叙事**：1.0 语言→2.0 视觉→3.0 空间 | **技术路径**：数据熵解耦架构图 |
| 03 | **全球排名**：双权威榜单榜首 | **产品定义**：四大核心能力（全景/3D/角色/物理） | **方法论**：4D时空增广模型 |
| 04 | **不可能三角**：又好+又快+又省（对标 Sora 1/10 成本）| **核心功能**：轻巧/迅捷/原生多模 | **效果对比**：Action 100% 指标 |
| 05 | 产品矩阵（MaaS/SaaS/APP 三层）| **学术背书**：北大视频与视觉技术国家工程研究中心 | 技术架构详解 |
| 06 | **用户反馈**：全球艺术家证言+作品展示 | **核心团队**：首席科学家(IEEE Fellow)+CEO/CTO/COO | 团队 |
| 07 | **行业覆盖**：8 大行业 30+ 场景 | **技术团队**：博士后×3+博士×6 | 产品展示 |
| 08 | **社区生态**：全球 2500 万用户 100 万视频/天 | **竞对矩阵**：vs Marble/英伟达/Meshy 四维对比表 | 应用场景 |
| 09 | 未来展望 | **技术架构**：数据→模型→能力→应用四层图 | 商业模式 |
| 10 | — | **发展路线图**：三阶段（工具→物理AI→行业微调） | 财务/融资 |

### 蒸馏出的关键写法

**封面写法**：不是"XX商业计划书"，而是**一句话定位**。
- ✅ "多模态生成领域全球领航者"
- ✅ "虚实之间的造梦师，体验边界的开拓者"
- ✅ "具身智能的核心部件供应商"
- ❌ "XX科技有限公司商业计划书"

**技术页写法**：必须有一个**时间轴/演进叙事**。
```
2020-2022  技术积淀期：提出 U-ViT / DPM-Solver（被 OpenAI/Stable Diffusion 采用）
2023       公司成立
2024       产品发布：Vidu 发布（中国首个对标 Sora）
2025       快速迭代：1.0→1.5→2.0，累计 3 次重大版本
```
模式：**学术界成果（被谁采用）→ 产品化里程碑 → 版本迭代速度**。

**竞争壁垒写法**："不可能三角"或"N 重护城河"。
```
生数：又好（双榜第一）+ 又快（5秒生成）+ 又省（Sora 1/10 成本）
蓝成：宇树独家 + 十年行业沉淀 + 政府背书 + 数据飞轮
未来之城：六大核心技术（语音/力控/脑机/视觉/AI/协作）
```

**市场页写法**：**不要堆数字，要讲叙事**。
```
AI 的第三次跃迁：1.0 语言 → 2.0 视觉 → 3.0 空间
下一代智能终端：PC→移动互联网→AI→具身智能
```

## 案例 2：硬件/制造型（守护兽科技、如一动力、佳安智能）

**特征**：产品实物驱动，客户验证，产能数据。

### 页面结构（10-14 页）

| 页 | 守护兽科技（关节驱动器）| 如一动力 | 佳安智能 |
|----|----------------------|---------|---------|
| 01 | 封面："具身智能核心部件供应商" | 封面 | 封面 |
| 02 | **三问定位**：我们是谁/做什么/团队 | 市场机会 | 行业痛点 |
| 03 | 团队：CEO 20年经验+商务总监23年 | 技术原理 | 产品矩阵 |
| 04 | 产品：驱动器+编码器（实物图）| 产品架构 | 核心技术 |
| 05 | **六大优势**：全国产化/全栈自研/上位机/全系列/集成/性价比 | 应用场景 | 客户案例 |
| 06 | 应用场景：机器人/机械臂/外骨骼 | 客户验证 | 竞对对比 |
| 07 | **业务模式**：标准化模组销售 + 大客户订制 | 量产数据 | 商业模式 |
| 08 | **业务现状**：客户30家/订制56款/量产9款 | 财务预测 | 团队 |
| 09 | **发展规划**：2026→2028 三年出货量目标 | 融资需求 | 发展规划 |
| 10 | **财务数据**：2024 150万→2028 2.5亿 | — | 融资需求 |
| 11 | **融资计划**：估值5000万/出让10%/融资500万 | — | — |
| 12 | 结尾 | 结尾 | 结尾 |

### 蒸馏出的关键写法

**"我们是谁"页写法**：三栏简洁定位。
```
我们是谁：北京守护兽科技，2021年成立，专注机器人关节模组驱动器
我们做什么：为关节电机制造商提供驱动器方案，为终端厂商提供集成服务
我们的团队：北大团队领衔，10年+创业经验，电子+自动化+AI 融合
```

**业务现状写法**：数字驱动、不废话。
```
签约客户：30 个 | 订制驱动：56 款 | 小批量：14 款 | 量产：9 款
```

**财务预测写法**：逐步放量曲线。
```
2024: 150万 → 2025: 450万 → 2026: 2000万 → 2027: 1亿 → 2028: 2.5亿
```

## 案例 3：平台/解决方案型（蓝成应急、未来之城、浙江蓝成）

**特征**：行业深耕+技术平台+多场景覆盖。

### 页面结构（14-18 页）

| 页 | 核心内容 |
|----|---------|
| 01 | 封面：一句话定位（"为机器人提供岗前培训"）|
| 02 | **目录页**：6 大板块概览（行业/公司/技术/商业/融资/亮点）|
| 03 | **行业风口**：万亿赛道+技术临界点+政策东风 |
| 04 | **时代叙事**：PC→移动互联网→AI→具身智能 四阶段跃迁 |
| 05 | **核心痛点 vs 解决方案** 对照表：厂家懂硬件缺场景 ↔ 十年场景沉淀 |
| 06 | **公司实力**：顶尖跨界团队+全维生态资源=不可复制壁垒 |
| 07 | **核心团队**：三人（创始人/CEO/CTO）各一句话证明 + 标签 |
| 08 | **发展里程碑**：产业园 + 研究院 + 战略合作伙伴（宇树/海港/能源） |
| 09 | **战略布局**：海港 × 能源 双场景落地 + 具体指标 |
| 10 | **核心壁垒**：四重护城河（独家合作/自研技术/场景沉淀/政府背书）|
| 11 | **技术产品**：LanchengAIOT 平台（硬件抽象+AI能力+行业应用三层）|
| 12 | **产品矩阵**：应急消防 V1→港口 V2→开放生态 V3 三阶段 |
| 13 | **数据飞轮**：场景数据→模型优化→部署降本→更多客户 正向循环 |
| 14 | **标杆案例**：海港空箱查验(99.8%准确率) + 能源燃料检测 |
| 15 | **商业模式**：硬件销售 + 软件订阅 + 增值服务 |
| 16 | **融资计划** |

### 蒸馏出的关键写法

**目录页写法**（蓝成的尤其出彩）：
```
01 行业风口 — 万亿具身智能赛道，机器人落地刚需爆发
02 公司实力 — 顶尖团队+生态资源，构建场景落地护城河
03 技术产品 — 数据驱动平台，全场景机器人解决方案矩阵
04 商业价值 — 高粘性商业模式，标杆验证的可持续增长
05 融资计划 — 精准投入，加速领跑市场
06 投资亮点 — 赛道+壁垒+落地，打造确定性成长标的
```
每个目录项 = 板块名 + **价值承诺句**。

**痛点 vs 方案对照表写法**：
```
厂家懂硬件缺场景      ←→  十年应急场景沉淀，垂直业务流程全吃透
企业有需求无能力      ←→  自研低代码平台，零门槛快速部署
定制开发周期长成本高  ←→  模块化架构，开发周期↓80% 成本↓70%
极端环境无法作业      ←→  全地形导航+自组网通信，完美适配高危场景
```
格式：左边一句痛点，右边一句我们的解法 + 量化效果。

**数据飞轮写法**：
```
真实场景作业 → 积累多维数据 → 优化大模型 → 降低部署成本 → 更多客户 → 更多数据
```

## 案例 4：消费/服务型（未来之城文旅机器人）

**特征**：可感知的用户价值，单台经济模型，场景可视化。

### 浓缩写法

**收益模型**（简洁到一行一个数字）：
```
文旅打卡机器人
· 单价 49.9 元（自选 3 张 AI 照片）
· 保守预估单台日流水 3,750 元（约 75 单/天）

```

## 通用蒸馏：所有 BP 都有的 8 页

从 25 份 BP 中提取的**必含页面**（顺序可调）：

### P1 封面页
- 公司名 + **一句话价值主张**（不要写"商业计划书"）
- 可选：底部一行 3-4 个核心指标芯片

### P2 市场机会
- **不要堆 TAM 数字**。讲叙事：时代变迁/技术临界点/政策东风
- 可以用"从 X 到 Y"的范式转移框架

### P3 问题与方案
- 左栏 3-4 个痛点，右栏对应 3-4 个方案
- 每个方案带量化效果（↓80% 成本 / ↑40% 效率）

### P4 产品
- 产品架构图 + 3-4 个核心功能卡片
- 技术型公司：技术演进时间轴

### P5 竞争壁垒
- "不可能三角"或"N 重护城河"框架
- 每个壁垒一句话 + 一个证据

### P6 商业模式
- 收入来源 ×3（硬件/订阅/增值）
- 最好配增长飞轮图（客户→数据→优化→更多客户）

### P7 团队
- 3-5 人，每人：姓名 + 头衔 + **一句话为什么是他**（不是罗列履历）
- 学术型公司：首席科学家单独一页

### P8 融资需求
- 估值 / 出让比例 / 融资额 / 资金用途（饼图或清单）
- 结尾页：回到封面那句话

## BP 文案铁律（从 25 份中提炼）

1. **一页一个核心判断**：不是"市场分析"，是"万亿赛道正处在爆发前夜"
2. **数字就是武器**：每个论断后面跟一个数字（准确率99.8% / 成本降80% / 日流水3750元）
3. **团队写"为什么是他"不是"他干过什么"**：蓝成的"前百度智能云消防物联网中心主任"比"10年行业经验"有力十倍
4. **竞对对比必须具体**：不能"技术领先"，要"vs Sora 做到 1/10 成本"
5. **发展路线有版本号**：V1.0 验证→V2.0 深耕→V3.0 生态，比"Q1 Q2 Q3"更有产品感
6. **融资页写"怎么花"比"要多少钱"更重要**：200万运营 + 300万模组超市建设
