# 演讲叙述框架与说服逻辑

PPT 不只"好看"，更要"好讲"。每套幻灯片都要有一条清晰的叙述线。
本文件提供可复用的叙述框架，生成 outline.json 时先把叙述逻辑定好再填内容。

---

## 为什么需要叙述框架

图片生成模型能出好看的图，但**不知道先说什么后说什么、怎么说服观众**。
叙述线 = 页面间的因果关系链，由人来设计。然后用 image-prompt-guide.md 的视觉框架去呈现每一页。

---

## 六大叙述模式

### N1 倒金字塔 — 结论先行

```
结论 → 支撑理由 → 详细数据 → 背景补充
```

**适用**：汇报、述职、向忙碌的决策者汇报。
**核心**：把最重要的结论放在第一页，后面都是支撑。

**页面顺序**：
```
01 结论页（一句话 + 3 个核心数据）
02 总览（框架图全景）
03-06 支撑模块 1/2/3（逐个展示证据）
07 数据汇总
08 下一步 + 请求决策
```

**文案风格**：直接、肯定、无铺垫。"Q3 GMV 增长 47%，超出目标 12 个百分点"而不是"我想汇报一下 Q3 的数据情况……"

---

### N2 英雄之旅 — 问题驱动

```
普通世界 → 遭遇问题 → 尝试解决 → 找到方法 → 验证成功 → 带着成果归来
```

**适用**：产品发布、融资路演、个人述职。
**核心**：让观众跟随你一起经历"发现问题 → 解决问题"的过程。

**页面顺序**：
```
01 现状（"一切安好"的表象）
02 问题浮现（数据/用户反馈揭示的危机）
03 深度分析（问题的根源和严重性）
04 我们的洞察（"我们需要一种全新的方法"）
05 方案（我们做了什么）
06 突破（关键数据/关键时刻）
07 成果（全面数据展示）
08 启示 + 未来
```

**文案风格**：叙事化，有情感起伏。"直到有一天，我们发现……"

---

### N3 WHY-HOW-WHAT — 黄金圈

```
WHY（为什么） → HOW（怎么做） → WHAT（做了什么/结果）
```

**适用**：价值观输出、品牌宣讲、战略沟通。
**核心**：先讲信念/愿景，再讲方法，最后讲产品/结果。

**页面顺序**：
```
01 封面（愿景句）
02 WHY：我们相信什么（信念页）
03 WHY：世界应该是什么样（趋势/市场）
04 WHY：我们为什么做这件事（初心）
05 HOW：我们如何做（方法论/原则）
06 HOW：我们的不同之处（差异化）
07 WHAT：我们做了什么（产品/服务）
08 WHAT：结果（数据/影响）
09 WHAT：下一步（路线图）
10 结语（回到 WHY）
```

**文案风格**：价值观驱动、不急着卖产品。"因为我们相信……"

---

### N4 对比阵痛 — 制造张力

```
现状痛点（长） → 理想状态（短） → 差距/桥 → 我们的方案 → 验证
```

**适用**：SaaS 销售、咨询方案、内部变革推动。
**核心**：先把观众的"痛"讲透，再给"药"。

**页面顺序**：
```
01 "你知道吗？"（一个反常识数据）
02 痛点 1 × 数据
03 痛点 2 × 案例
04 痛点 3 × 代价
05 "如果能这样呢？"（理想状态，不超过 2 页）
06 差距（从痛到理想的桥）
07 我们的方案（框架）
08 如何落地（步骤）
09 预期效果（数据对比）
10 行动起来（call to action）
```

**文案风格**：先共鸣后鼓舞。在痛点页用"你"而不是"你们"。

---

### N5 金字塔论证 — 层层递进

```
基础 → 上层 → 顶层 → 总结
```

**适用**：技术架构汇报、系统介绍、学术论文。
**核心**：从最基础开始，每一层依赖上一层，不可跳跃。

**页面顺序**：
```
01 问题定义
02 理论基础/背景
03 核心方法（架构总览）
04 方法细节 — 模块 A
05 方法细节 — 模块 B
06 方法细节 — 模块 C
07 实验/验证
08 结果分析
09 局限与未来
```

**文案风格**：逻辑严密，过渡句明确。"基于 A，我们设计了 B……"

---

### N6 SCQA — 情境-冲突-问题-答案

```
Situation（情境）→ Complication（冲突）→ Question（问题）→ Answer（答案）
```

**适用**：咨询报告、战略建议、商业提案。
**核心**：麦肯锡经典框架，从大家都认可的现状出发引出矛盾。

**页面顺序**：
```
01 情境：行业现状（公认事实）
02 情境：我们的现状（公司表现）
03 冲突：出现了什么变化（外部/内部）
04 冲突：这个变化意味着什么（如果不改变……）
05 问题：所以核心问题是什么
06 答案：我们的建议（金字塔顶部）
07 支撑 1：为什么这个建议可行
08 支撑 2：数据支撑
09 支撑 3：风险与应对
10 行动方案：具体怎么做
```

**文案风格**：冷静、客观、推理性。"我们看到……这使得……因此核心问题是……我们的建议是……"

## 文案铁律

1. **一页一个核心信息**：如果一句话说不清这一页想表达什么，拆成两页。
2. **数字先行**：能用数字就不用形容词。不说"增长迅速"，说"同比增长 47%"。
3. **动词驱动**：每页标题/结论用动词。"营收突破 1 亿"比"营收数据"好一百倍。
4. **不写 AI 腔**：避免"探索""深入""总而言之""在当今时代""赋能""抓手"。
5. **受众视角**：对老板讲"省了多少"、对投资人讲"赚了多少"、对用户讲"解决了什么痛"。
6. **结论句放最上面**：不是"结论"两个字的标签，而是一句完整的判断。
