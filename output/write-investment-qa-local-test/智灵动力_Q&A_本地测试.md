# 智灵动力（北京）科技有限公司

## Q1：ZeeLin 的核心定位，为什么不能只概括为一家大模型公司？

智灵动力更接近一家以自进化智能体框架为底座、向企业工作流提供产品和交付能力的应用型 AI 公司，而不是训练通用基础模型的厂商。其产品从 Desearch 研究智能体延伸到视频、短剧、数字人和 MetaV 品牌营销，说明公司试图把多模态理解、内容生成和任务执行能力装进具体业务流程。这个定位的吸引力在于场景贴近付费部门，难点则是产品跨度较大，研发、销售和交付资源能否围绕一个高频入口形成合力，将直接决定公司是长成平台，还是停留在多个项目型工具的集合。

## Q2：Desearch 能否成为 ZeeLin 最先跑通标准化收入的产品？

Desearch 是当前产品矩阵里最接近标准软件形态的一环。产品侧已经呈现深度研究、行业研究、专家模式、知识库和多源数据融合等能力，并向企业客户开放 API 与 MCP 接口。这意味着它既可以作为独立研究工具收费，也可以嵌入客户已有系统，商业模式比单次内容制作更容易形成订阅、调用量或私有化部署收入。

真正决定其收入质量的不是功能数量，而是企业用户在研究流程中的使用频次、席位扩张和续费表现。若知识库、企业接口与研究工作流能够沉淀为稳定使用习惯，Desearch 有机会成为获客入口，并把后续的定制需求导向标准模块；反过来，如果主要收入仍来自逐项目搭建和人工交付，产品上线本身不会自动转化为软件规模效应。

## Q3：FDE 项目交付如何沉淀为可复用产品，而不是持续增加人力成本？

智灵动力提出的路径是先由 FDE 团队进入客户现场，把业务需求拆成智能体工作流，再将反复出现的能力组件化，沉淀到研究、内容生成和营销产品中。这一路径适合企业 AI 早期市场：客户往往说不清需求，纯标准产品难以直接成交，项目交付可以缩短从演示到实际使用的距离，也能帮助公司识别哪些能力值得产品化。

这套模式能否形成经营杠杆，取决于同类项目之间的复用率。如果每个项目都要重新连接数据、重写流程并长期驻场，合同额增长会同步推高交付人天，毛利和现金流承压；如果核心组件、评测方法和行业知识库可以重复使用，新增项目的实施周期会缩短，交付经验才会转化为产品壁垒。因而，评价 FDE 的关键不是项目数量，而是标准模块收入占比、单项目人天、上线周期和后续增购之间是否出现持续改善。

## Q4：MetaV 与视频、短剧、数字人产品并行，会带来协同还是资源分散？

MetaV 把创意生成、内容生产、智能获客和效果分析放在同一条营销链路中，与视频、短剧和数字人能力存在天然复用关系：底层模型、素材处理、品牌知识库和内容评测可以共享，客户也可能从一次内容制作扩展到持续营销服务。若这些产品由统一账户、工作流和数据层承载，多产品并行有助于提高客单价，并增加客户切换成本。

风险在于每个场景都有不同的销售对象和交付节奏。研究工具面向知识工作者，品牌营销面向市场部门，短剧和数字人又带有内容制作属性；若各产品分别建设渠道和交付团队，有限资源会被摊薄。当前更合理的观察框架，是看多条产品线是否共享同一技术底座、同一客户群和同一交付资产，而不是仅以产品数量判断平台价值。

## Q5：ZeeLin 当前的商业化信号，能说明客户愿意持续付费吗？

官网产品可访问、Desearch 对外提供企业接口、MetaV 展示完整营销流程，加上与高校围绕 AI 内容创作实践平台的交流，说明智灵动力已经越过单纯概念展示阶段，具备把能力包装成产品并接触真实使用场景的基础。这些信号对早期项目有意义，因为它们降低了“只有技术设想、没有产品载体”的风险。

但产品上线、合作交流和持续付费是三件不同的事。前两者更多说明触达能力和产品完成度，只有合同、交付、验收、回款、续费与增购能回答收入质量。智灵动力的商业化判断应围绕同一批客户的状态变化展开：从试用到付费用了多久，首次合同中多少是人工服务，第二次采购是否转向标准模块，以及回款周期是否随复制而缩短。只有这条链路连续出现，产品矩阵才真正具备可估值的增长含义。

## Q6：ZeeLin 的多场景产品矩阵应如何影响估值判断？

现阶段不宜把研究、视频、短剧、数字人和营销产品简单相加后计算平台溢价。多场景首先提供的是选择权：公司可以用较低成本测试不同需求，找到付费意愿更强、交付更容易复用的入口；选择权只有在客户重合、技术复用和交叉销售发生后，才会转化为收入协同。否则，多产品会增加研发维护、销售教育和客户成功成本，规模越大反而越考验现金流。

因此，估值的基础价值应来自已经形成的可重复收入和可观察毛利，平台期权则来自 Desearch、FDE 组件与 MetaV 之间的复用。若后续经营数据表明标准模块收入占比上升、实施人天下降、同一客户购买多个产品，平台溢价才有扎实依据；若增长主要依靠新增定制项目，估值锚点应更接近技术服务公司，而不是高倍数软件平台。

## Q7：继续接触智灵动力的价值是什么，什么情况会使这一判断失效？

智灵动力值得继续接触的核心理由，是公司已经形成可观察的产品矩阵，并选择用 FDE 贴近企业工作流，再把交付经验沉淀为标准能力。这条路径与企业 AI 从演示走向业务落地的阶段相匹配，Desearch 和 MetaV 又分别提供了研究与营销两个可直接体验的产品入口。对早期投资人而言，这类项目的价值不在于产品线看起来完整，而在于有机会用较短周期识别“项目收入能否变成产品收入”这一关键拐点。

接触的重点应集中在三组经营关系。第一，Desearch 的活跃使用、付费席位和续费是否同步增长，以确认研究智能体具备独立产品价值；第二，FDE 项目的标准模块占比、交付人天和毛利是否持续改善，以确认项目经验正在形成复用；第三，MetaV 与内容产品是否服务同一批客户并产生增购，以确认多场景不是资源分散。若三组关系中至少两组出现连续改善，公司具备从早期产品验证走向规模化的可能。

这一判断会在两类情形下失效：一是收入增长长期依赖新增定制项目，人员扩张与合同额保持近似同步，说明经营杠杆没有形成；二是多条产品线客户重合度低，各自需要独立销售和交付体系，平台协同难以兑现。在这两种情形下，公司的技术与产品能力仍可能具有产业合作价值，但股权投资的回报空间会明显收窄。
