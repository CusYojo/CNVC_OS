# 智灵动力Q&A 报告
## Q1：公司的产品定位能否形成可复制的客户价值？

智灵动力拟以多模态理解、语言模型和推理能力构建面向业务场景的智能引擎，产品价值不在于单项模型指标，而在于能否把客户工作流中的识别、判断和执行环节连接起来。若同一技术底座能够在多个客户场景中复用，交付周期和新增项目的人力投入有望下降，商业模式才可能从定制项目逐步转向标准产品与持续服务。

目前能够确认的是产品方向和技术架构已经形成，但跨客户复用、交付周期、实际使用频率和付费意愿仍缺少连续经营数据支撑。下一阶段应以真实客户的部署范围、验收结果、续费或扩单行为作为产品化程度的主要判断依据；如果每个项目仍需重新开发，收入增长将继续依赖同比增加的交付人员。

## Q2：现有商业化进展是否足以支持下一轮融资？

融资说服力取决于客户状态是否已经跨过需求接触、试用、合同、验收和回款之间的关键门槛。客户名单或合作意向只能说明市场接触面，正式合同能够验证采购意愿，验收与回款则进一步验证产品交付质量和客户预算的真实性，几类信号不能相互替代。

在缺少连续合同、验收和回款记录的情况下，下一轮融资更可能依赖团队背景和技术预期，估值安全边际相对有限。公司需要用同口径客户漏斗说明各阶段数量、转化周期、合同金额、交付成本与回款节奏，并证明新增客户不会同比增加定制开发负担，才能把技术故事转化为可核验的经营增长逻辑。

## Q3：当前最需要关注的反方风险是什么？

最重要的反方风险是技术能力尚未稳定转化为可重复交付和持续回款。大模型及多模态产品迭代较快，基础模型能力可能被平台厂商持续商品化；如果公司的竞争优势主要来自模型调用和项目实施，而非专有数据、行业工作流、交付效率或客户迁移成本，产品差异化可能随基础能力普及而收窄。

这一风险应通过三组经营事实持续观察：同类场景的部署周期是否缩短，单位交付人力是否下降，存量客户是否形成续费或扩单。若技术指标提升但上述经营指标没有同步改善，说明核心资产尚未形成稳定的商业机制，投资判断应保持审慎，并把资源优先放在客户验证与产品化效率而非单纯扩大研发规模上。
